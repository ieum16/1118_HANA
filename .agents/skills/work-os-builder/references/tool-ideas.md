# 작은 도구 아이디어 모음 (HTML 한 장)

불편을 들은 뒤 해결 아이디어를 낼 때 쓴다. 모두 `index.html` 하나로, 서버 · 로그인 · API 키 · 실제 데이터 없이 돌아가는 것만 적었다. 이름은 수강생의 직무에 맞게 바꿔서 제안한다.

## 도구 유형 (쉬운 순서)

| 유형 | 모양 | 이런 불편에 | 난이도 |
|---|---|---|---|
| **작성기** | 칸 몇 개를 채우면 정해진 문장이 완성되고 복사 버튼 | 같은 안내 · 보고 문장을 매번 다시 씀 | 쉬움 |
| **점검표** | 체크 항목 + 진행률, 다 체크하면 "완료" 표시, 날짜 바뀌면 초기화 | 정기 업무 · 절차를 빠뜨림 | 쉬움 |
| **계산기** | 숫자 몇 개 입력 → 결과 + 결과를 담은 안내 문장 복사 | 계산기 두드리고 결과를 다시 옮겨 적음 | 보통 |
| **변환기 · 검사기** | 글이나 표를 붙여 넣으면 정리 · 가리기 · 빨간 표시 | 엑셀 · 메신저 내용을 손으로 다듬음, 표현 실수 | 보통 |
| **현황판** | 표(가짜 데이터 또는 붙여넣기)를 숫자 요약 · 막대 차트로 | 매주 같은 집계 · 보고 | 보통 |

## 금융권 직군별 불편 → 아이디어

| 직군 | 자주 듣는 불편 | HTML 도구 아이디어 |
|---|---|---|
| 창구 · 개인금융 | 만기 금액 · 이자를 물을 때마다 계산하고 안내문을 다시 씀 | 예적금 만기 계산기 (세후 금액 + 안내 문장 복사) — `[강사예시]` 참고 |
| 창구 · 개인금융 | 고객마다 필요 서류를 말로 설명하고 빠뜨림 | 업무별 필요 서류 점검표 (업무 고르면 서류 목록 + 안내 문장) |
| 창구 · 공통 | 마감 때 시재 · 서류 점검을 기억에 의존 | 일일 마감 점검표 (항목 체크 + 진행률 + 날짜 바뀌면 초기화) |
| 외환 · 송금 | 환전 금액 · 우대율 계산하고 안내를 다시 씀 | 환전 안내 계산기 (기준환율 · 우대율 → 살 때 금액 + 안내 문장) |
| 여신 · 기업금융 | 중도상환수수료 · 이자를 매번 계산 | 중도상환수수료 계산기 (잔액 · 요율 · 남은 기간 → 수수료 + 설명 문장) |
| 여신 · 기업금융 | 만기 도래 고객에게 비슷한 연락 문장을 반복 작성 | 만기 안내 문장 작성기 (고객 유형 · 만기일 · 필요 서류 → 문장 복사) |
| 고객 안내 · 마케팅 | 문자 · 카톡 안내문에 쓰면 안 되는 표현을 매번 눈으로 확인 | 금지어 점검기 (글 붙여 넣기 → "확정 수익 · 무조건 · 100%" 빨간 표시 + 바꿀 말 제안) |
| 내부통제 · 공통 | AI나 메신저에 붙이기 전에 개인정보를 손으로 지움 | 개인정보 마스킹기 (글 붙여 넣기 → 주민번호 · 계좌 · 전화번호 가리기 + 가린 개수) |
| 본부 · 기획 | 매주 엑셀을 정리해 같은 모양의 보고 숫자를 만듦 | 주간 현황판 (표 붙여 넣기 → 합계 · 증감 · 막대 차트, 가짜 데이터로 시작) |
| 본부 · 공통 | 회의 메모를 보고 문장으로 다시 정리 | 회의 메모 → 보고 문장 정리기 (항목 칸 채우기 → 보고 형식 문장 복사) |

## HTML 하나로 안 되는 요청을 바꾸는 법

| 원래 요청 | HTML로 바꾸면 |
|---|---|
| 고객에게 자동으로 문자 · 메일 보내기 | 문장을 만들어 **복사 버튼** (보내기는 사람이) |
| 사내 시스템에서 자동으로 불러오기 | 시스템 화면을 복사해 **붙여 넣으면** 정리 |
| 엑셀 파일 여러 개 합치기 | 표를 **붙여 넣으면** 합쳐서 보여 주기 (파일 업로드 없이) |
| 앱 안에서 AI가 답하기 | 정해진 규칙 · 문장 틀로 만들기 (AI 호출은 키 · 보안 승인이 필요한 다음 단계) |
| 팀이 함께 쓰는 공유 장부 | 첫 버전은 혼자 쓰는 브라우저 저장 + 백업 버튼 (공유는 다음 단계) |
