# 디자인 참고 사이트

홈페이지나 나만의 도구를 만들 때, 원하는 분위기와 화면 구성을 찾아보는 사이트입니다.

| 사이트 | 주소 | 이렇게 활용해요 |
|---|---|---|
| **Superdesign · 수퍼디자인** | [superdesign.dev](https://superdesign.dev/) | 디자인 예시와 프롬프트를 살펴보고, 원하는 화면을 말로 설명해 UI 시안을 만들어 봐요. |
| **Get Design MD** | [getdesign.md](https://getdesign.md/) | 여러 웹사이트의 색상·글꼴·간격·컴포넌트를 정리한 `DESIGN.md`를 찾아 AI에게 디자인 기준으로 전달해요. |
| **Pinterest · 핀터레스트** | [pinterest.com](https://www.pinterest.com/) | 이미지로 디자인 아이디어를 찾고, 마음에 드는 색상과 화면 배치를 모아 봐요. |

## 실습에서 쓰는 순서

1. 참고 사이트에서 마음에 드는 디자인을 찾아요. 핀터레스트에서는 `팀 소개 홈페이지`, `대시보드 UI`, `할 일 앱 디자인`처럼 검색해 보세요.
2. 마음에 드는 점을 구체적으로 골라요. 예: 초록색 포인트, 넓은 여백, 둥근 카드, 큰 제목.
3. 참고 화면이나 `DESIGN.md`를 AI에게 전달하고, 내 실습에 맞게 만들어 달라고 요청해요.

### 참고 화면으로 요청하기

```text
첨부한 참고 화면의 색상, 여백, 카드 배치를 참고해서 내 팀 소개 페이지를 만들어 줘.
팀 이름과 문구는 내 기획서를 사용하고, 이미지는 내가 만든 것으로 넣어 줘.
```

### DESIGN.md로 요청하기

```text
첨부한 DESIGN.md의 색상, 글꼴, 간격 규칙을 참고해서 내 홈페이지 디자인을 다듬어 줘.
기존 기능은 유지하고, 바꾼 내용을 짧게 알려 줘.
```

참고 화면은 디자인을 살펴보는 용도로 사용해요. 다른 사이트에서 캡처한 `reference.png`는 과제 저장소에 올리지 않고, 결과물의 이미지와 로고는 직접 만들거나 사용 가능한 자료를 써요.
