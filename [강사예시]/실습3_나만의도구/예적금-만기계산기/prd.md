# 예적금 만기 계산기 PRD

## 한 줄 소개
원금 · 금리 · 기간만 넣으면 만기 때 받을 세후 금액과 고객 안내 문장이 바로 나오는 계산기

## 누가 쓰나
- 창구에서 예적금 상담을 하는 직원
- 고객에게 메신저 · 문자로 만기 금액을 안내하는 직원

## 줄이고 싶은 불편
- 상담할 때마다 계산기로 이자, 세금, 수령액을 따로 계산한다
- 계산한 숫자를 안내 문장으로 다시 옮겨 적는다

## 입력
- 상품 종류: 정기예금 / 정기적금
- 원금(예금) 또는 월 납입액(적금)
- 연 금리(%)
- 기간(개월)
- 가입일

## 출력
- 원금 합계, 세전 이자, 이자소득세(15.4%), 세후 이자, 만기 수령액
- 만기일
- 고객 안내 문장

## 꼭 필요한 기능 (3개)
1. 원금 · 금리 · 기간 입력칸
2. 세후 수령액 표시
3. 안내 문장 복사 버튼

## 있으면 좋은 기능
- 단리 · 월복리 선택 ← 1차 완성 뒤 추가
- 월별 이자 표
- 비과세 선택

## 예외 상황
- 빈칸, 0, 음수, 글자를 넣으면 계산하지 않고 안내 문구를 보여 준다
- 콤마가 들어간 금액(1,000,000)도 계산한다
- 기간은 1~120개월

## 조건
- HTML 파일 하나(index.html), 로그인 없음
- 실제 고객 정보 없이 가상 금액으로만 쓴다
- 실제 금액은 은행 시스템 기준이라는 안내를 화면에 넣는다
