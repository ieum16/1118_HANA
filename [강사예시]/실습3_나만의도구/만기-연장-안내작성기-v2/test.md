# 만기 연장 안내 작성기 v2 테스트 체크리스트

prd.md 기준. 하나씩 해 보고 ○ / × 를 적는다. × 는 3줄 공식(무엇을 했더니 · 기대한 것 · 실제 결과)으로 Codex에 말한다.

처음 상태로 돌리려면 화면 맨 아래 「기록 모두 지우기」를 누른다. 날짜는 2026-11-19에 연 것을 기준으로 적었다. 「예시 목록 넣기」의 만기일은 여는 날 기준으로 바뀐다.

## 꼭 필요한 기능
| 번호 | 해 볼 것 | 기대 결과 | ○/× |
|---|---|---|---|
| 1 | index.html 더블클릭으로 열기 | 예시 목록 12곳이 이미 들어가 있고, 요약에 "12 만기 고객 · 2 급한 곳", 카드가 만기일 순으로 나온다 | |
| 2 | `만기도래_고객목록_2026-11.xlsx`를 열어 표 전체(제목 줄 포함) 복사 → 붙여넣기 칸을 비우고 붙여 넣기 → 「목록 읽기」 | 12곳 카드가 만들어지고 빨간 칸(읽지 못한 줄)은 안 나온다 | |
| 3 | 2번 뒤 (주)한빛정밀 카드 보기 | 법인 · 운전자금 · D-8 · 급해요. 필요 서류 5가지. 문장에 "만기가 얼마 남지 않아 서둘러 연락드렸습니다." | |
| 4 | (주)다온물류(법인 · 시설자금) 카드 | 필요 서류 6가지, 마지막이 "담보 물건 등기사항전부증명서" | |
| 5 | 청솔인테리어(개인사업자 · 시설자금) 카드 | 필요 서류 5가지. 재무제표 · 법인 인감증명서는 없다 | |
| 6 | (주)한빛정밀에서 서류 1~3번 체크 | 문장이 노란 "재요청 문장 · 아직 안 온 서류 2가지"로 바뀌고, 부가가치세 과세표준증명원 · 법인 인감증명서만 들어 있다. 태그에 "3/5 받음" | |
| 7 | 같은 카드에서 4~5번도 체크 | 초록 "접수 완료 문장"으로 바뀌고 "서류 다 받음" 태그. 요약의 "서류 다 받은 곳"이 1 | |
| 8 | 아무 카드 「문장 복사」 → 메모장에 붙여 넣기 | 버튼이 잠깐 "복사했어요", 화면 문장과 같은 문장이 줄바꿈까지 그대로 | |
| 9 | 6~7번 체크한 뒤 창을 닫았다가 다시 열기 | 체크와 문장 상태가 그대로 남아 있다 | |

## 예외 상황
| 번호 | 해 볼 것 | 기대 결과 | ○/× |
|---|---|---|---|
| 10 | 만기일을 `2027.2.3` · `2027/01/08` 로 바꿔 붙여 넣기 | 둘 다 정상으로 읽는다 | |
| 11 | 고객유형을 `개인`, `법인사업자`로 적기 | 각각 개인사업자 · 법인으로 읽는다 | |
| 12 | 만기일 `2027-02-30` 넣기 | 그 줄만 빨간 칸에 "만기일을 읽지 못했어요", 나머지는 정상 | |
| 13 | 만기일 `2025-01-10` 넣기 | 그 줄만 "이미 지났어요" | |
| 14 | 회사명에 `(주)테스트 010-1234-5678` | 그 줄만 "회사명 칸에 실제 번호처럼 보이는 숫자가 있어요". 빨간 칸에 그 번호가 다시 나오지 않는다 | |
| 15 | 고객유형에 `외국인` | 그 줄만 "법인 또는 개인사업자로 적어 주세요" | |
| 16 | 같은 회사 · 같은 만기일 줄을 두 번 붙여 넣기 | 두 번째 줄만 "이미 위에 있어요" | |
| 17 | 회신 기한 규칙을 14 → 7로 바꾸기 | 급하지 않은 고객의 회신 기한이 만기일 7일 전(주말이면 앞 금요일)으로 바뀐다 | |
| 18 | 카드의 회신 기한을 만기일 뒤 날짜로 고르기 | "회신 기한은 오늘 이후, 만기일보다 앞으로" 안내가 뜨고 원래 날짜로 돌아간다 | |
| 19 | 담당자 이름 비우기 | 문장 첫 줄이 "… 대표님. 담당 RM입니다." | |
| 20 | 「급한 곳」 · 「서류 다 받은 곳」 버튼 | 해당 고객만 보인다. 없으면 "이 조건에 맞는 고객이 없어요." | |
| 21 | 「기록 모두 지우기」 → 확인 | 체크가 모두 풀리고 예시 목록으로 돌아간다 | |
