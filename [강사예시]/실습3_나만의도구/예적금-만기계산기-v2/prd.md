# 적금 상품 비교 계산기 PRD (예적금 만기계산기 v2)

v1(`../예적금-만기계산기`)은 상품 하나를 계산했다. 그런데 계산 자체는 은행 시스템에도 있다. v2는 시스템이 잘 안 해 주는 것, **고객 앞에서 상품 여러 개를 한 화면에 나란히 놓고 비교해 보여 주는 것**에 집중한다.

## 한 줄 소개
매월 넣을 금액 · 기간 · 고객이 채울 수 있는 우대 조건을 고르면 하나은행 적금 3개의 세후 만기 금액을 나란히 보여 주고, 상담 안내 문장을 만들어 주는 계산기

## 누가 쓰나
- 창구 · 전화로 적금 상담을 하는 직원
- "어떤 적금이 나아요?"라는 질문에 상품을 하나씩 조회해서 비교하던 직원

## 줄이고 싶은 불편
- 상품마다 금리표 · 우대 조건을 따로 열어 보고, 고객 조건에 맞춰 머릿속으로 비교한다
- 비교한 결과를 고객에게 보낼 문장으로 다시 쓴다

## 데이터 (AI로 공개 페이지에서 옮겨 옴)
- 하나은행 홈페이지 상품 안내 · 금리안내 팝업에서 판매 중인 적금 3개를 골라 금리를 옮겨 적었다 (금리 기준일 2026-11-19, 확인일 2026-11-19)
- 은행연합회 소비자포털 공시와 기본금리를 맞춰 봤다 (내맘 적금 · 주거래하나 월복리 적금 일치)
- 홈페이지는 금리 박스를 화면에서 그려 넣고, robots.txt가 자동 수집을 막아 둔 주소가 있다. 그래서 **도구가 실시간으로 긁어 오지 않고**, 사람이 확인한 값을 코드 맨 위 `PRODUCTS` 표에 넣었다. 금리가 바뀌면 그 표만 고친다

| 상품 | 이자 방식 | 1년 · 2년 · 3년 기본금리 (연 %) | 우대 (연 %) | 납입 한도 |
|---|---|---|---|---|
| 내맘 적금 (정액적립식) | 단리 (은행연합회 분류) | 2.3 · 2.4 · 2.5 | 입출금통장 자동이체 0.5 | 매월 1천원 ~ 1,000만원 |
| 주거래하나 월복리 적금 | 월복리 | 2.95 · 3.0 · 3.1 | 주거래 실적 1종 0.5 / 2종 이상 0.9, 온라인 가입 0.1 (최대 1.0) | 분기당 1만원 ~ 300만원 |
| 급여하나 월복리 적금 | 월복리 | 2.95 · 3.0 · 3.1 | 급여 이체 0.9, 온라인 가입 0.1 (최대 1.0) | 분기당 1만원 ~ 300만원 |

- 급여하나 월복리 적금의 청년 특별금리(연 1.3%, 만 35세 이하 · 1년제 · 카드 실적 등 조건)는 넣지 않았다
- 내맘 적금 상품 페이지의 만기이자 예시는 지금 금리와 맞지 않는 옛 수치라 쓰지 않았다

## 입력
- 매월 넣을 금액
- 기간: 1년 / 2년 / 3년
- 세금: 일반과세 15.4% / 비과세종합저축
- 우대 조건: 자동이체 · 급여 이체 · 온라인 가입 체크, 주거래 실적 없음 / 1종 / 2종 이상

## 출력
- 상품 카드 3개: 적용 금리(기본 + 우대 내역), 세후 만기 수령액, 원금 합계, 세전 이자, 세금
- 가장 많이 받는 상품에 "이 조건에서 가장 많이" 표시 (같으면 둘 다)
- 상담 안내 문장 + 복사 버튼

## 꼭 필요한 기능 (3개)
1. 고객 조건 입력 → 상품 3개 만기 금액 나란히
2. 우대 조건을 체크하면 상품별 적용 금리가 바뀌기
3. 비교 안내 문장 복사

## 예외 상황
- 금액이 비었거나 0 이하, 글자, 소수면 계산하지 않고 안내
- 콤마가 들어간 금액(500,000)도 계산한다
- 상품 한도를 넘으면 그 상품 카드만 "매월 ○○원까지만"으로 바꾸고 나머지는 계산한다 (예: 매월 120만원 → 월복리 두 상품은 분기 300만원 한도 초과)
- 넣을 수 있는 상품이 하나도 없으면 문장을 만들지 않는다

## 조건
- HTML 파일 하나, 로그인 · 서버 없음. 입력한 내용을 바깥으로 보내지 않는다
- 화면 아래에 출처 · 기준일 · "실제 금액은 은행 시스템 기준"을 넣는다
- 고객 실명 · 계좌번호는 입력칸 자체가 없다
