# 만기 연장 안내 작성기 테스트 체크리스트

prd.md 기준. 하나씩 눌러 보고 ○ / × 를 적는다. × 는 3줄 공식(무엇을 했더니 · 기대한 것 · 실제 결과)으로 Codex에 말한다.

기본값: 아래 표에서 따로 말하지 않으면 회사명 `(주)한빛정밀` · 담당자 `연습요정` · 만기일 `2027-01-15` · 회신 기한 `2027-01-05` 로 둔다.

## 꼭 필요한 기능
| 번호 | 해 볼 것 | 기대 결과 | ○/× |
|---|---|---|---|
| 1 | index.html 더블클릭으로 열기 (아무것도 안 바꾸기) | 예시 값이 이미 들어 있고, 필요 서류 "5가지"와 안내 문장이 바로 보인다. 만기일은 오늘부터 28일 뒤, 회신 기한은 그 14일 전 | |
| 2 | 법인 · 운전자금 · 기본값 | 필요 서류 **5가지**. 문장 둘째 줄이 "(주)한빛정밀의 운전자금 대출 만기일이 2027년 1월 15일(금)이라 기한 연장 안내드립니다." 셋째 줄에 "서류 5가지를 2027년 1월 5일(화)까지" | |
| 3 | 2번에서 대출 종류만 시설자금으로 | 필요 서류 **6가지**, 6번이 "담보 물건 등기사항전부증명서 (최근 3개월 이내 발급)" | |
| 4 | 개인사업자 · 회사명 `봄날베이커리` · 운전자금 | 필요 서류 **4가지**: 사업자등록증 사본 / 소득금액증명원 (최근 2년) / 부가가치세 과세표준증명원 (최근 1년) / 대표자 신분증 (방문하실 때 지참). 재무제표 · 법인 인감증명서는 없다 | |
| 5 | 4번에서 시설자금으로 | 필요 서류 **5가지** (4번 목록 + 담보 물건 등기사항전부증명서) | |
| 6 | 「안내 문장 복사」 → 메모장에 붙여 넣기 | 버튼이 잠깐 "복사했어요"로 바뀌고, 화면 문장과 같은 문장이 줄바꿈까지 그대로 붙는다 | |

## 예외 상황
| 번호 | 해 볼 것 | 기대 결과 | ○/× |
|---|---|---|---|
| 7 | 회사명 비우기 (띄어쓰기만 넣어도) | "회사명을 넣어 주세요. (가짜 이름으로 연습해요)" 안내, 문장 칸은 "입력값을 넣으면 안내 문장이 만들어집니다.", 복사 버튼 꺼짐 | |
| 8 | 회사명에 31자 넣기 (예: "가"를 31번) | "회사명은 30자 이내로 넣어 주세요." 안내, 복사 버튼 꺼짐 | |
| 9 | 회사명에 `(주)테스트 010-1234-5678` | "전화번호 · 계좌번호 같은 실제 번호는 넣지 말아 주세요." 안내, 복사 버튼 꺼짐 | |
| 10 | 회사명에 `(주)한빛정밀2공장` (숫자 한 자리) | 안내 없이 문장이 정상으로 나온다 | |
| 11 | 담당자 이름 비우기 | 첫 줄이 "안녕하세요, (주)한빛정밀 대표님. 담당 RM입니다." | |
| 12 | 만기일 지우기 | "대출 만기일을 골라 주세요." 안내, 복사 버튼 꺼짐 | |
| 13 | 만기일 `2025-01-10` (지난 날짜) | "만기일이 이미 지났어요. 날짜를 확인해 주세요." 안내 | |
| 14 | 회신 기한을 `2027-01-15`(만기일과 같은 날) 또는 `2027-01-20` | "서류 회신 기한은 만기일보다 앞이어야 해요." 안내 | |
| 15 | 회신 기한 `2025-12-01` (지난 날짜) | "서류 회신 기한이 이미 지났어요. 오늘 이후로 골라 주세요." 안내 | |
| 16 | 7~15번 뒤에 기본값으로 되돌리기 | 안내 문구가 사라지고 2번과 같은 문장이 다시 나오며 복사 버튼이 켜진다 | |

## 있으면 좋은 기능 (아직 안 만듦 · 붙인 뒤 확인)
| 번호 | 해 볼 것 | 기대 결과 | ○/× |
|---|---|---|---|
| 17 | 엑셀에서 가짜 고객 3줄(회사명 · 유형 · 대출 종류 · 만기일)을 복사해 붙여 넣기 | 고객 3명의 안내 문장이 각각 만들어지고, 문장마다 복사 버튼이 있다 | |
| 18 | 법인 · 운전자금에서 "법인 인감증명서" 체크 빼기 | 필요 서류 4가지, 문장에서도 빠지고 "서류 4가지"로 바뀐다 | |
| 19 | 받은 서류 1~3번 체크 → 재요청 문장 만들기 | "아직 안 온 서류 2가지"(부가가치세 과세표준증명원, 법인 인감증명서)만 담긴 문장이 나온다 | |
