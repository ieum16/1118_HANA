# 만기 연장 안내 작성기 PRD

## 한 줄 소개
고객 유형 · 회사명 · 대출 종류 · 만기일을 넣으면 그 고객에게 필요한 서류 목록이 들어간 만기 연장 안내 문장이 완성되고, 복사해서 메신저에 붙여 넣는 작성기

## 누가 쓰나
- 기업 고객의 대출 만기를 관리하는 기업금융 RM
- 매주 만기 도래 고객에게 메신저로 연장 안내를 보내는 직원

## 줄이고 싶은 불편
- 매주 월요일 만기 도래 고객 목록(엑셀)을 보고, 고객마다 거의 같은 연장 안내 문장을 다시 쓴다 (주 15건쯤, 건당 5분 → 주 75분쯤)
- 필요 서류(재무제표, 사업자등록증 등)를 빠뜨려서 고객에게 다시 연락하는 일이 생긴다

## 입력
- 고객 유형: 법인 / 개인사업자
- 회사명 (가짜 이름으로 연습)
- 대출 종류: 운전자금 / 시설자금 (가정)
- 대출 만기일
- 서류 회신 기한 (가정 · 처음에는 만기일 14일 전으로 채워 둔다)
- 담당자 이름 (닉네임, 비워도 됨)

## 출력
- 고객 유형 · 대출 종류에 맞는 필요 서류 목록과 개수
- 메신저에 붙여 넣을 만기 연장 안내 문장 (만기일 · 회신 기한에 요일까지 표시)

## 필요 서류 목록 (가정 · 연습용 예시)
| 경우 | 서류 |
|---|---|
| 법인 공통 (5가지) | 사업자등록증 사본 · 법인 등기사항전부증명서(최근 3개월 이내 발급) · 최근 3개년 재무제표(결산 기준) · 부가가치세 과세표준증명원(최근 1년) · 법인 인감증명서(최근 3개월 이내 발급) |
| 개인사업자 공통 (4가지) | 사업자등록증 사본 · 소득금액증명원(최근 2년) · 부가가치세 과세표준증명원(최근 1년) · 대표자 신분증(방문하실 때 지참) |
| 시설자금이면 더하기 (1가지) | 담보 물건 등기사항전부증명서(최근 3개월 이내 발급) |

실제 필요 서류는 은행 내규 · 심사 기준을 따른다. 이 표는 화면 동작을 보기 위한 예시다.

## 꼭 필요한 기능 (3개)
1. 고객 유형 · 회사명 · 대출 종류 · 만기일 · 회신 기한 입력칸
2. 고객 유형 · 대출 종류에 맞는 필요 서류 목록이 문장에 자동으로 들어가기
3. 안내 문장 복사 버튼

## 있으면 좋은 기능
- 엑셀에서 만기 고객 목록을 복사해 붙여 넣으면 여러 고객의 문장을 한꺼번에 만들기 ← 1차 완성 뒤 추가
- 서류 목록에서 이번 고객에게 필요 없는 서류 빼기 · 직접 더하기
- 받은 서류를 체크하면 "아직 안 온 서류"만 담은 재요청 문장 만들기
- 말투 고르기 (정중하게 / 짧게)

## 예외 상황
- 회사명을 비우면 문장을 만들지 않고 "회사명을 넣어 주세요" 안내, 복사 버튼은 꺼진다
- 회사명이 30자를 넘으면 "30자 이내로" 안내
- 회사명 · 담당자 칸에 전화번호 · 계좌번호 · 주민번호처럼 숫자가 6자리 이상 이어지면 "실제 번호는 넣지 말아 주세요" 안내 (가정)
- 만기일을 비우거나, 이미 지난 날짜를 고르면 안내
- 회신 기한을 비우거나, 오늘보다 앞이거나, 만기일과 같거나 뒤면 안내
- 담당자 이름을 비우면 문장에 "담당 RM입니다"로만 넣는다

## 조건
- HTML 파일 하나(index.html), 로그인 · 서버 없음, 더블클릭으로 열린다
- 가짜 회사명 · 가짜 날짜로만 연습한다. 입력한 내용을 바깥으로 보내지 않는다
- 메신저로 **자동 발송은 하지 않는다.** 문장을 복사 버튼으로 만들고, 보내기는 사람이 직접 한다
- 화면 아래에 "실제 필요 서류 · 연장 조건은 은행 내규와 시스템 기준"이라는 안내를 넣는다
