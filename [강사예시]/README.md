# 강사 예시

수업에서 보여 주는 예제입니다. **이 폴더는 고치지 않아요.** 내 것으로 시작하고 싶으면 내 실습 폴더로 복사해서 씁니다 (Codex에 "강사 예시 01을 내 실습1 폴더로 복사해 줘").

| 폴더 | 내용 |
|---|---|
| [실습1_확장프로그램/01_기본-todo](실습1_확장프로그램/01_기본-todo) | 할 일 추가 · 완료 체크 · 삭제 · 남은 개수 |
| [실습1_확장프로그램/02_환율-todo](실습1_확장프로그램/02_환율-todo) | 01 + 환율 계산기 (기준환율 입력 · 스프레드·우대율 · 은행 환율표 붙여넣기 · 「오늘 환율 불러오기」 Frankfurter API) |
| [실습2_홈페이지/팀-소개-페이지](실습2_홈페이지/팀-소개-페이지) | 가상 브릿지팀 소개 페이지 · 로고 · 기획서(PRD) |

확장 프로그램 설치: 주소창에 `chrome://extensions` → 개발자 모드 켜기 → 「압축해제된 확장 프로그램 로드」 → 폴더 선택

> 01 예시에는 일부러 남겨 둔 빈틈이 있어요 (긴 할 일이 넘침, 같은 할 일 두 번). 실습 ③ 검수 때 찾아보세요.
