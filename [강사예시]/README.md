# 강사 예시

수업에서 보여 주는 예제입니다. **이 폴더는 고치지 않아요.** 내 것으로 시작하고 싶으면 내 실습 폴더로 복사해서 씁니다 (Codex에 "강사 예시 01을 내 실습1 폴더로 복사해 줘").

## 실습1 · 확장 프로그램

| 폴더 | 내용 |
|---|---|
| [01_기본-todo](실습1_확장프로그램/01_기본-todo) | 할 일 추가 · 완료 체크 · 삭제 · 남은 개수 |
| [02_메일-todo](실습1_확장프로그램/02_메일-todo) | 01 + 지메일에서 메일을 열면 「+ 할 일에 추가」 버튼이 생겨서 메일 제목을 할 일로 넣어 줌 |
| [03_캐릭터-todo](실습1_확장프로그램/03_캐릭터-todo) | 캐릭터가 오늘 할 일을 말해 주고, 끝내면 "잘했어!" 하고 칭찬해 주는 투두 (빗썸고딕 글꼴, SIL OFL) |
| [04_환율-todo](실습1_확장프로그램/04_환율-todo) | 01 + 환율 계산기 (기준환율 입력 · 스프레드·우대율 · 은행 환율표 붙여넣기 · 「오늘 환율 불러오기」 Frankfurter API) |

설치: 주소창에 `chrome://extensions` → 개발자 모드 켜기 → 「압축해제된 확장 프로그램 로드」 → 폴더 선택

> 03 예시의 캐릭터 그림은 수업 시연용이에요. 캐릭터의 저작권은 원작자에게 있으니, 내 결과물에는 **직접 만들거나 AI로 새로 만든 그림**을 써 주세요.

> 01 예시에는 일부러 남겨 둔 빈틈이 있어요 (긴 할 일이 넘침, 같은 할 일 두 번). 실습 ③ 검수 때 찾아보세요.
