Google Calendar 연결

Calendar API는 기본 사용 범위에서 무료예요. 이 확장 프로그램의 연결 설정은 결제 계정이나 유료 서버 없이 진행할 수 있어요. 기본 할당량을 늘리는 유료 옵션은 신청할 필요가 없어요. Google 무료 사용 범위 안내

처음 연결하는 방법

최초 한 번 Google Cloud 설정이 필요해요. 아래 ID는 이 확장 프로그램의 ID예요.

  1. Google Cloud Console에서 프로젝트를 만들거나 선택하고, API 라이브러리에서 Google Calendar API를 사용 설정하세요.
  2. Google Auth Platform에서 브랜딩과 잠재고객을 설정하세요. 외부 앱을 테스트 모드로 쓴다면 테스트 사용자에 캘린더를 사용할 Google 계정을 추가하세요. 회사 계정은 조직의 앱 연결 정책에 따라 관리자 승인이 필요할 수 있어요.
  3. 데이터 액세스에 https://www.googleapis.com/auth/calendar.calendarlist.readonly와 https://www.googleapis.com/auth/calendar.events 범위를 추가하세요.
  4. 클라이언트에서 OAuth 클라이언트를 만들고 애플리케이션 유형을 Chrome 확장 프로그램으로 선택하세요. 항목 ID / 애플리케이션 ID에는 위의 확장 프로그램 ID를 입력하세요.
  5. 발급된 …apps.googleusercontent.com 클라이언트 ID를 복사하세요. todo-extension/manifest.json을 메모장으로 열고 oauth2.client_id의 000000000000-replace-me.apps.googleusercontent.com을 발급된 값으로 바꿔 저장하세요.
  6. Chrome 주소창에 chrome://extensions를 입력하고 Soy Todo List 카드의 새로고침 버튼을 누르세요. 설정 창을 다시 열어 Google 연결을 누르고 Google 동의 화면에서 권한을 허용하세요.
  7. 아래에서 개인과 팀 캘린더를 확인하고 설정 저장을 누르세요. 팀 캘린더는 연결한 계정에 일정 쓰기 권한이 있어야 표시돼요.

테스트 모드에서는 일정 기간 후 Google 연결을 다시 해야 할 수 있어요. 확장 프로그램 폴더 위치를 바꾸거나 재설치해 ID가 바뀌면 OAuth의 항목 ID도 맞춰 주세요.
