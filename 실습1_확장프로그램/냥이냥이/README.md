# 오늘 할 일 작성기

## 한 줄 소개

달력에서 날짜별 할 일을 관리하고 외화 금액을 원화로 계산하는 크롬 확장 프로그램입니다.

## 누구를 위해 만들었나요

확장 프로그램 만들기를 연습하는 수강생을 위한 실습용입니다.

## 주요 기능

- 달력에서 날짜를 골라 할 일을 추가하고 완료 표시하거나 삭제할 수 있습니다.
- 남은 할 일 개수와 모든 할 일을 마친 날을 보여 주며, 할 일은 브라우저에 저장합니다.
- 환율을 직접 입력하거나 공개 기준환율을 불러와 외화를 살 때와 팔 때의 원화 금액을 계산합니다.
