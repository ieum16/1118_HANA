# 오늘 할 일 작성기

폭 400px의 한국어 크롬 확장 프로그램입니다. 할 일 추가, 완료 체크, 삭제, 남은 개수, 추가 시각(YYMMDD hhmm), 개별 마감일을 지원합니다.

마감 날짜 칸을 누르면 캘린더에서 날짜를 선택할 수 있습니다. 당일 / 2일 / 3일 / 7일 / 30일 버튼은 오늘을 기준으로 마감일을 설정합니다. 해제를 누르거나 날짜를 비우면 마감 없이 추가됩니다. 목록에서도 날짜 칸을 눌러 마감일을 변경할 수 있습니다. 마감일은 현지 날짜 기준으로 D-5, D-Day, D+1처럼 자동 갱신됩니다.

아이콘은 초록색 배경에 검정색 ‘오’ 글자입니다. 목록은 chrome.storage.local에 자동 저장되며 팝업이나 크롬을 다시 열어도 유지됩니다. 확장 프로그램을 제거하면 저장한 목록도 삭제됩니다. 공백만 있는 할 일은 추가할 수 없습니다.

## USD/KRW 자동 환율

할 일 목록 아래에 네이버가 제공하는 하나은행 USD/KRW 매매기준율과 현찰 살 때·팔 때 환율을 표시합니다. 1 USD당 원화입니다. 살 때·팔 때는 사용자가 달러 현찰을 사고파는 방향이며, 은행 관점의 매수·매도와 반대입니다. 송금 환율이나 외환시장 호가를 표시하는 기능은 아닙니다.

- 공개 JSON 조회: https://api.stock.naver.com/marketindex/exchange/FX_USDKRW/prices?page=1&pageSize=10
- 원본 화면: https://m.stock.naver.com/marketindex/exchange/FX_USDKRW
- 응답 검증일: 2026-11-19. API 키나 로그인은 사용하지 않습니다. 네이버 웹 화면용 공개 응답이며 공식 개발자 계약 API는 아니므로 형식이나 제공 여부가 바뀔 수 있습니다.
- 팝업을 열 때와 팝업이 열린 동안 60초마다 새로 조회합니다. 새로고침 버튼으로 즉시 조회할 수도 있습니다. 팝업을 닫으면 조회하지 않습니다. 매 요청은 12초 후 시간 초과 처리합니다.
- 원본 응답의 최신 날짜 행에서 closePrice(기준), cashBuyValue(고객이 달러 살 때), cashSellValue(고객이 달러 팔 때)를 함께 사용합니다. 다른 시점의 기준율과 매수·매도율을 혼합하거나 스프레드로 역산하지 않습니다.
- 응답에 고시 날짜만 있으므로 고시 기준일과 실제 조회 시각(한국 시간)을 따로 표시합니다. 은행 고시에 따라 갱신되며, 휴일·장외 시간에는 최근 영업일 값일 수 있습니다. 거래소 스트리밍 호가가 아닙니다.
- 조회 실패 시 마지막 성공 값을 ‘저장된 이전 환율’로 명확히 표시합니다. 저장값도 없으면 숫자 대신 —를 표시합니다. 오래된 값을 실시간 값으로 표시하지 않습니다.
- 선택적으로 달러 금액을 넣으면 원본 매수·매도 환율을 곱해 낼 원화·받을 원화를 보여 줍니다. 최종 금액은 원 단위로 반올림합니다.
- 수동 기준환율 입력, 스프레드·우대율 입력, 은행 표 붙여넣기는 자동 조회 화면으로 교체했습니다. 기존 할 일과 달러 입력 금액은 유지합니다. 기존에 직접 입력한 환율은 자동 조회값으로 사용하지 않습니다.
- host_permissions는 https://api.stock.naver.com/* 하나만 추가했습니다. 조회 요청에 로그인 쿠키를 보내지 않으며 입력한 할 일이나 금액도 전송하지 않습니다.

자동 검증(Node.js 설치 환경): node tests/fx.test.cjs

## 업데이트 적용

chrome://extensions 에서 오늘 할 일 작성기의 새로고침(↻)을 누른 뒤 팝업을 다시 엽니다. 네이버 환율 접속 권한 승인이 표시되면 허용해야 조회할 수 있습니다. 기존 목록을 유지하려면 확장 프로그램을 삭제하지 말고 새로고침하세요.

## 크롬 설치 방법

1. 크롬 주소창에 chrome://extensions 를 입력하고 오른쪽 위 개발자 모드를 켭니다.
2. 압축해제된 확장 프로그램을 로드합니다를 누르고 이 todo-extension_swp 폴더를 선택합니다.
3. 도구 모음의 확장 프로그램(퍼즐)에서 오늘 할 일 작성기를 고정한 뒤 아이콘을 누릅니다.

공식 설치 안내: https://developer.chrome.com/docs/extensions/get-started/tutorial/hello-world#load-unpacked
