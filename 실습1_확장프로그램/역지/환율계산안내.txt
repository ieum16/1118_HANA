환율 계산기

할 일 목록 아래에서 사용할 수 있습니다. 통화를 고르고 기준환율과 외화 금액을 입력하세요.
JPY는 기본 100엔당 원화 환율입니다. 예를 들어 기준환율 900원, 외화 금액 10,000엔이면 기준환산액은 90,000원입니다.
JPY·VND·IDR은 기본 100단위, 그 외 지원 통화는 기본 1단위입니다. 은행 표의 단위가 다르면 기준 단위를 바꿔 주세요.

계산 방식
- 기준환산액 = 외화 금액 ÷ 기준 단위 × 기준환율
- 살 때 적용환율 = 기준환율 × (1 + 살 때 스프레드% ÷ 100 × (1 - 우대율% ÷ 100))
- 팔 때 적용환율 = 기준환율 × (1 - 팔 때 스프레드% ÷ 100 × (1 - 우대율% ÷ 100))
- 살 때/팔 때 원화 = 외화 금액 ÷ 기준 단위 × 해당 적용환율
- 화면의 원화는 1원 단위로 반올림하며, 실제 거래의 별도 수수료나 은행별 반올림 방식은 포함하지 않습니다.
- 직접 입력한 기준환율 또는 버튼으로 불러온 최신 발표 환율로 계산합니다.

오늘 환율 불러오기
- 버튼을 누를 때만 Frankfurter의 유럽중앙은행(ECB) 기준 JPY→KRW 환율을 조회합니다.
- 1엔당 환율을 100배 하여 100엔당 기준환율로 채우고, 통화를 JPY로 전환합니다.
- 기존 외화 금액, 스프레드, 우대율과 다른 통화의 환율은 유지합니다.
- API가 제공한 환율 기준일, 불러온 날짜(한국 시간), ‘유럽중앙은행 기준 · 은행 고시와 다름’을 표시합니다.
- 주말·공휴일이나 발표 전에는 환율 기준일이 오늘보다 이전일 수 있습니다.
- 실패하면 ‘환율을 가져오지 못했어요’를 표시하고 기존 값은 유지합니다.
- 불러온 환율과 날짜는 입력값과 함께 저장합니다. 환율을 직접 바꾸거나 은행 표를 적용하면 ECB 출처 표시를 해제합니다.
- 외부 접근 권한은 https://api.frankfurter.dev/* 로 제한합니다. API 키는 필요하지 않습니다.
- API 문서: https://frankfurter.dev/
- 사용 주소: https://api.frankfurter.dev/v2/providers/ecb/rate/JPY/KRW

글꼴
- 화면 글꼴은 배민 주아체입니다. 글꼴 파일을 함께 포함하여 오프라인에서도 표시합니다.

은행 표 가져오기
1. ‘은행 환율표 붙여넣기’를 열고, 은행 표의 통화코드와 매매기준율 제목을 함께 복사하여 붙여넣으세요.
2. ‘표 읽기’를 누르면 통화별 기준 단위와 환율을 확인할 수 있습니다.
3. 맞으면 ‘확인 후 적용’을 누르세요. 통화를 바꾸면 해당 통화의 환율이 채워집니다.

지원 형식: 웹페이지에서 복사한 HTML 표, 탭으로 구분된 표, 쉼표로 구분된 CSV, |로 구분된 표, 통화코드와 기준환율만 적은 간단한 줄.
예:
JPY(100) 900
USD 1,400
EUR 1,500

여러 금액 열이 있으면 매매기준율 제목으로 구분합니다. 구분할 수 없는 행은 채우지 않습니다.
현찰 사실 때/파실 때 제목이 있으면 매매기준율 대비 차이를 계산하여 통화별 스프레드도 채웁니다.
붙여넣은 표에 우대가 이미 적용된 환율이 있으면 우대가 중복되지 않도록 우대율을 확인하세요.
적용 시 같은 통화의 기준환율·단위와 읽은 스프레드를 덮어씁니다. 기존 외화 금액과 통화별 우대율은 유지합니다.

저장
통화 선택, 외화 금액, 통화별 기준환율·단위·스프레드·우대율, 붙여넣은 텍스트를 현재 크롬 프로필에 저장합니다.
‘입력값이 자동 저장됐어요’를 확인하면 창을 닫았다 열어도 복원됩니다.
저장 실패가 표시되면 ‘다시 저장’을 누르세요.
기존 할 일 목록은 별도의 저장 항목을 사용합니다.
