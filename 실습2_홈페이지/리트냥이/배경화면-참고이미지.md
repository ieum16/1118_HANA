# 리트냥이 홈페이지 배경 참고 이미지

2026년 11월 19일 IDA입시연구소가 예고한 수능 국어 공개 검증 방송과 관련된 이미지 두 장을 모았다. 방송은 시작됐고, 예고한 당사자의 국어 문제풀이는 진행되지 않았다. [IDA입시연구소 유튜브 방송 주소](https://www.youtube.com/live/zGWhfOF1nes) · [당일 뉴시스 보도](https://m.newsis.com/view/NISX20261119_0003874248)

## 후보 1 · 방송 시작 전 화면

![IDA입시연구소 유튜브 방송의 사전 화면](https://image.edaily.co.kr/images/photo/files/NP/S/2026/11/PS26111900215.jpg)

방송 예고 기사에 실린 IDA입시연구소 유튜브 캡처. 첫 화면을 구성할 때 방송 제목과 배경의 배치, 제목을 읽기 쉽게 만드는 대비를 참고할 수 있다. [이데일리 기사와 이미지 출처](https://www4.edaily.co.kr/News/Read?mediaCodeNo=257&newsId=01643286645647360)

## 후보 2 · 당일 생중계 진행 화면

![IDA입시연구소 수능 국어 공개 검증 생중계에서 진행자가 방송하는 모습](https://img1.newsis.com/2026/11/19/NISI20261119_0002296213_web.jpg?rnd=20261119084835)

당일 진행자가 방송을 이어가는 장면이다. 스튜디오 화면의 구도와 조명, 송출 화면의 분위기를 참고하기 좋다. [뉴시스 기사와 이미지 출처](https://m.newsis.com/view/NISX20261119_0003874248)

두 후보는 원문 이미지 링크로 열리는 디자인 참고 자료다. 홈페이지 배경으로 원본을 사용할 경우 이미지와 방송 화면의 사용 권한을 확인한다.

## 홈페이지 적용

유튜브 원본에서 IDA입시연구소 채널과 다시보기 플레이어를 직접 확인했다. 현재 영상 제목은 최초 예고 보도와 달라졌으며, 홈페이지에는 유튜브 영상 페이지의 공식 썸네일을 배경으로 사용한다. [유튜브 원본](https://www.youtube.com/live/zGWhfOF1nes)

`index.html`의 전체 배경에 적용하고 페이지 하단에 출처를 표시한다. 제목 뒤에는 어두운 그라데이션을 깔고, 작은 화면에서는 썸네일의 중심을 오른쪽으로 옮겨 글자 대비를 높인다.
