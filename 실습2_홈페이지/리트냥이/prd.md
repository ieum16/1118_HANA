# 리트냥이 팀 소개 페이지 PRD

리트냥이는 가상 지도의 경로 퍼즐을 소개하는 실습용 팀이다. 한 줄 소개는 ‘도주경로 찾기’다.

| 메뉴 | 콘텐츠 |
|---|---|
| 소개 | 한 줄 소개, 팀 설명, 로고, 도구 보기 버튼 |
| 하는 일 | 가상 지도 만들기, 경로 퍼즐 설계, 길찾기 화면 다듬기 |
| 제공 솔루션 | 광진구·송파구·강동구 이름을 붙인 가상 지도에서 경로를 탐색하고 이동 횟수를 확인하는 분석기 |
| 문의 | 리트냥이 지도 탐색팀 라온과 예시 이메일 `raon.ritnyangi@example.com` |

짙은 녹색 배경에 연두색 안경과 헤드셋을 쓴 가상 3D 지도 분석가 로고를 배치한다. 홈페이지 파일은 `index.html`, 로고는 `images/logo.png`를 사용한다. 작은 화면에서는 카드가 한 열로 배치되고 모바일 메뉴는 버튼으로 열고 닫을 수 있어야 한다.
