# 리트냥이 팀 홈페이지 제작 계획서

1. 상단 메뉴를 소개, 하는 일, 도구, 문의에 연결한다.
2. 소개에 ‘도주경로 찾기’ 문구와 가상 3D 지도 분석가 로고를 표시한다.
3. 가상 지도 설계, 숨은 통로 발견, 경로 검증을 업무 카드로 소개한다. 제공 솔루션에는 광진구·송파구·강동구 보드를 선택할 수 있는 가상 경로 분석기를 배치한다.
4. 모바일에서 메뉴를 접고, 업무 카드를 화면 폭에 따라 3열, 2열, 1열로 배치한다.
5. 브라우저에서 `index.html`을 열고 링크, 로고, 375px 화면과 키보드 메뉴를 확인한다.
