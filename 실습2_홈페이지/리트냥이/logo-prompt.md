# 리트냥이 로고 제작 프롬프트

~~~text
가상 지도에서 길을 탐색하는 퍼즐 팀 '리트냥이'의 로고를 만들어 줘.
검녹색(#101414) 정사각형 배경에 연두색(#E6F38A) 고양이 얼굴 아이콘을 그려 줘.
고양이 얼굴 주변에 짧은 점선과 체크포인트 점 하나를 배치해 지도 퍼즐을 표현해 줘.
아이콘 아래에 한글 팀 이름 '리트냥이'를 정확히 넣어 줘. 글자는 굵은 산세리프체로 부탁해.
평면 색과 단순한 윤곽을 사용하고, 작게 보일 때도 읽히도록 여백을 남겨 줘.
~~~
