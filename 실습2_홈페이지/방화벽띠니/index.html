요청 목적, 필요한 기간, 적용 범위와 예상 영향을 정리하세요. 업무별 카드의 준비물을 참고하면 좋습니다.

공식 절차 확인

알아두세요이 페이지에는 실제 접수 기능이 없습니다. 고객 정보, 계정 비밀번호, 내부 구성 정보는 공개 페이지에 남기지 마세요.

어떤 업무로 요청해야 할지 모르겠어요.

먼저 ‘하는 일’의 설명과 요청 예시를 살펴보세요. 항목을 고르기 어렵다면 하려는 작업, 현재 겪는 현상, 필요한 시점을 정리해 공식 문의 경로로 확인하면 됩니다.

방화벽과 WAF는 어떻게 다른가요?

방화벽은 네트워크 연결의 허용 여부를 관리하고, WAF는 웹 요청을 분석해 웹 서비스를 겨냥한 공격을 차단합니다. 목적에 따라 함께 검토할 수 있습니다.

요청 전에 무엇을 준비해야 하나요?

목적, 필요한 기간, 적용 범위, 영향받는 서비스를 먼저 정리해 주세요. 업무별로 필요한 내용은 위 카드의 ‘요청 전 준비물’에서 확인할 수 있습니다. 실제 제출 항목은 소속 조직의 양식을 따릅니다.

긴급 장애도 이 페이지로 접수하나요?

이 페이지는 실제 대응 채널이 아닙니다. 긴급 장애나 보안 사고가 의심될 때는 소속 조직의 공식 긴급 대응 절차를 이용하세요.
