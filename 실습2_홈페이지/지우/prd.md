# 비대면법인프로세스팀 소개 페이지 PRD

| 항목 | 내용 |
|---|---|
| 문서 상태 | 초안 v0.1 |
| 작성일 | 2026-11-19 |
| 작성자 | 지우 |
| 관련 문서 | [로고 프롬프트](logo-prompt.md), [제작 계획서](build-plan.md) |

PRD는 페이지를 누구를 위해 만들고 어떤 내용을 담을지 정리한 기획서예요.

## 1. 배경 · 문제

영업점 담당자와 본부 협업부서가 법인 비대면 여수신, 결제성 여신 상품, 영업점 문의 응대 중 어떤 업무를 팀이 맡는지 한 번에 확인할 수 있는 페이지가 필요해요. 반복되는 질문은 FAQ에 모아, 자주 찾는 답을 업무 소개와 같은 화면에서 볼 수 있게 해요.

## 2. 목표와 성공 기준

| 목표 | 확인 방법 |
|---|---|
| 팀 역할을 빠르게 이해한다 | 처음 보는 사람이 첫 화면과 업무 카드만 읽고 팀의 주요 업무 3가지를 설명할 수 있는지 확인해요. |
| 자주 묻는 질문에 대한 첫 안내를 찾는다 | 상단이나 첫 화면의 FAQ 링크를 눌러 해당 질문과 다음 행동을 확인할 수 있는지 점검해요. |
| 추가 문의와 협업에 필요한 정보를 안다 | 문의 안내에서 어떤 유형의 문의를 준비하고 무엇을 적을지 확인할 수 있는지 점검해요. |

## 3. 대상 사용자

| 대상 | 궁금한 것 | 페이지가 주는 답 |
|---|---|---|
| 영업점 담당자 | 비대면 절차를 어디서 확인하는지, 신청이 막히거나 상품 문의가 있을 때 어떻게 시작하는지 | 업무 유형별 설명, FAQ, 문의 시 준비 항목 |
| 본부 협업부서 | 팀의 담당 범위와 협업을 요청할 때 공유할 내용 | 주요 업무 3가지, 협업 요청 안내 |

## 4. 범위

팀 소개, 주요 업무 카드 3개, FAQ 3개, 문의·협업 안내를 한 장에 담아요. 모의 화면에서는 문의 채널을 예시 값으로 표시하고 FAQ와 문서명은 확인 가능한 내용에 맞춰 완성해요.

## 5. 정보 구조

| 메뉴 | 섹션 ID | 담는 내용 |
|---|---|---|
| 팀 소개 | `#intro` | 팀 이름, 한 줄 소개, FAQ 바로가기 |
| 주요 업무 | `#work` | 법인 비대면 여수신 프로세스, 결제성 여신 상품, 영업점 문의 응대 |
| 자주 묻는 질문 | `#faq` | 질문 3개와 펼쳐 읽는 답변 |
| 문의·협업 안내 | `#contact` | 문의별 준비 항목과 협업 요청 방법 |

## 6. 화면 구성

1. 헤더에 팀 이름과 메뉴 네 개를 표시해요.
2. 첫 화면에 한 줄 소개와 **자주 묻는 질문 보기** 버튼을 배치해요.
3. 주요 업무 세 가지를 같은 형식의 카드로 보여 줘요.
4. FAQ는 질문을 먼저 보여 주고 선택하면 해당 답변이 펼쳐져요.
5. 마지막에 문의와 협업 요청 시 적을 내용을 보여 줘요.

## 7. 콘텐츠 상세

### 7-1. 한 줄 소개

- 제목 **비대면법인프로세스팀**
- 소개 문구 **법인 고객의 비대면 여수신 절차와 결제성 여신 상품을 기획·운영하고, 영업점 업무를 지원합니다.**
- 버튼 **자주 묻는 질문 보기**

### 7-2. 업무 카드

| 업무 | 설명 | 요청 예시 |
|---|---|---|
| 법인 비대면 여수신 프로세스 | 법인 고객이 비대면으로 예금·대출 업무를 진행하는 절차를 기획하고 운영해요. | 비대면 신청 과정이나 절차 개선에 관한 문의 |
| 결제성 여신 상품 | 결제성 여신 상품을 기획하고 운영해요. | 상품 운영 기준이나 협업 범위에 관한 문의 |
| 영업점 문의 응대 | 관련 절차와 상품에 대한 영업점 문의를 확인하고 안내해요. | 신청 중 막힌 단계나 안내 문구에 관한 문의 |

### 7-3. 자주 묻는 질문

아래 답변은 **기획 초안**이에요. 정확한 문서명과 문의 채널을 확인한 뒤 보완해요.

| 질문 | 답변 초안 |
|---|---|
| 법인 비대면 여수신 절차는 어디서 확인하나요? | 예금과 대출 중 문의 유형을 먼저 구분해 주세요. 적용 절차를 확인할 수 있는 업무 안내 문서의 이름과 위치는 확인 후 이곳에 표시할 예정이에요. |
| 비대면 신청이 안 되면 어떻게 하나요? | 진행이 멈춘 단계와 화면에 표시된 오류 문구를 확인해 주세요. 추가 문의 시에는 고객 식별정보를 뺀 상태로 신청 단계와 오류 문구를 전달해 주세요. |
| 결제성 여신 상품은 어디에 문의하나요? | 상품명과 문의 내용을 적어 문의·협업 안내의 채널을 이용해 주세요. 실제 문의 채널은 확인 후 연결할 예정이에요. |

### 7-4. 문의·협업 안내

- **영업점 문의** 업무 또는 상품명, 문의를 하게 된 단계, 확인받고 싶은 내용을 적어요.
- **본부 협업 요청** 협업 목적, 요청 범위, 희망 일정을 적어요.
- **문의 채널** 미리보기에는 예시 주소 `team@example.com`을 표시해요. 실제 채널과 응답 시간은 확인 후 반영해요.

## 9. 반응형 · 접근성

- 1280px 데스크톱부터 375px 휴대폰까지 가로 스크롤 없이 읽을 수 있게 해요.
- 주요 업무는 데스크톱 3열, 태블릿 2열, 휴대폰 1열로 표시해요.
- 휴대폰 메뉴와 FAQ를 키보드로 열 수 있게 하고, 선택 위치를 뚜렷하게 표시해요.
- 본문과 버튼 글자는 대비를 확보하고, 팀을 식별하는 이미지에는 대체 텍스트를 넣어요.

## 10. 기술 조건

`index.html` 한 파일에 스타일과 동작을 넣고 브라우저에서 바로 열 수 있게 해요. FAQ는 브라우저의 기본 펼침 요소를 사용해요.
