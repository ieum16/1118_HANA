# 비대면법인프로세스팀 소개 페이지 제작 계획서

## 1. 만들 것

[기획서](prd.md)를 바탕으로 영업점 담당자와 본부 협업부서가 업무 범위와 FAQ를 빠르게 확인하는 한 장짜리 팀 소개 페이지를 만들어요.

## 2. 파일 구조

```
team-page/
├─ prd.md
├─ logo-prompt.md
├─ build-plan.md
├─ index.html          제작 확인 후 생성
└─ images/
   ├─ logo.png         로고 파일을 받으면 추가
   └─ reference.png    참고 화면을 받으면 추가
```

## 3. 준비물

| 항목 | 상태 | 화면에 적용할 방식 |
|---|---|---|
| 팀 이름, 메뉴, 업무 카드, FAQ 질문 | 확인 | 기획서에 적힌 순서와 문구로 반영 |
| FAQ 답변과 업무 문서 위치 | 초안 | 확인된 안내와 다음 행동을 먼저 보여 주고, 문서 위치는 확인 후 추가 |
| 문의 채널과 응답 시간 | 확인 예정 | 예시 주소를 명시하고 실제 운영 안내는 확인 후 반영 |
| 로고와 참고 화면 | 선택 | 팀 이름 글자 표시와 기획서의 청록색으로 시작 |

## 4. 만드는 순서

| 단계 | 할 일 | 확인 방법 |
|---|---|---|
| 1 | 헤더와 네 섹션의 구조를 만들어요. | 메뉴를 눌러 각 섹션으로 이동해요. |
| 2 | 청록색과 흰색을 적용하고, 팀 소개와 FAQ 바로가기를 배치해요. | 첫 화면에서 팀 이름, 한 줄 소개, 버튼을 읽어 봐요. |
| 3 | 업무 카드 3개를 배치하고 FAQ 답변을 펼칠 수 있게 만들어요. | 요청한 제목과 질문이 있는지 확인하고 키보드로 FAQ를 열어요. |
| 4 | 영업점 문의와 본부 협업에 필요한 항목을 표시해요. | 예시 채널 표기와 실제 확인이 필요한 항목을 구분해요. |
| 5 | 휴대폰 메뉴와 카드 배치를 조정해요. | 375px, 태블릿 폭, 1280px에서 배치와 가로 스크롤을 확인해요. |
| 6 | 미리보기와 주요 동작을 확인한 뒤 결과를 보여 드려요. | [기획서의 완료 기준](prd.md#12-완료-기준)을 하나씩 점검해요. |

## 5. 섹션별 구현

| 섹션 | 데스크톱 | 휴대폰 |
|---|---|---|
| 헤더 | 팀 이름과 상단 메뉴 | 메뉴 열기 버튼 |
| 소개 | 넓은 여백과 왼쪽 정렬로 메시지 강조 | 소개와 버튼을 세로 배치 |
| 주요 업무 | 동일한 형태의 카드 3열 | 카드 1열 |
| FAQ | 질문 행을 눌러 답변 펼치기 | 질문 전체를 눌러 펼치기 |
| 문의·협업 안내 | 영업점 문의와 본부 협업을 나란히 배치 | 문의와 협업을 순서대로 표시 |

## 6. 결과 확인

`index.html`을 브라우저에서 열고 FAQ 바로가기, 모바일 메뉴, 질문 펼치기를 직접 확인해요. 데스크톱과 휴대폰 미리보기를 함께 보고 문구나 색을 조정해요.
