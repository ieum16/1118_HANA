# 비대면법인프로세스팀

## 한 줄 소개

법인 고객의 비대면 여수신 절차와 결제성 여신 상품을 기획·운영하고 영업점 업무를 지원하는 팀 소개 페이지예요.

## 누구를 위해 만들었나요

영업점 담당자와 본부 협업부서가 팀의 역할을 파악하고, 업무 중 자주 묻는 질문에 대한 안내를 바로 찾을 수 있도록 만들었어요.

## 페이지 구성

- 팀 소개와 별돌이가 등장하는 첫 화면
- 업무별 바로가기와 주요 업무 카드 세 개
- 자주 묻는 질문 게시판
- 업무 자료 모음
- 문의·협업 안내와 문의 문구 작성·복사 양식
- 같은 브라우저에서 체험하는 게스트·관리자 시연용 채팅
