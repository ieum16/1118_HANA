```

메인 색은 차분한 청록색 #007C78, 보조 색은 짙은 청록색 #005B57.

작게 줄여도 알아보기 쉽게 선과 면을 단순하게 구성하고, 한글 팀 이름은 “비대면법인프로세스팀”으로 정확히 넣어 줘.
전체 분위기는 단정하고 신뢰감 있게, 기업금융 팀의 안내 페이지에 어울리게 만들어 줘.
```
