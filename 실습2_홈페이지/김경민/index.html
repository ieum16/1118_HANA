정기 보고에 필요한 숫자를 모아 정해진 양식에 옮기는 일을 줄입니다.

요청 예시“매주 같은 양식의 보고서에 표를 옮기는 과정을 자동화하고 싶어요.”

엑셀 데이터 정리

여러 표의 형식을 맞추고, 중복을 정리하고, 필요한 항목만 모으는 일을 줄입니다.

요청 예시“서식이 다른 엑셀 표를 같은 열 순서로 정리하고 싶어요.”

사내 업무 도구 제작

자주 쓰는 계산, 문구 작성, 확인 절차를 간단한 웹 도구로 만듭니다.

요청 예시“조건을 고르면 안내 문구가 완성되는 도구가 필요해요.”

우리가 만든 도구

출근부터 퇴근까지, 직장 생활을 돕는 도구 아이디어를 소개합니다.

출근 커피 배달

출근하면 그날의 날씨에 맞춰 커피 메뉴를 골라 내 자리로 배달해 줍니다.

점심 알림과 구내식당 주문

점심시간이 되면 PC 알림을 띄우고, 오늘 구내식당 메뉴 중 날씨에 어울리는 메뉴를 추천합니다. 알림에서 추천 메뉴 하나를 고르면 구내식당에 자동으로 주문됩니다.

퇴근 알림과 경로 추천

오후 6시가 되면 PC로 퇴근 시간을 알려줍니다. 집을 목적지로 설정해 자차와 대중교통 각각에 최적의 퇴근길을 추천합니다.
