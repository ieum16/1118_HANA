## 한 줄 소개

직원들의 반복 업무를 줄여 전사 업무 효율을 높이는 가상의 업무 자동화 팀입니다.

## 누구를 위해 만들었나요

전사 임직원을 위해 만들었습니다. TimeSaver가 지원하는 업무와 도구 아이디어를 살펴보고, 자동화가 필요한 일을 요청서로 정리할 수 있습니다.

## 페이지 구성

- 팀 소개
- 하는 일
- 우리가 만든 도구와 단계별 사용 예시
- 자동화 요청 안내와 요청서 작성 화면
