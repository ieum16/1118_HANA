## 1. 배경과 문제

TimeSaver는 직원들의 반복 업무를 줄여 전사 업무 효율을 높이는 팀이다. 전사 임직원이 어떤 업무를 자동화해 달라고 요청할 수 있는지 알아보고, TimeSaver가 공개한 도구를 한곳에서 찾을 수 있도록 팀 소개 페이지를 만든다.

## 2. 목표와 성공 기준

| 목표 | 확인 방법 |
|---|---|
| 임직원이 TimeSaver의 역할을 이해한다 | 사내 시범 검토에서 방문자가 1분 안에 팀의 역할과 요청할 수 있는 업무 사례 하나를 설명할 수 있는지 확인한다. (제안) |
| 반복 업무 자동화 요청을 시작할 수 있다 | 방문자가 첫 화면에서 요청 안내까지 이동할 수 있는지 확인한다. 접수 채널을 확정한 뒤 실제 접수 경로도 점검한다. |
| 공개 도구를 찾을 수 있다 | 첫 화면과 메뉴에서 도구 섹션으로 이동할 수 있는지 확인한다. 첫 버전에는 ‘준비 중’을 표시하고, 도구가 공개되면 이름과 용도, 실행 링크를 제공한다. |

## 3. 대상 사용자

| 대상 | 궁금한 점 | 페이지가 제공하는 정보 | 기대 행동 |
|---|---|---|---|
| 전사 임직원 | 내 반복 업무도 자동화할 수 있나? | 지원 업무 세 가지, 요청 예시, 접수 안내 | 자동화하려는 업무를 정리하고 접수 채널이 열리면 요청한다. |
| 전사 임직원 | 지금 써 볼 수 있는 도구가 있나? | 도구 공개 상태와 공개 이후의 도구 링크 | 도구 영역을 찾아보고, 공개된 도구를 열어 써 본다. |

## 4. 첫 버전 범위

팀 소개, 업무 카드 3개, 도구 준비 상태, 자동화 요청 안내를 한 페이지에 담는다. 자동화 요청은 접수 채널 확정 후 해당 채널로 연결한다. 로그인, 페이지 내 접수 폼, 요청 현황 관리, 도구 자체 개발은 후속 범위다.

## 6. 화면 구성

상단 메뉴 → 팀 소개 → 하는 일 → 우리가 만든 도구 → 자동화 요청 → 푸터 순서로 배치한다. 첫 화면에 ‘자동화 요청 안내’ 버튼과 ‘도구 보기’ 링크를 둔다. (제안)

## 7. 콘텐츠

### 팀 소개

- 제목은 “반복 업무를 줄이는 TimeSaver”.
- 보조 문구는 “직원들의 반복 업무를 줄여 전사 업무 효율을 높입니다.”

### 하는 일

| 업무 | 설명 | 요청 예시 |
|---|---|---|
| 반복 보고서 작성 자동화 | 정기 보고에 필요한 숫자를 모아 정해진 양식에 옮기는 일을 줄입니다. | “매주 같은 양식의 보고서에 표를 옮기는 과정을 자동화하고 싶어요.” |
| 엑셀 데이터 정리 | 여러 표의 형식을 맞추고, 중복을 정리하고, 필요한 항목만 모으는 일을 줄입니다. | “서식이 다른 엑셀 표를 같은 열 순서로 정리하고 싶어요.” |
| 사내 업무 도구 제작 | 자주 쓰는 계산, 문구 작성, 확인 절차를 간단한 웹 도구로 만듭니다. | “조건을 고르면 안내 문구가 완성되는 도구가 필요해요.” |

### 우리가 만든 도구

‘준비 중’ 카드를 한 장 표시한다. 공개할 도구가 생기면 카드에 이름, 용도, 도구 열기 링크를 추가한다.

### 자동화 요청

요청을 준비할 때는 ‘어떤 일을 얼마나 자주 하는지’, ‘지금 어떤 방식으로 처리하는지’, ‘어떤 결과를 원하는지’를 적도록 안내한다. (제안)

접수 채널을 확정하기 전에는 “자동화 요청 채널은 준비 중입니다.”라고 표시한다. 접수 링크와 예상 응답 시간은 확정 후 안내한다.

| 로고 | 제작한 이미지는 `images/logo.png`에 둔다. 이미지가 준비되기 전에는 T 글자 로고를 사용한다. |
| 참고 이미지 | 현재 제공된 이미지 없음. |

## 9. 반응형과 접근성

업무 카드는 데스크톱 3열, 태블릿 2열, 휴대폰 1열로 배치한다. 640px 미만에서는 접이식 메뉴를 사용한다. 375px 화면에서 가로 스크롤 없이 읽을 수 있어야 한다. 키보드로 메뉴와 링크에 접근할 수 있게 하고, 초점 표시와 충분한 텍스트 대비를 확보한다. 의미 있는 이미지에는 대체 텍스트를 붙인다.

## 10. 기술 조건

CSS와 JavaScript를 `index.html`에 포함한다. 파일을 브라우저에서 직접 열 수 있게 하고, 외부 글꼴을 불러오지 못해도 시스템 글꼴로 표시한다.
