# 역지네 팀 로고 제작 프롬프트

## 실제 생성에 사용한 프롬프트

Codex의 이미지 생성 도구로 만든 결과는 `images/logo.png`에 있다.

```text
Use case: logo-brand. Create a minimalist Korean typographic logo for a website header. The ENTIRE mark must be exactly two separate standalone Korean compatibility jamo arranged horizontally, in this order: ㅇㅈ. First glyph ㅇ is a round outline with a hollow center, and second glyph ㅈ has one flat top horizontal stroke and two diagonals descending from the middle, like standard Korean sans-serif ㅈ (no extra stroke above it). Comfortable gap between characters, same visual height, upright bold sans-serif strokes, solid dark forest green #21483B. Centered square canvas, generous margins, genuine transparent alpha around and inside the glyphs. Pure flat typography. No badge, clouds, illustrations, extra marks, punctuation, gradients, shadows, outlines around the type, or other lettering.
```

## 다시 만들 때

같은 두 글자를 유지하면서 조절할 수 있다.

- 작은 화면에서도 잘 보이도록 두 글자에 같은 굵기를 적용해 줘.
- `ㅇ`과 `ㅈ` 사이의 간격을 조금만 넓혀 줘.
