# 아키기획팀 홈페이지 제작 계획서

## 1. 만들 것
prd.md를 기준으로 팀 소개, 주요 업무, 담당자, 협업 요청을 담는 index.html을 제작한다.

## 2. 파일 구성
- prd.md — 페이지 기획서
- logo-prompt.md — 로고 제작 및 수정 프롬프트
- build-plan.md — 제작과 확인 순서
- images/logo.png — 생성한 팀 로고
- index.html — 기획 검토 후 제작할 페이지

## 3. 준비 현황
팀명, 규모, 주요 업무, 방문 목적, 분위기를 확인했다.
로고를 생성해 images/logo.png에 저장했다.
기존 team-page 폴더를 작업 위치로 사용한다.
담당자 배정과 연락 채널은 기획서에 예시로 표시했다.

## 4. 만드는 순서
1. 로고와 메뉴가 있는 헤더, 네 섹션, 푸터를 구성한다.
2. 흰색과 밝은 회색 배경, 남색 제목, 차콜 본문을 적용하고 청록색은 주요 버튼과 로고에 포인트로 배치한다.
3. 팀 소개와 두 개의 이동 버튼을 만든다.
4. 주요 업무에서 해당 담당자 정보로 이동할 수 있게 한다.
5. 총 여덟 명의 예시 담당자와 역할을 배치한다.
6. 협업 요청 안내와 요청문 복사 기능을 구현한다.
7. 모바일 메뉴와 반응형 레이아웃을 적용한다.
8. 기능과 화면을 점검하고 결과를 보고한다.

## 5. 섹션별 구성
- 헤더 — 흰 배경에 로고와 네 메뉴, 모바일에서 메뉴 버튼.
- 팀 소개 — 한 줄 설명과 팀 규모, 담당자 및 요청 바로가기.
- 주요 업무 — 밝은 쿨그레이 배경에 다섯 가지 업무와 담당자 연결.
- 담당자 — 팀장 한 명과 팀원 일곱 명의 역할.
- 협업 요청 — 남색 안내 영역과 흰 입력 영역에 요청 순서, 준비 항목, 예시 연락 채널과 청록색 복사 버튼.

## 6. 확인 방법
1280px 및 375px에서 레이아웃과 메뉴 동작을 확인한다.
파일로 연 페이지에서 로고가 표시되는지 확인한다.
키보드 포커스와 모바일 메뉴의 열림 상태를 확인한다.
요청문 복사와 복사 실패 안내를 확인한다.
예시 이름과 예시 연락처가 실제 정보로 오해되지 않게 표시한다.
흰색과 회색이 화면의 주된 면적을 이루고 초록색이 포인트로 사용되는지 확인한다.
제목과 본문, 버튼의 색 대비와 키보드 포커스를 확인한다.

## 7. 구현 상태
소개 홈페이지를 구현하고 사용자 요청에 따라 사업별 공동 예산 작업을 추가했다.

## 8. 공유 예산 추가 파일
- budget.html — 사업 설명, 환경 검토, 기술팀별 품목 입력과 가견적 화면
- budget.js — 화면 상태와 실시간 갱신, 입력 저장 및 내려받기
- budget-core.js — 양쪽에서 재사용하는 입력 검증, 계산, 환경 규칙, 동시 수정 병합
- server.cjs — 공유 API, 실시간 알림, SQLite 저장
- 서버시작.cmd — Windows 서버 실행
- data/budgets.sqlite — 실행 시 생성되는 공유 데이터
- 사용안내.md — 실행과 공동 작업 방법

## 9. 추가 검증
두 브라우저에서 서로 다른 필드를 수정한 뒤 저장하면 양쪽 수정이 보존되는지 확인했다.
같은 필드가 충돌하면 저장이 거절되고 저장 전 입력이 보존되는지 확인했다.
계산 예시 공급가액 9,200,000원, 예비비 920,000원, 부가세 1,012,000원, 총 11,132,000원을 확인했다.
0원 단가, 미입력 품목, 음수 수량, 잘못된 날짜, 과금 개월 오류를 확인했다.
환경 후보 분기, CSV, 320·375·768·1280px 화면, 서버 재시작 후 보존을 확인했다.
다른 PC에서의 접속은 해당 네트워크와 방화벽 설정에서 추가 확인이 필요하다.

## 10. 장비 카탈로그 추가 검증
기존 수량·단가의 보존과 이중화 수량 수정, 신규 사업 기본 품목 8개, 계층 누락 표시를 확인했다.
콤보박스 장비 변경 시 기본 정보와 수량 채우기 및 단가 초기화, 직접 입력 전환, 클라우드 월 과금, 배치 계층 저장을 확인했다.
서버 검증과 동시 수정 병합·충돌, CSV 장비·계층 내보내기, 새로고침 후 보존, 반응형 화면을 확인했다.
