# 아키기획팀 로고 제작 프롬프트

## 기본 프롬프트
아키기획팀의 로고를 만들어 줘.
청록색 #008485 계열, 단순한 아이콘과 정확한 한글 이름 “아키기획팀”을 사용해 줘.
흰 배경의 정사각형에, 건축적인 A 구조와 클라우드 및 연결을 상징하는 다리를 조화롭게 표현해 줘.
차분하고 믿음직하며 신뢰감 있는 아키텍처·전략기획팀의 분위기.
불필요한 장식 없이 작은 크기에서도 알아보기 쉬운 로고.

## 아이콘 아이디어
- 구조적인 A — 아키텍처와 계획의 기반.
- 클라우드 — 클라우드 운영 기획의 업무 영역.
- 다리 — 부서 간 협업과 조율.

## 수정할 때 쓸 문장
- 구름과 다리를 더 단순하게 정리해 줘.
- 아이콘만 따로 투명 배경으로 만들어 줘.
- 한글 이름을 더 가늘고 차분한 글씨로 바꿔 줘.
