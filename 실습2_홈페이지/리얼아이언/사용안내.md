# 아키기획팀 공유 홈페이지 사용 안내

## 실행
Node.js 24가 설치된 PC에서 서버시작.cmd를 더블클릭한다. 이 PC에는 Node.js 24가 설치되어 있다.
실행 창을 켜 둔 상태에서 http://localhost:4174/ 를 연다.
기술팀은 실행 창에 표시된 팀 공유 주소로 접속한다. 같은 서버 주소를 사용해야 같은 사업과 견적을 볼 수 있다.
접속 대상 PC까지의 네트워크 연결과 4174 포트 접근이 필요하다. 다른 PC에서의 실제 연결은 아직 확인하지 않았다.
서버 종료는 실행 창에서 Ctrl+C를 누른다. 다시 실행하면 저장된 사업을 불러온다.

## 사업 등록과 협업
1. 인프라 예산 화면에서 사업명을 입력하고 사업 만들기를 누른다.
2. 작성자 닉네임, 사업 설명, 주사용자와 서비스 대상, 규모와 일정을 입력한다.
3. 쉬운 환경 질문에 답하고 우선 검토 후보와 확인할 사항을 읽는다.
4. 인프라팀·네트워크팀·클라우드플랫폼팀·DB팀에서 각각 품목과 규격·수량·단가를 입력한다.
5. 변경 저장을 누르면 다른 접속자의 화면에도 갱신된다. 접속자는 모든 팀 자료를 공동 편집할 수 있다.
6. 총 가견적과 팀별 합계를 확인하고 CSV 또는 사업 JSON을 내려받는다.

## 계산과 환경 후보
월 단가는 자원 한 개의 월 비용으로 입력한다. 월 비용에 사업의 과금 개월 수를 곱한다.
예비비는 공급가액에 적용하고, 부가세는 공급가액과 예비비의 합계에 적용한다. 원 단위 반올림을 사용한다.
0원 단가도 허용한다. 품목명·수량·단가가 미입력인 항목은 합계에서 제외된다.
사용 날짜와 과금 개월 수는 별도다. 날짜로 기간 채우기를 누르면 시작·종료 월을 포함해 계산한다.
환경 추천은 선택한 답과 공개된 참고 규칙에 따른 검토 후보다. 사업 설명은 담당 팀이 읽도록 공유된다.
기본 구성은 장비별 수량 2개로 채운다. 용량·부하에 따른 추가 수량과 실제 가격은 기술팀이 입력한다.

## 3티어와 장비 선택
새 사업에는 WEB·WAS·DB 서버, SAN 스토리지, L3·L4 스위치, 방화벽, VPN을 각각 2개씩 등록한다. 가격은 빈칸으로 시작한다.
기존 사업은 기존 수량과 단가를 보존한다. 물리서버 기준 기본 구성 추가 버튼으로 필요한 기본 품목을 채울 수 있다.
각 팀의 장비 종류 콤보박스에서 기본 서버, 스토리지, 네트워크·보안 장비, 클라우드 VM, DB 장비 등을 선택한다.
장비를 바꾸면 품목명·기본 검토 규격·배치 계층·수량·과금 방식을 채우고 가격은 새로 입력받는다. 직접 입력을 선택하면 기존 입력값을 수정할 수 있다.
단가는 장비 1개 기준이며 총 수량에 이미 이중화 수량을 포함한다. 비용을 다시 두 배로 곱하지 않는다.
최소 수량은 2개다. N+1 등의 구성에는 3개 이상도 허용한다. 빈 수량은 작성 중인 항목으로 보관할 수 있다.
3티어의 미작성 계층과 최소 수량 미충족 항목을 표시한다. 계층 구성이 작성 중이어도 공유 초안을 저장할 수 있다.
수량과 계층 입력 기준 충족 여부는 실제 고가용성 구성 검증과 함께 사용한다. 독립 장애영역·전원·네트워크 경로·스토리지 복제·DB 절체는 기술팀이 확인한다.
클라우드에서는 서버를 VM으로 바꾸고 배치 계층을 지정한다. 물리서버·VM 및 기존 공용 장비 비용의 중복 반영 여부도 확인한다.
기존 직접 입력 품목은 공통 계층으로 표시하므로 각 품목의 실제 계층을 선택해 준다. 기존 수량 1개는 변경 저장 전에 이중화 수량을 확인한다.
CSV와 JSON에도 3티어·이중화 기준, 장비 종류와 배치 계층을 포함한다.

## 동시 수정
다른 항목을 동시에 고치면 저장 시 합쳐진다. 같은 항목이 다르게 수정되면 충돌을 표시한다.
충돌 시 최신 변경 비교를 열고, 필요하면 내 초안을 JSON으로 내려받은 뒤 최신 내용 불러오기로 다시 검토한다.
최신 내용 불러오기는 저장하지 않은 입력을 버릴지 먼저 확인한다.
변경 저장 전 입력은 다른 사용자의 저장 알림으로 덮어쓰지 않는다.

## 데이터 위치
공유 사업은 서버 PC의 data/budgets.sqlite에 저장된다. 브라우저 기록을 지워도 서버 저장본을 불러올 수 있다.
데이터 사본을 보관할 때는 서버를 종료한 뒤 data 폴더 전체를 복사한다.
사업 JSON 내려받기는 현재 사업의 기록용 사본이며 JSON 복원 화면은 제공하지 않는다.
data 폴더는 .gitignore로 깃허브 업로드 대상에서 제외했다.
