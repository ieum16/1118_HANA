# 집안일 쉼표 페이지 제작 계획서

## 1. 만들 것

prd.md를 기준으로 한 장짜리 팀 소개 페이지를 제작한다. 화면은 공감되는 소개, 개선할 집안일과 아이디어, 역할 분담 예시, 집안일 제보 순서다.

사용자의 제작 요청에 따라 index.html과 images/intro.png를 구현했다. 로고는 쉼표와 반짝임을 조합한 CSS 로고로 표시한다.

## 2. 파일 구조

```text
TEAM!/
├─ prd.md
├─ logo-prompt.md
├─ build-plan.md
├─ index.html       (제작 단계)
└─ images/         (이미지 준비 단계)
   ├─ logo.png
   └─ intro.png
```

## 3. 준비물과 결정할 내용

| 항목 | 현재 상태 | 제작 시 처리 |
|---|---|---|
| 팀 이름 | 집안일 쉼표로 확정 | 모든 화면에 동일하게 표기 |
| 로고 | 쉼표 모양과 반짝이는 청소 느낌 확정, 파일 준비 전 | logo-prompt.md로 시안 제작. 미준비 시 쉼표와 팀 이름을 임시 적용 |
| 소개 이미지 | 따뜻한 가족 생활 장면 제안 | 사용자 제공 또는 새 이미지 제작 후 intro.png로 준비 |
| 참고 사이트 | https://kkini.kr/ | 생활 이미지 분위기 참고, 정확한 글꼴명 확인 |
| 글꼴 | 공개 CSS에서 서울남산체·Poppins·Pretendard 확인 | 제목에 서울남산체·Poppins, 본문에 Pretendard 적용 |
| 색 | 민트·초록·올리브 확정 | prd.md의 제안 색상으로 시안 구성 |
| 제보 접수 | 실제 채널 미정 | 초안은 작성·복사 방식으로 계획. 실제 접수 요구 시 채널과 구현 방식 확정 |

## 4. 제작 순서

| 단계 | 작업 | 확인할 것 |
|---|---|---|
| 1 | 기획 검토와 제작 진행 확인 | 열린 질문과 가정 검토 |
| 2 | 글꼴 확인, 로고와 소개 이미지 준비 | 쉼표 형태, 팀 이름 철자, 이미지 구도 |
| 3 | 헤더·네 영역·푸터 구성 | 화면 순서와 이동 메뉴 |
| 4 | 색·글꼴·여백·카드 스타일 적용 | 식물원 분위기와 글자 가독성 |
| 5 | 소개 문구와 다섯 개선 아이디어 적용 | 사용자 요청 집안일 누락 여부 |
| 6 | 역할 분담 예시 적용 | 모바일 가독성과 조정 가능 안내 |
| 7 | 제보 작성·복사 동작 구현 | 필수 입력, 복사 성공·실패 안내 |
| 8 | 휴대폰 메뉴와 반응형 조정 | 375px에서 가로 스크롤 여부 |
| 9 | 전체 기능과 화면 점검 | prd.md 완료 기준 확인 |

## 5. 영역별 구현 메모

| 영역 | 구성 | 휴대폰 대응 |
|---|---|---|
| 헤더 | 쉼표 로고, 팀 이름, 네 메뉴 | 긴 팀 이름과 메뉴 버튼 겹침 점검 |
| 소개 | 공감 문구, 팀 소개, 생활 이미지, 이동 버튼 | 세로 배치, 제목 줄바꿈 조정 |
| 아이디어 | 다섯 집안일별 불편과 개선 방법 | 카드 한 열 배치 |
| 역할 분담 | 담당과 실행 내용을 담은 예시 | 표를 카드 형태로 표현 가능 |
| 제보 | 집안일·빈도·불편·바라는 변화 입력 | 라벨과 버튼을 충분한 크기로 표시 |

쉼표는 로고의 중심 형태로 사용한다. 본문 장식은 읽기에 필요한 여백을 유지하도록 조절한다.

## 6. 기술과 제보 동작

index.html 안에 CSS와 JavaScript를 넣고 이미지 파일을 상대 경로로 불러온다. 파일을 직접 열어도 기본 콘텐츠와 메뉴를 사용할 수 있게 한다.

제보는 실제 접수 채널이 결정되기 전까지 작성·복사 방식으로 계획한다 `(가정)`. 클립보드 사용이 제한되는 환경에서는 내용을 직접 선택해 복사할 수 있게 표시한다. 복사 완료 안내는 실제 복사 성공 후 보여준다. 입력 오류는 해당 입력 옆에 쉬운 문장으로 안내한다.

## 7. 확인 방법

- 데스크톱 1280px과 휴대폰 375px에서 레이아웃과 이미지 잘림을 확인한다.
- 네 메뉴와 첫 화면 버튼이 올바른 영역으로 이동하는지 확인한다.
- 휴대폰 메뉴의 열기·닫기, 키보드 조작과 포커스 표시를 확인한다.
- 다섯 집안일과 역할 분담 예시의 내용을 기획서와 대조한다.
- 빈 제보와 정상 제보를 입력하고 안내 및 복사를 확인한다.
- 글자 대비, 대체 텍스트, 입력 라벨, 가로 스크롤 유무를 확인한다.
- 확인하지 못한 항목은 완료 보고에 명시한다.
