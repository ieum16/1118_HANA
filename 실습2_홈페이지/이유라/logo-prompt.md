# 집안일 쉼표 로고 제작 프롬프트

## 기본 프롬프트

아래 내용을 이미지 생성 도구에 붙여 넣어 사용한다.

```text
‘집안일 쉼표’ 팀의 로고를 만들어 줘.
반복되는 집안일을 줄여 바쁜 맞벌이 가족의 저녁에 여유를 만드는 팀이야.
활기찬 민트, 초록, 올리브 계열을 사용하고 따뜻하고 힘찬 인상을 줘.
단순한 아이콘과 ‘집안일 쉼표’라는 한글 팀 이름을 조합해 줘.
흰 배경, 정사각형 구도로 만들어 줘.

아이콘의 중심은 알아보기 쉬운 쉼표 모양이야.
쉼표에 잎사귀의 유기적인 곡선을 살짝 담고,
주변에 작은 반짝임 두 개를 더해 청소 후의 산뜻함을 표현해 줘.
작은 크기에서도 쉼표가 선명하게 보이도록 윤곽과 형태를 단순하게 해 줘.
식물원의 생기와 깨끗하게 정리된 집의 편안함을 담아 줘.
한글은 ‘집안일 쉼표’로 정확하게 표기하고 읽기 편하게 배치해 줘.
```

## 아이콘 아이디어

| 안 | 구성 | 담긴 뜻 |
|---|---|---|
| A · 우선 제안 | 잎사귀 곡선을 담은 민트색 쉼표 + 작은 반짝임 | 집안일 사이의 휴식과 산뜻함 |
| B | 집 모양 안에 쉼표 + 반짝임 | 가족의 집에 생기는 쉼 |
| C | 쉼표 아래를 쓸고 지나간 듯한 곡선 + 반짝임 | 집안일을 가볍게 정리하는 힘 |

쉼표 모양 추가는 사용자 확정 요청이다. 잎사귀와 반짝임의 구체적인 배치는 시안 제안이다.

## 수정 요청 예시

- “쉼표가 더 크게 보이도록 하고 반짝임은 작게 해 줘.”
- “올리브색을 조금 더 넣고 전체 색감은 따뜻하게 해 줘.”
- “아이콘만 따로, 글자 없이 정사각형으로 만들어 줘.”
- “한글 팀 이름은 ‘집안일 쉼표’로 정확하게 고쳐 줘.”
- “작은 화면에서도 선명하도록 세부 장식을 줄여 줘.”

## 저장과 적용

선택한 로고를 TEAM!/images/logo.png로 저장한다. 이미지 속 한글을 확인하고, 페이지 헤더에는 팀 이름을 읽을 수 있는 텍스트로도 제공한다.

로고 파일이 준비되기 전 제작한다면 쉼표 모양과 팀 이름을 조합한 임시 텍스트 로고를 사용한다. 최종 로고 적용 후 크기와 가독성을 다시 확인한다.

## 소개 이미지 제작용 보조 프롬프트

소개 이미지의 구체적인 구도는 제안이다.

```text
식물이 있는 따뜻한 집의 저녁 생활 사진을 만들어 줘.
맞벌이 부부와 아이가 편안한 표정으로 함께 빨래를 정리하고 있어.
민트, 초록, 올리브색 소품과 따뜻한 크림색 벽,
넓은 잎의 화분, 부드러운 자연광으로 식물원처럼 생기 있는 느낌을 줘.
바쁘고 지친 하루 끝에 서로 일을 나누며 여유를 찾는 순간을 담아 줘.
소개 페이지에 쓸 가로형 사진으로 만들고 사람과 손의 형태를 자연스럽게 표현해 줘.
```

참고 사이트는 https://kkini.kr/ 이다. 가족의 생활을 따뜻하게 담는 방향을 참고한다. 최종 소개 이미지는 TEAM!/images/intro.png로 저장한다.
