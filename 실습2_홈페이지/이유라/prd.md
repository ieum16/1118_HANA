# 집안일 쉼표 팀 소개 페이지 기획서

| 항목 | 내용 |
|---|---|
| 문서 상태 | 초안 v0.1 |
| 작성일 | 2026-11-19 |
| 작성자 | 집안일 쉼표 |
| 관련 문서 | logo-prompt.md, build-plan.md |

PRD는 누구를 위해 무엇을 왜 만드는지 정리한 제품 요구사항 문서다. 사용자가 정한 내용과 제작을 위해 제안한 내용을 함께 기록하며, 미확정 제안은 `(가정)`으로 표시한다.

## 1. 배경과 문제

바쁜 맞벌이 부부는 퇴근 후에도 저녁 메뉴, 장보기, 빨래, 아이의 숙제와 취침 준비를 챙기느라 저녁 시간에 쫓긴다. 집안일 자체에 더해 무엇을 언제 누가 할지 생각하고 독촉하는 일도 반복된다.

집안일 쉼표는 반복되는 집안일을 분석해 번거로움과 소모되는 시간을 줄이는 팀이다. 방문자가 자신의 불편을 발견하고, 개선 아이디어와 가족 역할 분담 예시를 통해 실천 방법을 찾도록 돕는다.

## 2. 목표와 성공 기준

| 목표 | 확인 방법 |
|---|---|
| 팀의 목적을 쉽게 이해한다 | 맞벌이 부부 3명에게 보여주고 팀이 돕는 일을 설명할 수 있는지 확인 `(가정)` |
| 실천할 아이디어를 찾는다 | 방문자가 적용하고 싶은 개선 아이디어를 1개 이상 고를 수 있는지 확인 `(가정)` |
| 역할 분담 대화를 시작한다 | 담당자와 실행 시간을 함께 정할 수 있는 예시 제공 |
| 불편한 집안일을 제보할 수 있다 | 제보 문구 작성과 복사 기능이 정상 동작하는지 확인 `(가정)` |

## 3. 대상 사용자

| 대상 | 궁금한 것 | 제공할 내용 | 기대 행동 |
|---|---|---|---|
| 저녁 시간이 부족한 맞벌이 부부 | 반복되는 집안일을 어떻게 줄일까 | 일상에 적용할 개선 아이디어 | 아이디어를 골라 시도하기 |
| 역할 분담이 필요한 가족 | 누가 언제 무엇을 맡을까 | 부부와 아이가 함께하는 분담 예시 | 상황에 맞게 역할 조정하기 |
| 불편을 제보하고 싶은 방문자 | 무엇을 어떻게 알려주면 될까 | 집안일, 반복 빈도, 번거로운 점을 정리하는 양식 | 제보 내용 작성하기 |

## 4. 제작 범위

- 팀 소개, 집안일 줄이기 아이디어, 역할 분담 예시, 집안일 제보로 구성된 한 장짜리 소개 페이지.
- 반응형 화면, 섹션 이동 메뉴, 로고와 소개 이미지.
- 제보는 첫 버전에서 내용을 작성하고 복사하는 형태로 제안한다 `(가정)`. 실제 팀에 접수하려면 받을 채널과 연결 방식 확정이 필요하다.
- 가족 역할 분담은 예시를 제공하는 범위로 계획한다. 가족별 계정, 공유 일정, 개인별 자동 배정은 후속 검토 항목이다 `(가정)`.

## 6. 화면 구성

헤더의 쉼표 로고와 메뉴 → 공감되는 한 줄 소개 및 팀 소개 → 개선할 집안일과 줄이기 아이디어 → 역할 분담 예시 → “집안일 제보 부탁드립니다!” → 푸터.

첫 화면의 ‘집안일 줄여보기’ 버튼은 아이디어 영역으로, ‘우리 집 집안일 제보하기’ 버튼은 제보 영역으로 이동한다 `(가정)`.

## 7. 콘텐츠 상세

### 한 줄 소개와 팀 소개

- 제목 제안 `(가정)` — “집안일 사이에, 우리 가족의 쉼표.”
- 보조 문구 제안 `(가정)` — “퇴근 후 또 시작되는 집안일, 함께 줄여봐요. 번거로운 일은 가볍게, 가족의 저녁은 여유롭게.”
- 팀 소개 — “집안일 쉼표는 반복되는 집안일을 살펴보고, 시간을 잡아먹는 불편을 줄일 아이디어와 가족이 함께하는 방법을 찾습니다.”
- 소개 이미지 제안 `(가정)` — 식물이 있는 따뜻한 집에서 가족이 함께 정리하고 쉬는 생활 장면.

### 개선할 집안일과 아이디어

아래 아이디어는 제작용 초안 `(가정)`이며, 효과 수치를 확정해 표시하지 않는다.

| 집안일 | 번거로운 점 | 줄이기 아이디어 |
|---|---|---|
| 저녁 메뉴 정하기 | 매일 처음부터 고민한다 | 가족이 자주 먹는 메뉴를 모아 주간 후보를 함께 정한다 |
| 장보기 | 필요한 것을 여러 번 확인하고 다시 산다 | 메뉴에 맞춘 장보기 목록을 만들고 주문 전 재고를 확인한다 |
| 빨래 개기 | 마른 빨래가 쌓여 한꺼번에 처리한다 | 가족별 바구니를 두고 각자 옷 정리를 나눈다 |
| 아이 숙제 준비 | 준비물과 해야 할 일을 반복해서 묻는다 | 아이와 함께 다음 날 준비 체크리스트를 확인한다 |
| 아이 취침 준비 챙기기 | 씻기부터 잠들기까지 매일 챙길 일이 많다 | 씻기·양치·잠자리 순서를 정해 가족이 함께 확인한다 |

### 역할 분담 예시

성별과 관계없이 상황에 따라 바꾸는 예시다. 담당은 계획부터 마무리 확인까지 맡는다는 설명을 함께 제공한다 `(가정)`.

| 할 일 | 가족 구성원 A | 가족 구성원 B | 아이 참여 |
|---|---|---|---|
| 메뉴와 장보기 | 주간 메뉴 후보 정리 | 재고 확인 후 구매 | 먹고 싶은 메뉴 고르기 |
| 빨래 개기 | 세탁과 건조 | 공용 빨래 정리 | 가능한 범위에서 자기 옷 정리 |
| 숙제 준비 | 주중 첫날 체크 함께하기 | 다음 날 준비물 함께 확인 | 숙제와 준비물 체크 |
| 취침 준비 | 씻기·양치 함께 확인 | 잠자리 준비와 재우기 | 순서대로 준비하고 잠자리 들기 |

역할은 생활 일정에 맞춰 주 단위로 교대할 수 있다고 안내한다. 아이의 참여 범위는 연령과 가정 상황에 맞춘다 `(가정)`.

### 집안일 제보

- 제목 — “집안일 제보 부탁드립니다!”
- 안내 문구 제안 `(가정)` — “우리 집 저녁을 바쁘게 만드는 일을 알려주세요. 함께 줄일 방법을 찾아봐요.”
- 입력 항목 제안 `(가정)` — 집안일 종류, 반복 빈도, 번거로운 점, 바라는 변화.
- 첫 버전 동작 제안 `(가정)` — 필수 입력을 확인하고 제보 내용을 복사한다. 복사가 제한되면 선택 가능한 제보 문장을 보여준다.
- 버튼 문구 — “제보 내용 복사하기”. 완료 안내 — “내용을 복사했어요.”
- 실제 접수 채널은 미정이다. 공개 전 확정하고 접수 동작과 안내를 함께 반영한다.

## 8. 디자인 가이드

| 항목 | 방향 |
|---|---|
| 분위기 | 따뜻함, 힘참, 식물원의 생기 |
| 메인 색 | 활기찬 민트 `#50D6AD` `(가정)` |
| 보조 색 | 짙은 초록 `#205B42`, 올리브 `#788542` `(가정)` |
| 바탕과 본문 | 따뜻한 크림 `#FAF8EF`, 짙은 초록 본문 `#183D2E` `(가정)` |
| 로고 | 쉼표 모양을 중심으로 반짝임과 잎사귀 느낌을 조합 |
| 형태 | 넉넉한 여백, 둥근 카드, 굵고 선명한 제목 `(가정)` |
| 글꼴 | 참고 사이트의 공개 CSS에서 Poppins, SeoulNamsanJungM, Pretendard 사용 확인. 제목은 Poppins·서울남산체, 본문은 Pretendard 적용 |
| 소개 이미지 | 따뜻한 자연광, 초록 식물, 가족이 집안일을 함께하는 장면 `(가정)` |

참고 사이트는 https://kkini.kr/ 이다. 가족의 저녁 고민을 다루는 문구와 생활 이미지의 분위기를 참고한다. 소개 이미지는 사용자 소유 이미지 또는 새로 제작한 이미지로 구성한다 `(가정)`. 원본 이미지 파일과 사용 허락 여부는 확인되지 않았다.

## 9. 반응형과 접근성

- 375px 휴대폰부터 1280px 데스크톱까지 가로 스크롤 없이 표시한다.
- 아이디어 카드는 데스크톱 3열, 태블릿 2열, 휴대폰 1열로 구성한다 `(가정)`.
- 640px 아래에서 메뉴는 햄버거 버튼으로 전환한다. 키보드 조작과 열림 상태 안내를 제공한다.
- 휴대폰 좌우 여백은 16px 이상 확보한다.
- 민트 위 본문은 짙은 초록을 사용하고 글자 대비를 확인한다.
- 이미지 대체 텍스트와 입력 항목 라벨을 제공한다. 장식 반짝임은 읽기 흐름을 방해하지 않게 한다.

## 10. 기술 조건

- index.html에 CSS와 JavaScript를 포함하며 빌드 도구 없이 연다.
- 로고와 소개 이미지는 images 폴더에 둔다.
- 웹 글꼴 사용이 어려울 때 시스템 글꼴로 읽을 수 있게 한다.
- 제보의 실제 외부 접수는 채널 확정 후 구현 범위를 정한다.

## 11. 진행 순서

기획 문서 검토 → 로고와 소개 이미지 준비 → 제작 확인 → 페이지 구현 → 데스크톱과 휴대폰 점검.

## 12. 완료 기준

- [ ] 팀 이름이 ‘집안일 쉼표’로 표시되고 로고에 쉼표 모양이 있다.
- [ ] 요청한 네 영역과 화면 순서가 반영되어 있다.
- [ ] 다섯 집안일에 각각 개선 아이디어가 있다.
- [ ] 가족 역할 분담 예시가 있다.
- [ ] 메뉴와 첫 화면 버튼이 해당 영역으로 이동한다.
- [ ] 제보 작성과 복사가 동작하고 실제 동작에 맞는 완료 안내가 나온다.
- [ ] 375px 화면에서 가로 스크롤이 없다.
- [ ] 로고, 이미지, 글자 대비와 키보드 조작을 확인한다.

## 13. 열린 질문

- 글꼴은 공개 CSS 확인 후 반영 완료. 외부 글꼴을 불러올 수 없을 때 시스템 글꼴로 표시한다.
- 소개 이미지의 최종 구도와 파일 준비.
- 로고 시안 선택.
- 제보를 실제로 받을 채널 및 접수 방식 결정. 현재 문서는 복사 방식을 가정한다.
- 제안한 첫 화면 문구, 색상 코드, 개선 아이디어와 역할 분담 예시 검토.
