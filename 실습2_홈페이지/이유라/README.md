## 한 줄 소개

반복되는 집안일을 줄이는 아이디어와 역할 분담으로 가족의 저녁에 여유를 만드는 팀입니다.

## 누구를 위해 만들었나요

저녁마다 집안일에 쫓기는 바쁜 맞벌이 부부를 위해 만들었습니다. 개선 아이디어를 실천하고 가족과 역할을 나누며, 번거로운 집안일을 제보할 수 있도록 구성했습니다.
