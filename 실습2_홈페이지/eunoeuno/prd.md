## 1. 배경과 목적

으노네 가족은 잘 먹고, 잘 자고, 잘 놀고, 행복하게 사는 가족이다. 가족사진, 여행 일정, 다녀온 여행지와 맛집을 한곳에 모아 가족이 각자의 휴대폰에서 함께 보고 추가하는 공간을 만든다.

## 2. 목표와 성공 기준

| 목표 | 확인 방법 |
|---|---|
| 가족사진을 함께 모으기 | 한 가족 구성원이 올린 사진이 다른 구성원의 휴대폰에서도 보인다 |
| 날짜별 여행 일정 만들기 | 여행 기간을 정하고 날짜별 시간·장소·메모를 추가하고 수정한다 |
| 다녀온 장소 기록하기 | 여행지·맛집을 저장하고 구글지도 열기 버튼으로 해당 장소를 확인한다 |
| 다시 찾아보기 | 다시 로그인해도 사진·일정·장소가 유지된다 |

## 3. 대상 사용자

| 대상 | 하고 싶은 일 | 페이지에서 할 수 있는 일 |
|---|---|---|
| 으노으노 | 가족의 기록과 여행 계획 정리 | 사진 추가, 여행 만들기, 장소 등록 |
| 초대한 가족 구성원 | 휴대폰으로 기록을 보고 함께 추가 | 같은 사진첩·여행 일정·방문 장소 사용 |

가족만 접근하는 공유 공간으로 설계한다. 이는 가족사진을 다루는 용도를 바탕으로 한 가정이며 제작 전 확인한다.

## 4. 만들 기능

- 가족 구성원 로그인과 초대에 따른 접근 권한
- 가족 공용 사진첩에 사진과 짧은 설명 추가
- 여행 제목·시작일·종료일 및 날짜별 일정 작성
- 방문한 여행지와 맛집의 이름·주소·메모 기록
- 장소별 구글지도 열기
- 사진·일정·장소의 공유 저장
- 본인이 올린 기록 수정과 삭제

가족 구성원별 삭제 권한과 관리자의 범위는 제작 전 확정한다. 기본 가정은 본인 기록 수정·삭제와 관리자 전체 관리다.

## 5. 메뉴

| 메뉴 | 담을 내용 |
|---|---|
| 우리 가족 | 로고, 가족 소개 문장, 최근 사진과 다가오는 여행 |
| 사진첩 | 사진 목록과 사진 추가, 설명과 촬영일 |
| 여행 일정 | 여행 목록, 날짜별 시간·장소·메모 |
| 다녀온 곳 | 여행지·맛집 구분, 장소명·주소·방문일·메모, 구글지도 열기 |

사진에 여행을 연결하고 방문 장소를 여행 일정에 연결하는 기능은 추가 단계의 후보로 둔다.

## 6. 화면 구성

맨 위에 로고와 메뉴를 배치한다. 첫 화면에는 ‘잘 먹고, 잘 자고, 잘 놀고, 행복하게’라는 소개를 보여 준다. 최근 사진, 다가오는 여행, 최근 방문한 장소를 이어 배치한다. 주요 동작은 사진 올리기, 여행 만들기, 장소 추가다.

휴대폰에서 사진과 날짜별 일정을 읽기 쉽게 한 열로 보여 준다. 넓은 화면에서는 사진과 장소 카드를 여러 열로 배치한다.

## 7. 입력과 저장 정보

| 기록 | 입력 항목 |
|---|---|
| 사진 | 이미지 파일, 설명, 촬영일, 작성자 |
| 여행 | 제목, 시작일, 종료일 |
| 일정 | 여행, 날짜, 시간, 장소, 메모, 작성자 |
| 방문 장소 | 여행지 또는 맛집, 장소명, 주소 또는 구글지도 링크, 방문일, 메모, 작성자 |

장소명이나 주소로 구글지도를 연다. 같은 이름의 장소를 구분할 수 있도록 주소 입력을 함께 제공한다.

## 9. 모바일과 접근성

- 휴대폰 375px부터 넓은 화면까지 가로 스크롤 없이 사용한다.
- 본문은 16px 이상, 주요 버튼은 손가락으로 누르기 충분한 크기를 유지한다.
- 입력칸에는 이름을 붙이고 저장 성공·실패를 한국어로 알린다.
- 사진 대체 설명을 제공하고 키보드로 메뉴와 입력칸을 이용할 수 있게 한다.

## 10. 구현과 공유 저장

여러 휴대폰에서 같은 사진과 일정을 쓰려면 로그인과 서버 저장이 필요하다. 화면은 웹 앱으로 만들고 기록은 데이터베이스, 사진은 파일 저장소에 둔다. 가족 접근 권한은 서버에서 확인한다. 저장 실패 시 입력값을 유지하고 다시 시도할 수 있게 한다.

사진 파일은 가족 로그인과 접근 권한을 확인한 요청을 통해 제공한다. 파일 종류·크기를 검사한다. 이미지의 촬영 위치 등 부가정보를 제거하는 처리를 계획에 포함한다.

구글지도는 장소별 지도 열기 버튼을 통해 사용자가 선택한 장소의 검색 결과를 새 창으로 보여 준다.

## 12. 완료 기준

- [ ] 로고와 연한 올리브색 분위기가 적용된다.
- [ ] 가족이 각자의 기기에서 로그인한다.
- [ ] 업로드한 사진이 다른 가족의 기기에서도 보인다.
- [ ] 날짜별 여행 일정을 추가·수정하고 다시 열어 확인한다.
- [ ] 방문 장소와 맛집을 기록하고 올바른 구글지도 검색 결과를 연다.
- [ ] 가족 접근 권한이 사진과 기록의 조회·수정 요청에 적용된다.
- [ ] 저장·업로드 실패 안내와 재시도가 동작한다.
- [ ] 실제 가족사진 대신 예시 이미지로 배포 전 검증한다.

## 13. 제작 전 확인할 가정

- 가족만 로그인해서 이용하는 공간으로 시작한다.
- 가족 구성원별 계정을 이용한다. 이용할 로그인 방식과 초대할 가족은 배포 단계에 확인한다.
- 사진은 한 장당 10MB 이하의 JPEG·PNG·WebP를 우선 지원한다.
- 여행 종료일은 시작일 이후로 입력한다.
- 가족 구성원 정보·사진·여행 기록은 가족용 운영 저장소에서 관리한다.


## 실습2 공개 체험판 범위

제출자 닉네임은 eunoeuno입니다. 공개 체험판은 AI 예시 사진과 가상 여행 일정을 제공합니다. 사진·여행·날짜별 일정·장소를 추가, 수정, 삭제할 수 있으며, 기록은 각 브라우저의 IndexedDB에 저장됩니다. 브라우저 저장 데이터를 지우면 체험 기록도 사라집니다. 다른 기기와 공유되지 않습니다.

가족이 함께 사용하는 실제 앱은 기존 로그인과 접근 권한을 유지하며 공개 체험판에서 링크로 이동합니다. 초대는 추후 진행합니다. 공개 체험판에는 실제 가족 데이터, 개인정보, API 키를 포함하지 않습니다.

정적 index.html에 화면 코드와 예시 이미지가 포함되어 있습니다. 별도 서버·설치·빌드 없이 Vercel에서 실행합니다.
