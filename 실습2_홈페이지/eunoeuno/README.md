# 으노네 가족

## 한 줄 소개

잘 먹고, 잘 자고, 잘 놀고, 행복하게 사는 가족의 사진과 여행 기록을 모으는 공간입니다.

## 누구를 위해 만들었나요

우리 가족을 위해 만들었습니다. 실습 제출용 공개 페이지는 누구나 예시 사진과 가상 일정으로 기능을 체험할 수 있습니다. 직접 추가한 기록은 해당 브라우저에만 저장됩니다.

## 페이지 구성

- 우리 가족: 가족 소개, 로고, 예시 사진, 다음 여행과 다녀온 장소
- 사진첩: 사진 추가, 크게 보기, 삭제
- 여행 일정: 여행 만들기, 날짜별 일정 추가·수정·삭제
- 다녀온 곳: 여행지·맛집 기록, 종류별 보기, 구글지도 열기
- 가족용 앱 로그인: 실제 가족 앱으로 이동하는 링크

## 체험판 안내

AI로 만든 예시 사진과 가상 일정입니다. 체험 기록은 브라우저 IndexedDB에 저장되며 다른 기기와 공유되지 않습니다. 브라우저 저장 데이터를 지우면 체험 기록도 사라집니다. 실제 가족용 앱의 로그인과 접근 권한은 별도로 유지됩니다.
