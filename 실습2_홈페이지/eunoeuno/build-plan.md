# 으노네 가족 페이지 제작 계획서

## 1. 만들 결과

연한 올리브색의 가족 공유 웹 앱을 만든다. 가족사진과 날짜별 여행 일정, 방문한 여행지·맛집을 함께 관리한다. 장소마다 구글지도 열기 버튼을 제공한다.

## 2. 준비된 파일

- prd.md
- logo-prompt.md
- build-plan.md
- images/logo.png

실습2 폴더에 기획 자료와 로고를 보관한다. 여러 기기에서 사진과 일정을 공유하는 요구에 맞춰 화면·로그인·서버 저장을 갖춘 앱 소스를 제작한다.

## 3. 준비물

| 항목 | 상태 |
|---|---|
| 이름과 소개 | 으노네 가족, 잘 먹고 잘 자고 잘 놀고 행복하게 살기 |
| 로고 | 이미지 생성 도구로 제작 |
| 색과 분위기 | 연한 올리브, 귀엽고 포근함 |
| 사진 | 검증용 예시 이미지 사용 |
| 가족 계정과 초대 대상 | 배포 단계에 확인 |
| 구글지도 API 키 | 선택한 장소별 지도 열기 방식에 필요한 키 없음 |

## 4. 만드는 순서

| 순서 | 작업 | 확인할 결과 |
|---|---|---|
| 1 | 메뉴와 가족 소개 화면 | 로고, 소개 문장, 사진첩·여행 일정·다녀온 곳 이동 |
| 2 | 사진첩 | 사진 선택, 설명 입력, 업로드 진행·완료·실패 안내 |

| 8 | 휴대폰 검증과 배포 | 375px 화면과 가족용 접속 주소 |

## 5. 화면 구현

홈에는 최근 사진, 다가오는 여행, 최근 방문 장소를 보여 준다. 사진첩은 사진 중심 카드로, 일정은 날짜별 묶음으로, 방문 장소는 여행지·맛집 필터가 있는 카드 목록으로 만든다.

페이지 내부에 입력 폼을 제공하고, 저장할 때 해당 버튼에 진행 상태를 표시한다. 삭제는 기록을 확인할 수 있는 안내와 함께 처리한다.

## 6. 공유와 접근 권한

배포 환경의 로그인 기능을 사용한다. 서버는 가족 구성원 여부와 기록별 수정 권한을 확인한다. 가족의 공용 기록은 데이터베이스에, 사진은 파일 저장소에 보관한다. 실제 사진과 가족 정보는 앱 운영 데이터로 저장한다.

사진은 접근 권한 확인 후 제공한다. 파일 종류와 크기 확인, 부가정보 제거, 업로드 실패 시 정리를 구현한다. 실제 사진으로 전환하기 전에 가족 두 계정에서 조회와 수정 권한을 점검한다.

## 7. 구글지도 연결

장소명과 주소를 지도 검색 링크로 변환한다. 한국어와 특수문자를 안전하게 처리하고 새 창으로 연다. 사용자가 구글지도 링크를 직접 입력하는 경우에는 허용된 지도 주소 형식인지 확인한다.

## 8. 확인 방법

- 로고와 글씨가 375px 화면에서 선명하게 보이는지 확인한다.
- 예시 사진 업로드 후 다른 가족 계정에서 보이는지 확인한다.
- 사진 업로드 실패 후 입력한 설명이 남고 재시도되는지 확인한다.
- 여행 기간과 날짜별 일정을 저장하고 다시 로그인해 확인한다.
- 빈 장소명, 잘못된 기간, 큰 이미지에 한국어 안내가 나오는지 확인한다.
- 장소명을 눌렀을 때 해당 위치의 구글지도 검색 화면이 열리는지 확인한다.
- 가족 외 계정의 사진·일정 조회와 변경 요청이 거절되는지 확인한다.
- 동시 편집과 재시도로 사진이나 일정이 중복 생성되지 않는지 확인한다.

## 9. 다음 단계
