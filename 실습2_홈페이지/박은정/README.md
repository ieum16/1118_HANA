# 마케팅플랫폼팀

## 한 줄 소개

시스템 기획·운영, 데이터 정비, 손님관리 프로세스 구축을 소개하고 대시보드와 문의 정보를 안내하는 팀 페이지입니다.

## 누구를 위해 만들었나요

현업부서가 팀의 담당 업무와 문의 경로를 파악하고 필요한 대시보드를 찾을 수 있도록 만들었습니다.

## 페이지 구성

- 팀 소개 · 팀원 8명과 주요 업무 안내
- 하는 일 · 시스템 기획, 시스템 운영, 데이터 정비, 손님관리 프로세스 구축
- 대시보드 · 마케팅 실행 건수·대상 손님 수, 피로도
- 담당자·문의 · 업무별 담당자와 문의 채널 등록 예정
- 일하는 방식 · 검토용 업무 흐름 초안
- FAQ · 검토용 질문과 답변
- 공지 · 등록 준비 중

## 배포 주소

Vercel 배포 준비 중이며 GitHub 앱 설치 권한 확인을 기다리고 있습니다. 내려받은 index.html을 브라우저로 열어 확인할 수 있습니다.

## 화면

초록 계열의 차분하고 전문적인 디자인입니다. 레퍼런스의 둥근 상단 메뉴, 굵은 테두리, 좌우로 나눈 메인 화면을 적용했습니다. 휴대폰에서는 메뉴가 접히고 소개와 업무 안내가 세로로 배치됩니다. 로고는 임시 글자로 표시합니다.
