# 마케팅플랫폼팀 홈페이지 제작 계획서

## 1. 만들 것

현업부서가 팀의 업무와 문의 경로를 파악하고 필요한 대시보드를 찾는 반응형 팀 소개 홈페이지를 만든다. 상세 요구사항은 prd.md를 따른다.

## 2. 파일 구조

```text
team-page/
├─ prd.md
├─ logo-prompt.md
├─ build-plan.md
├─ index.html          제작 진행 확인 후 생성
└─ images/            제작 시 생성
   ├─ logo.png        로고 제공 시 저장
   └─ reference.png   참고 이미지 제공 시 저장
```

## 3. 준비물

| 항목 | 현재 상태 | 초기 제작 방법 |
|---|---|---|
| 로고 | 없음 | 팀 이름과 첫 글자 기반 임시 로고 (가정) |
| 참고 디자인 | 미제공 | PRD의 초록 계열 디자인 적용 (가정) |
| 대시보드 주소 | 미제공 | 두 카드에 연결 준비 중 표시 |
| 담당자·문의 경로 | 미제공 | 등록 예정 표시 (가정) |
| 일하는 방식·FAQ | 초안 제안 | PRD의 가정 내용을 확인 후 반영 |
| 공지 | 미제공 | 공지 준비 중 표시 (가정) |

## 4. 만드는 순서

| 단계 | 작업 | 확인 |
|---|---|---|
| 1 | 기획 초안과 가정 확인 | 메뉴와 문구 수정사항 반영 |
| 2 | 제작 진행 답변 확인 | 지금 제작 또는 이미지 준비 후 제작 결정 |
| 3 | 헤더, 섹션 7개, 푸터 구성 | 메뉴 이동과 고정 헤더 간격 |
| 4 | 색상과 글꼴 적용 | 차분하고 전문적인 초록 계열 |
| 5 | 소개와 업무 카드 4개 작성 | 팀원 8명과 업무 명칭 일치 |
| 6 | 대시보드 2개와 담당자·문의 구성 | 실제 주소가 없으면 준비 상태 표시 |
| 7 | 일하는 방식, FAQ, 공지 구성 | 확정된 운영 정책처럼 오해할 문구 검토 |
| 8 | 반응형과 접근성 구현 | 모바일 메뉴, 키보드, 대비 |
| 9 | 브라우저 검토 | PRD 완료 기준 확인 |

## 5. 섹션별 구현

| 섹션 | 구성 | 휴대폰 대응 |
|---|---|---|
| 헤더 | 임시 로고, 팀 이름, 메뉴 7개 | 640px 미만에서 접이식 메뉴 |
| 팀 소개 | 소개, 8명, 주요 버튼 2개 | 세로 배치 |
| 하는 일 | 업무 카드 4개 | 4열 → 2열 → 1열 |
| 대시보드 | 실행 현황과 피로도 카드 | 2열 → 1열 |
| 담당자·문의 | 업무별 담당자 상태와 문의 경로 | 세로 배치 |
| 일하는 방식 | 4단계 흐름 초안 | 세로 배치 |
| FAQ | 질문과 답변 초안 | 키보드 조작 가능한 펼침 항목 |
| 공지 | 준비 중 카드 | 전체 너비 |

## 6. 기술과 확인 방법

- index.html 안에 CSS와 JavaScript를 포함한다.
- 색상을 CSS 변수로 관리한다.
- 로고 파일 로딩 실패 시 임시 로고를 표시하고 나중에 파일을 추가하면 자동 적용되게 한다.
- 데스크톱 1280px와 휴대폰 375px에서 화면, 줄바꿈, 가로 스크롤을 확인한다.
- 메뉴 이동, 모바일 메뉴 펼침·닫힘, FAQ와 주요 버튼을 확인한다.
- 대시보드 주소가 제공되면 각 카드의 목적지와 접근 조건을 확인한다.
- 확인하지 못한 항목은 완료 보고에 명시한다.
