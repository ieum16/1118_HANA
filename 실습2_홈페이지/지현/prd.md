# teamteum 팀 홈페이지 PRD

작성일: 2026-11-19

## 배경과 목표

팀 소개와 주간보고 작성 공간을 한 페이지로 모아 반복 업무를 줄인다. 팀원 3명이 업무를 확인하고 금주·차주 주간보고를 작성한다.

## 대상 사용자

팀원. 가상 멤버는 햄스터(팀장), 냥이(책임자), 토끼(팀원)다.

## 페이지 구성

팀 소개 → 주간업무 작성 및 팀 주간보고 → 멤버 소개 → 이용 안내.

## 주요 기능

- 프로젝트 불러오기: 가상 프로젝트 데이터를 조회하고 보고에 포함할 업무를 선택한다.
- 주간보고 생성: 요건을 업무별 표로 취합하고 프로젝트 목록을 자동으로 접는다.
- 수기 업무 추가: 제목, 담당자, 업무 구분, 완료여부, 금주 업무, 차주 계획, 기한을 직접 입력한다.
- 업무별 보기: 전체·기획·개발·검토·기타로 분류하며 수정 내용을 유지한다.
- 보고서 표: 금주 / 완료여부 / 차주 / 기한. 업무 설명은 글머리표 형식으로 작성·수정한다.
- 진행 업무는 위, 완료 업무는 아래에 정렬한다. 완료 업무의 차주 내용과 기한은 비워 둔다.
- 기한은 MM.DD 형식이며 직접 수정할 수 있다.
- 복사는 선택한 업무 구분의 내용만 포함한다.
- 저장은 필터와 관계없이 전체 보고서 한 개를 현재 브라우저에 보관하고 다시 열면 복원한다.
- 업무별 삭제와 전체 삭제를 제공한다. 전체 삭제는 확인 후 저장 내용도 함께 지운다.

## 주간 계산 규칙

기준일은 수요일이다. 금주는 직전 화요일부터 다음 월요일, 차주는 그다음 화요일부터 월요일이다.
예: 2026-11-18 기준 금주 11/17~11/23, 차주 11/24~11/30.

## 디자인

흰 배경과 검은 글씨, 여백이 넓은 구성. 검은 사각형의 흰 t 로고와 같은 모양의 탭 아이콘 사용. 하단 원형 독 메뉴는 포인터 근접 시 확대되고 현재 섹션을 표시한다. 휴대폰에서는 메뉴 이름을 항상 표시한다.

## 기술과 배포

index.html에 CSS·JavaScript를 포함한다. favicon.svg를 사용한다. 빌드 도구·로그인·서버 API 없이 동작하는 정적 홈페이지이며 GitHub 저장소 jhp-428/teamteum과 Vercel로 배포한다.

배포 주소: https://teamteum.vercel.app/

## 확인 내용

수요일 기준 날짜 계산, 업무별 필터, 수기 업무 병합, 진행·완료 정렬, 완료 업무의 차주 제외, 기한 수정, 브라우저 저장·복원·삭제를 확인했다. 375px 모바일 화면에서 가로 넘침 없이 표시되는 것을 확인했다.
