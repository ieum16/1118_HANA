# 실습2 · 홈페이지 만들기

가상 팀의 소개 홈페이지를 PRD → Codex 구현 → 깃허브 · 버셀 배포까지 해서 **링크**로 만듭니다. (교안 1라운드 · 실습 ⑦~⑩)

## 내 폴더

```
실습2_홈페이지/<닉네임>/
├── prd.md            ← 꼭 · 기획서
├── images/logo.png   ← 꼭 · 팀 로고 (logo.png 를 폴더 바로 안에 둬도 돼요)
├── index.html        ← 홈페이지
├── screenshot.png    ← 선택(추천) · 첫 화면 캡처
└── README.md         ← 꼭 · ## 배포 주소 에 버셀 링크
```

참고 화면 `reference.png` 는 남이 만든 화면이라 **올라가지 않게** 막아 두었어요.

## 올리기

Codex에 **"실습2 올려 줘"** 라고 하면 PRD · 로고 · 버셀 링크를 확인하고 "올릴까요?" 하고 물어봐요. 버셀 링크가 없으면 배포부터 같이 해요.

- 팀 페이지 기획은 Codex에 **"팀 페이지 만들고 싶어"** (스킬 `team-page-prd`)
