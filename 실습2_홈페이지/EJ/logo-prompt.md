# 데이터마케팅팀 로고 제작 프롬프트

## 1. 기본 프롬프트

```
데이터마케팅팀의 로고를 만들어 줘.
고객 데이터를 분석해 마케팅 성과를 높이는 팀이야.
#008485를 메인 색으로, #E90061을 작은 포인트로,
#B5B5B5를 보조 색으로 사용해 줘.
단순한 아이콘과 정확한 한글 팀 이름 “데이터마케팅팀”을 넣어 줘.
흰 배경, 정사각형, 깔끔하고 전문적인 대시보드에 어울리는 디자인.
아이콘은 데이터 점 세 개가 연결되며 성장하는 모습을 표현해 줘.
작은 크기에서도 알아볼 수 있게 세부 장식을 줄여 줘.
```

## 2. 아이콘 아이디어

| 아이디어 | 팀과 연결되는 의미 |
|---|---|
| 연결된 데이터 점 | 분석과 마케팅 활동의 연결 |
| 겹치는 원과 중심점 | 고객 타깃 발견 |
| 간결한 막대그래프 | 마케팅 성과 개선 |

## 3. 수정 요청 예시

- 아이콘의 형태를 더 단순하게 해 줘.
- 아이콘만 따로, 글자 없이 한 장 더 만들어 줘.
- 팀 이름 철자를 정확히 “데이터마케팅팀”으로 넣어 줘.
- 청록색을 중심으로 하고 분홍색의 비중을 줄여 줘.

## 4. 적용 방법

마음에 드는 로고를 제공하면 images/logo.png에 저장해 헤더에 적용합니다.
초기 구현은 팀 이름 글자 표시로 시작할 수 있습니다.
참고 화면이 있으면 디자인 분위기와 정보 배치를 참고합니다.
