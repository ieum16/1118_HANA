# 지니니팀

## 한 줄 소개

일하는 방식에, 작은 여유를. 한 사람의 정리가 팀의 자산이 되도록 함께 쓰는 문서와 양식을 모았습니다.

## 누구를 위해 만들었나요

팀원들이 정리한 절차와 양식을 빠르게 찾아 활용하려는 팀 리더를 위해 만들었습니다.

## 페이지 구성

- 팀 소개 — 소개 문구, 팀이 함께 일하는 모습, 세 가지 양식 바로가기
- 팀 업무 안내 — 업무 매뉴얼, 업무 요청 방법, 자주 묻는 질문, 업무별 유관 부서와 담당 파트 예시
- 업무 문서 — 주간보고 양식, 자주 쓰는 안내 문구, 반복 업무 체크리스트를 검색하고 분류별로 열어 복사하는 카드
- 우리가 만든 도구 — 추가할 반복 업무 도구를 위한 준비 중 영역
- 문의 — 문서 추가·수정 제안 안내와 예시 이메일
