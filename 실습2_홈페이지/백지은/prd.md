# 지니니팀 소개 페이지 기획서

v0.2 · 2026-11-19

## 1. 배경과 목표

지니니팀은 반복 업무를 줄이는 도구를 만드는 팀이다. 팀 리더가 팀원들이 정리한 업무 절차를 한곳에서 찾아 문서 작성과 반복 업무에 다시 쓸 수 있게 한다.

## 2. 대상과 성공 기준

주 사용자는 팀 리더다. 첫 방문에서 업무 문서 메뉴를 찾고, 필요한 양식을 열어 복사한 뒤 기존 문서에 붙여 넣을 수 있어야 한다. 첫 검토에서는 주간보고 양식을 1분 안에 찾아 복사하는 흐름을 확인한다. 1분은 초안의 검토 기준이다.

## 3. 화면 구성

| 메뉴 | 섹션 | 내용 |
|---|---|---|
| 팀 소개 | `#intro` | 팀 이름, 한 줄 소개, 협업 이미지, 팀 업무 안내와 업무 문서 바로가기 |
| 팀 업무 안내 | `#guide` | 업무 매뉴얼, 업무 요청 방법, 자주 묻는 질문, 업무별 유관 부서·담당 파트 |
| 업무 문서 | `#work` | 문서 카드 3개. 제목·내용으로 검색하고 분류를 선택한 뒤 양식을 열거나 복사 |
| 우리가 만든 도구 | `#tools` | 도구가 등록되기 전까지 ‘준비 중’ 카드 표시 |
| 문의 | `#contact` | 문서 추가·수정 제안 안내와 예시 문의 채널 |

소개 문구는 ‘일하는 방식에, 작은 여유를’로 쓴다. 보조 문구는 ‘한 사람의 정리가 모두의 여유로 이어지도록, 함께 쓰는 문서와 양식을 모았습니다.’로 쓴다. 함께 일하는 가상 팀의 이미지를 곁들인다.

## 4. 업무 문서

| 문서 | 처음 제공할 양식 |
|---|---|
| 주간보고 양식 | 기간, 완료한 일, 진행 중인 일, 다음 주 계획, 공유할 사항 |
| 자주 쓰는 안내 문구 | 자료 제출 요청과 일정 변경 안내. 날짜, 대상, 회신 방법은 빈칸으로 표시 |
| 반복 업무 체크리스트 | 최신 양식 확인, 입력 자료 준비, 결과 검토, 공유 및 기록 |

문서 3종은 사용자가 채워 쓸 수 있는 예시 양식으로 시작한다. 문의에는 예시 이메일 `team@example.com`을 예시라고 표시하며 실제 전송 기능은 범위 밖이다. 로그인, 문서 업로드, 공동 편집도 이번 범위 밖이다.

팀 업무 안내에는 업무 범위 확인부터 공유까지의 절차, 요청 글에 적을 항목, 양식·일정 변경·담당자에 대한 질문, 업무 유형별 협업 부서와 담당 파트를 넣는다. 유관 부서와 담당 파트는 예시 역할로 표시한다.

## 5. 디자인과 기술

- 색상은 남색 `#172446`, 밝은 회색 `#F5F7FC`, 흰색 `#FFFFFF`, 강조색 `#364CC2`를 사용한다. 문서 유형은 카드 표지의 색과 이름으로 함께 구분한다.
- 여백을 충분히 두고 제목과 본문을 명확히 구분한다. 글꼴은 Pretendard 또는 시스템 기본 글꼴을 쓴다.
- 로고가 들어오면 `images/logo.png`를 사용한다. 최초 제작 시 이미지가 없으면 ‘지’ 글자 표식을 사용한다. 참고 이미지가 들어오면 `images/reference.png`의 색과 배치를 참고한다.
- `index.html`에 CSS와 JavaScript를 포함한다. 협업 이미지는 `images/team-collaboration.jpg`에 둔다. 배포 및 GitHub 제출용 HTML에는 이미지와 로고를 포함한다. 페이지를 브라우저에서 직접 열 수 있게 한다.

## 6. 완료 기준

- [ ] 메뉴와 첫 화면 버튼이 해당 섹션으로 이동한다. 팀 업무 안내의 네 항목을 펼쳐 볼 수 있다.
- [ ] 상단 검색과 분류 버튼으로 문서를 찾을 수 있다. 결과가 없을 때 안내가 보이고 바로가기에서 선택한 양식이 열린다.
- [ ] 세 양식을 각각 열고 복사할 수 있다. 복사 권한이 막힌 경우 양식 텍스트를 직접 선택할 수 있다.
- [ ] 데스크톱에서는 업무 문서가 3열, 태블릿에서는 2열, 휴대폰에서는 1열로 배치된다.
- [ ] 375px 폭에서 가로 스크롤이 없고 메뉴를 열고 닫을 수 있다.
- [ ] 키보드로 메뉴와 문서 컨트롤을 조작할 수 있고 포커스가 보인다.
- [ ] 헤더에 로고 또는 글자 표식이 보이고, 도구 영역에 ‘준비 중’이 표시된다.

## 7. 열린 질문

실제 업무 문서, 로고, 참고 이미지, 문의 채널이 생기면 예시 콘텐츠를 교체한다.
