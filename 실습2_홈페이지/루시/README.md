# 종검 업무 포털

## 한 줄 소개

종합 검사 시스템을 운영하는 종검팀의 업무 절차, 개발 요청, 문의 사례, 월간 일정을 모은 포털입니다.

## 누구를 위해 만들었나요

자점감사·준법·검사·글로벌 준법 담당자가 업무에 필요한 절차와 관련 기록을 한곳에서 찾을 수 있도록 만들었습니다. 화면의 업무 절차와 기록은 실습용 예시입니다.

## 페이지 구성

- 팀 소개와 이번 달 주요 일정
- 업무 지식맵과 상황별 절차·체크리스트
- PMS 개발 요청 검색과 상세 요건·담당자·개발자 조회
- 주제별 문의 사례
- 회의·휴가·연수를 확인하는 월간 달력
