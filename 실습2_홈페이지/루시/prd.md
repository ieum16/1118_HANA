# 종검 팀 소개 페이지 기획서 (PRD)

| 항목 | 내용 |
|---|---|
| 문서 상태 | 기획안 v0.4 |
| 작성일 | 2026-11-19 |
| 작성자 | 종검 |
| 관련 문서 | `logo-prompt.md`, `build-plan.md` |

## 1. 배경과 문제

종검은 종합 검사 시스템을 운영하는 팀이다. 자점감사·준법·검사·글로벌 준법 담당자가 직원들의 개발 요청(PMS), 기존 문의 답변, 월간 업무 일정을 한곳에서 찾아볼 수 있는 팀 소개 페이지를 기획한다.

## 2. 목표와 성공 기준

| 목표 | 확인 방법 |
|---|---|
| 필요한 개발 요청을 찾고 상세 요건을 확인할 수 있다 | 예시 PMS 번호로 검색해 해당 요청의 내용과 요건을 확인한다 |
| 비슷한 문의와 답변을 다시 참고할 수 있다 | 주제를 골라 해당 사례의 질문, 답변, 질의자 정보를 확인한다 |
| 월별 업무 일정을 확인할 수 있다 | 확인하려는 달로 이동해 회의·휴가·연수의 날짜와 시간을 확인한다 |
| 상황에 맞는 업무 절차와 관련 기록을 찾을 수 있다 | 업무 지식맵에서 업무를 선택해 절차와 체크리스트를 확인하고 문의 사례와 PMS 상세를 펼친다 |
| 종검의 역할을 바로 이해할 수 있다 | 첫 화면에서 팀 이름과 종합 검사 시스템 운영 역할을 읽을 수 있다 |

## 3. 대상 사용자

| 대상 | 페이지에서 확인할 내용 |
|---|---|
| 자점감사·준법·검사·글로벌 준법 담당자 | 업무와 관련된 개발 요청의 내용·요건, 주제별 기존 문의와 답변, 월간 업무 일정 |

## 4. 제작 범위

첫 버전은 팀 소개와 예시 기록·일정을 조회하는 단일 페이지다. PMS 검색, 문의 주제 필터, 월간 달력을 제공한다. 새 요청 접수, 답변 수정, 일정 등록·수정, 직원 인증, 권한 관리, 사내 시스템 연동은 실제 운영 방식이 정해진 뒤 별도로 기획한다. 시제품의 기록·일정·질의자 항목은 모두 가상 데이터로 채운다.

| 업무 지식맵 | `#knowledge` | 네 업무의 연결 관계, 상황별 절차와 체크리스트, 관련 문의 및 PMS 상세 |

## 6. 화면 구성

1. 헤더에 종검 워드마크와 메뉴를 배치한다.
2. 첫 화면에 팀 역할을 한 문장으로 소개하고 업무 지식맵·PMS·문의 사례·월간 업무 일정으로 이동하는 링크를 둔다.
3. 업무 지식맵에서 네 업무를 연결선으로 보여 주고, 선택한 업무의 상황별 안내를 아래에 표시한다.
4. PMS는 데스크톱에서 표로, 휴대폰에서 같은 항목을 가진 카드로 보여 준다.
5. 문의 사례는 주제별 필터 아래에 카드로 보여 준다. 질문과 답변을 먼저 배치하고 하단에 질의자 정보를 표시한다.
6. 월간 업무 일정은 데스크톱과 휴대폰에서 요일별 달력으로 보여 준다. 휴대폰에서는 칸에 일정 유형을 표시하고, 일정 선택 시 상세 내용을 보여 준다.

## 7. 콘텐츠와 표시 항목

### 팀 소개

- 제목: 종검
- 소개 문구: 종합 검사 시스템을 운영하고, 개발 요청과 문의 답변, 월간 업무 일정을 공유합니다.
- 바로가기: 업무 지식맵 보기, PMS 보기, 문의 사례 보기, 월간 업무 일정 보기

### 업무 지식맵

- 종합 검사 시스템을 중심으로 `자점감사 ↔ 검사`는 점검 결과와 후속 조치, `준법 ↔ 글로벌 준법`은 점검 기준과 준법 결과를 연결한다. 연결 관계와 절차는 실습용 예시다.
- 업무를 누르면 상황별 안내가 열린다. 첫 상황에는 업무 절차, 클릭해 확인할 수 있는 체크리스트, 관련 문의와 PMS가 보인다.
- 관련 문의의 질문·답변과 PMS의 상세 요건·담당자·개발자를 펼쳐 볼 수 있다. 기존 데이터와 연결해 표시 값을 일치시킨다.

### PMS

| 항목 | 표시 내용 | 가상 예시 |
|---|---|---|
| PMS 번호 | 개발 요청을 구분하는 번호 | `PMS-DEMO-001` |
| 요청 내용 | 직원이 요청한 변경의 요약 | 검사 결과 조회에 기간 조건 추가 |
| 상세 요건 | 입력 조건과 기대 동작 | 시작일과 종료일을 지정하면 해당 기간의 예시 결과만 표시 |
| 담당자 | 해당 개발 요청의 업무 담당자 | 가상 담당 A |
| 개발자 | 해당 개발 요청의 구현 담당자 | 가상 개발 A |

번호와 요청 내용으로 검색할 수 있게 제안한다. 검색 결과가 없으면 조건을 바꿔 다시 검색할 수 있도록 안내한다. 담당자나 개발자가 정해지지 않은 경우 `미지정`으로 표시한다.

### 문의 사례

| 항목 | 표시 내용 | 가상 예시 |
|---|---|---|
| 주제 | 문의를 분류하는 항목 | 시스템 사용 방법 |
| 질문 | 문의한 내용 | 지난달 검사 결과는 어떻게 찾나요? |
| 답변 | 질문에 대한 안내 | 예시 화면에서 조회 기간을 지난달로 설정합니다 |
| 질의자 이름 | 질문한 사람의 이름 | 가상직원 A |
| 행번 | 질문한 사람의 직원 번호 | `DEMO-101` |
| 지점 | 질문한 사람의 소속 지점명 | 예시중앙지점 |
| 지점번호 | 해당 지점의 구분 번호 | `DEMO-B01` |

초기 주제는 시스템 사용 방법, 권한·접속, 오류·장애로 제안한다. 기본값은 전체 보기다. 선택한 주제에 사례가 없으면 그 상태를 화면에 표시한다.

### 월간 업무 일정

| 항목 | 표시 내용 | 가상 예시 |
|---|---|---|
| 유형 | 회의, 휴가, 연수, 기타 | 회의 |
| 제목 | 일정을 구분할 수 있는 이름 | 월간 운영 회의 |
| 날짜·시간 | 시작일·종료일과 시간 또는 종일 여부 | 11월 24일 10:00–11:00 |
| 메모 | 공유할 안내 사항이 있을 때 표시 | 다음 달 점검 항목 확인 |

처음에는 이번 달을 표시한다. 이전 달·다음 달로 이동하거나 이번 달로 돌아갈 수 있다. 여러 날 이어지는 휴가와 연수는 해당 날짜에 표시한다. 두 달에 걸친 일정은 해당 월 양쪽에서 확인할 수 있다. 일정이 없는 달에는 안내 문구를 표시한다.

## 9. 반응형과 접근성

- 375px 모바일과 1280px 데스크톱에서 가로 스크롤 없이 긴 문장이 줄바꿈된다.
- 모바일 PMS 카드에 `PMS 번호`, `요청 내용`, `상세 요건`, `담당자`, `개발자` 항목명을 각각 표시한다.
- 메뉴, 검색, 필터는 키보드로 이동하고 조작할 수 있다. 선택된 필터는 색과 텍스트 상태로 구분한다.
- 입력칸에 눈에 보이는 검색 라벨을 두고 로고 이미지에 대체 텍스트를 제공한다.
- 월 이동 버튼과 달력에서 일정을 키보드로 선택할 수 있다. 일정 유형은 색과 텍스트로 구분하고, 상세 창에서 제목·날짜·시간·메모를 확인할 수 있다.

## 10. 기술과 데이터 조건

- `index.html`을 브라우저로 열어 실행한다. 화면 스타일과 검색·필터·달력 로직을 같은 파일에 넣는다.
- 하나서체는 `fonts/`의 OpenType 원본을 웹폰트로 불러온다. 서체의 저작권은 하나금융그룹에 있다.
- 가상 PMS·문의·일정 데이터를 파일 안에 포함하고 검색, 필터, 월 이동은 브라우저에서 처리한다.
- 실제 직원 정보, 내부 문의, 휴가 일정 등을 사용하는 운영 버전은 내부 공개 범위, 접근 권한, 데이터 관리 방식을 먼저 정한다.

## 12. 완료 기준

- [ ] 팀 역할을 첫 화면에서 읽을 수 있고 모든 메뉴가 해당 섹션으로 이동한다.
- [ ] 업무 지식맵의 네 업무를 선택하면 연결 설명과 상황별 절차·체크리스트가 바뀌고, 관련 문의와 PMS의 상세를 확인할 수 있다.
- [ ] PMS에서 번호, 요청 내용, 상세 요건, 담당자, 개발자가 보이고 번호나 내용으로 검색할 수 있다.
- [ ] 문의 주제 필터가 동작하고 질문, 답변, 이름, 행번, 지점, 지점번호가 보인다.
- [ ] 이전 달·다음 달·이번 달 이동이 동작하고 회의·휴가·연수 일정과 기간이 표시된다. 월을 넘기는 일정은 두 달 모두에서 확인할 수 있다.
- [ ] 일정이 없는 달에 안내가 표시된다. 휴대폰에서도 일곱 요일이 한 화면에 보이고, 일정을 누르면 상세 창이 열린다.
- [ ] 결과가 없을 때 안내가 보이고 전체 목록으로 돌아갈 수 있다.
- [ ] 375px 폭에서 긴 요건과 답변이 잘리거나 화면 밖으로 넘치지 않는다.
- [ ] 모든 예시 기록과 질의자 정보가 가상 값이다.
