# 종검 로고 제작 프롬프트

## 기본 프롬프트

```text
종합 검사 시스템을 운영하는 팀 ‘종검’의 로고를 만들어 줘.
청록색(#00766E)과 흰색을 사용해 차분하고 단정한 업무 포털에 어울리게 해 줘.
검사 문서를 뜻하는 단순한 사각형과 확인 표시 하나를 아이콘으로 쓰고, 옆에 ‘종검’을 읽기 쉽게 넣어 줘.
한글 표기는 정확히 ‘종검’. 흰 배경의 정사각형 안에 아이콘과 글자를 가로로 배치하고 사방에 여백을 충분히 둬.
작은 헤더에서도 글자와 아이콘이 선명하게 보이도록 단순한 형태로 만들어 줘.
```

## 아이콘 후보

| 아이디어 | 담을 의미 |
|---|---|
| 문서와 확인 표시 | 검사와 검토 |
| 항목 세 줄과 체크 한 개 | 검사 항목과 요청 내역 정리 |
| 사각 프레임 안의 ‘종검’ 워드마크 | 글자 중심으로 팀 이름을 빠르게 인식 |

## 다듬을 때 쓸 문장

- “작게 표시해도 읽히도록 ‘종검’ 글자를 더 크게 하고, 아이콘 안의 선을 줄여 줘.”
- “작은 바로가기 아이콘용으로 문서와 확인 표시만 남긴 버전도 만들어 줘.”

완성한 이미지는 `images/logo.png`에 넣는다. 첫 화면은 청록색 텍스트 워드마크로도 제작할 수 있다.
