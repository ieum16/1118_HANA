# 종검 팀 소개 페이지 제작 계획서

## 1. 제작 목표

직원이 종검의 역할을 이해하고 PMS 개발 요청, 주제별 문의 답변, 회의·휴가·연수 등 월간 업무 일정을 찾아볼 수 있는 조회용 업무 포털 시제품을 만든다. 내용과 디자인 기준은 `prd.md`를 따른다.

## 2. 파일 구성

```text
team-page/
├─ prd.md
├─ logo-prompt.md
├─ build-plan.md
├─ index.html        (제작 단계)
└─ images/
   └─ logo.png       (로고가 준비되면 추가)
```

## 3. 준비물

| 준비물 | 현재 상태 | 제작 시 적용 |
|---|---|---|
| 팀명과 역할 | 종검, 종합 검사 시스템 운영 | 첫 화면과 헤더에 표시 |
| 로고와 참고 화면 | 로고 파일 없음, 하나은행 홈페이지 색감 참고 | 종검 텍스트 워드마크와 청록·흰색 디자인 적용 |
| PMS와 문의 기록 | 가상 예시 값으로 구성 | 검색과 필터를 확인할 수 있게 요청 내용과 문의 주제를 다양하게 구성 |
| 월간 업무 일정 | 가상 예시 값으로 구성 | 시간 지정 회의, 종일 휴가, 여러 날에 걸친 연수 포함 |

## 4. 제작 순서

| 순서 | 작업 | 확인할 내용 |
|---|---|---|
| 1 | 헤더, 팀 소개, 업무 지식맵, PMS, 문의 사례, 월간 업무 일정 섹션 구성 | 메뉴와 소개의 바로가기 링크가 해당 섹션으로 이동 |
| 2 | 청록·흰색 테마와 워드마크 적용 | 제목, 본문, 검색창의 대비와 여백이 읽기 편함 |
| 3 | PMS 데이터와 검색 구현 | 번호 또는 요청 내용 일부로 검색되고, 상세 요건 전체를 확인할 수 있음 |
| 4 | 문의 데이터와 주제 필터 구현 | 전체 보기와 주제 필터가 동작하고 모든 질의자 항목이 표시됨 |
| 5 | PC·휴대폰 월간 달력과 일정 상세 창 구현 | 월 이동, 일정 유형, 여러 날 일정, 일정이 없는 달 표시 확인 |
| 6 | 모바일 배치와 접근성 점검 | 375px에서 카드가 한 열로 쌓이고 검색·필터·월 이동을 키보드로 조작할 수 있음 |
| 7 | 예시 데이터와 표시 문구 검토 | 가상 기록이라는 안내, 결과가 없는 상태, 초기화가 모두 확인됨 |
| 8 | 업무 지식맵과 상황별 안내 구현 | 네 업무와 연결선이 보이고 선택한 업무의 절차·체크리스트·관련 기록을 확인할 수 있음 |

## 5. 섹션별 구현 메모

| 섹션 | 데스크톱 | 휴대폰 |
|---|---|---|
| 헤더와 팀 소개 | 좌측 로고와 우측 메뉴, 소개 아래 바로가기 | 접을 수 있는 메뉴와 세로 흐름 |
| 업무 지식맵 | 연결선을 따라 네 업무를 선택하고 절차와 체크리스트를 나란히 확인 | 같은 맵과 접을 수 있는 상황별 안내, 절차와 체크리스트는 세로 배치 |
| PMS | 검색창 아래 번호·요청 내용·상세 요건·담당자·개발자 표 | 같은 다섯 항목을 표시한 요청 카드, 긴 요건 줄바꿈 |
| 문의 사례 | 주제 필터와 사례 카드. 질의자 정보는 카드 하단에 배치 | 필터는 줄바꿈하고 사례 카드는 한 열로 배치 |
| 월간 업무 일정 | 현재 연월과 월 이동 버튼, 달력에 일정 유형·제목·시간 표시 | 같은 요일별 달력에서 일정 유형 표시, 일정 선택 시 제목·날짜·시간·메모 확인 |

PMS 요청과 문의 사례는 각각 한 곳에 정의한 가상 데이터를 사용한다. 같은 PMS 기록을 표와 모바일 카드에 표시해 두 화면의 값이 일치하도록 구현한다.

일정에는 유형, 제목, 시작일, 종료일, 시간 또는 종일 여부, 선택 메모를 둔다. 표시 월과 날짜 범위가 겹치는 일정을 PC·휴대폰의 공통 달력에 표시한다.

## 6. 검증 방법

1. 브라우저에서 `index.html`을 열어 다섯 메뉴와 네 바로가기를 눌러 본다.
2. PMS 예시 번호와 요청 내용의 일부를 각각 입력하고 같은 요청을 찾을 수 있는지 확인한다. 일치하지 않는 검색어와 검색 초기화도 확인한다. 표와 카드에 담당자·개발자가 같은 값으로 표시되고 배정 전에는 `미지정`이 보이는지 확인한다.
3. 문의 필터의 주제별 목록과 전체 보기를 확인한다. 카드 하나에서 질문, 답변, 이름, 행번, 지점, 지점번호가 모두 읽히는지 확인한다.
4. 월간 업무 일정에서 이전 달·다음 달·이번 달 버튼을 눌러 본다. 시간 지정·종일·여러 날 일정, 월을 넘는 일정, 일정이 없는 달을 확인한다.
5. 375px와 1280px에서 긴 요건의 줄바꿈, 가로 스크롤, 메뉴 동작을 확인한다. 두 화면에서 달력의 일곱 요일이 보이고 일정의 상세 창이 열리는지 확인한다. 키보드로 검색창·필터·월 이동 버튼을 조작한다.
6. 지식맵에서 네 업무를 모두 선택하고 각 상황을 열어 절차와 체크리스트를 확인한다. 관련 문의와 PMS를 펼쳐 기존 목록과 상세 값이 일치하는지 확인한다.
7. `prd.md`의 완료 기준을 점검한다.
