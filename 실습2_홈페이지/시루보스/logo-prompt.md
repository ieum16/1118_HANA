# 자동화랩 로고 제안과 제작 프롬프트

## 1. 기본 프롬프트
사용자가 1번 ‘열린 고리 + 전진 화살표’를 선택했다. 로고 방향은 확정했으며 실제 이미지는 생성 완료했다. 사용자의 최종 요청에 따라 모든 글자를 제외한 아이콘만 사용한다.

```text
자동화랩 팀의 로고를 만들어 줘.
남색(#172554) 계열, 글자 없는 단순한 아이콘만,
흰 배경, 정사각형.
반복을 나타내는 열린 고리의 끝이 오른쪽을 향하는 화살표로 이어지게 해 줘.
반복 업무를 줄여 일이 앞으로 나아간다는 의미를 최소한의 도형으로 표현해 줘.
한글, 초성, 영문을 포함한 모든 글자와 텍스트를 넣지 마.
평면 디자인, 일정한 선 굵기, 충분한 여백, 작은 크기에서도 식별되는 형태.
그라데이션, 입체 효과, 복잡한 장식은 제외해 줘.
```

## 2. 로고 방향과 비교 후보
| 번호 | 아이디어 | 의미·특징 |
|---|---|---|
| 1 · 선택 확정 | 열린 고리 + 전진 화살표 | 반복에서 벗어나 업무를 앞으로 보낸다는 의미. 단순한 선으로 작게 쓰기 좋음 |
| 2 | 세 개의 선 → 한 개의 화살표 | 엑셀·메일·일정의 복잡한 흐름을 하나로 정리한다는 의미 |
| 3 | A 모노그램 + 작은 체크 | Automation의 A와 완료 표시를 결합. 간결하고 단정한 인상 |

후보 2를 선택하면 프롬프트의 아이콘 설명을 ‘세 개의 평행한 선이 하나의 오른쪽 화살표로 합쳐지는 도형’으로 바꾼다.
후보 3을 선택하면 ‘영문 A를 단순한 기하 도형으로 만들고 작은 체크 표시를 결합한 아이콘’으로 바꾼다.

## 3. 수정 요청 예시
- 더 단순하게, 선의 굵기를 일정하게 해 줘.
- 아이콘만 따로, 글자 없이 한 장 더 만들어 줘.
- 남색 #172554 한 가지 색으로 표현해 줘.
- 어떤 글자도 넣지 말고 아이콘만 남겨 줘.

## 4. 이미지 준비
이 프롬프트를 ChatGPT에 붙여 넣어 로고를 만든 뒤 마음에 드는 이미지를 이 대화에 올리거나 images/logo.png로 저장한다.
참고할 화면이 있다면 images/reference.png로 준비한다. 로고가 없어도 제작 시 임시 글자 로고로 시작할 수 있다.
