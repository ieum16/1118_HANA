# 자동화랩 팀 홈페이지 제작 계획서

## 1. 만들 것
prd.md를 기준으로 팀 소개와 자동화 업무 제안을 돕는 한 장짜리 페이지를 제작한다. 사용자 제작 요청에 따라 index.html을 제작했다. 실제 제안 전달 경로는 미정이다.

## 2. 파일 구조
```text
team-page/
├─ prd.md
├─ logo-prompt.md
├─ build-plan.md
├─ index.html          # 제작 완료
└─ images/             # 로고 준비 완료
   ├─ logo.png
   └─ reference.png    # 선택
```

## 3. 준비물 체크
| 준비물 | 현재 상태 | 대응 |
|---|---|---|
| 팀 소개·업무 범위 | 확정 | 기획서 반영 |
| 로고 | 1번 열린 고리 + 전진 화살표·글자 없는 아이콘 로고 준비 완료 | 없으면 ‘자’ 임시 글자 로고 |
| 참고 이미지 | 없음 | 남색·간결한 디자인 기준 적용 |
| 실제 제안 경로 | 미정 | 예시임을 표시하고 공개 전 확정 |
| 소개할 도구 | 없음 | 준비 중 카드 |

## 4. 만드는 순서
| 단계 | 할 일 | 확인할 것 |
|---|---|---|
| 1 | 헤더·섹션 4개·푸터 구성 | 메뉴명과 이동 대상 |
| 2 | 색·글꼴·여백 적용 | 남색과 간결한 구성 |
| 3 | 팀 소개·2명 규모·제안 버튼 배치 | 핵심 문구와 버튼 연결 |
| 4 | 업무 카드 3개 작성 | 엑셀·메일·일정 및 알림 |
| 5 | 만든 도구 준비 중 카드 | 점선 테두리와 배지 |
| 6 | 제안 안내·양식 복사 구현 | 복사 성공·실패 안내, 예시 경로 표시 |
| 7 | 반응형·키보드 접근성 적용 | 375px·모바일 메뉴·포커스 |
| 8 | 기획서 완료 기준 점검 | 결과 기록과 수정 |

## 5. 섹션별 구현 메모
| 섹션 | 구성 | 데스크톱 → 휴대폰 |
|---|---|---|
| 헤더 | 로고·메뉴, 상단 고정 | 메뉴 → 햄버거 |
| 팀 소개 | 팀명·한 줄 소개·2명·주요 버튼 | 여백을 줄여 한 열 |
| 하는 일 | 설명과 제안 예시를 담은 업무 카드 | 3열 → 2열 → 1열 |
| 만든 도구 | 준비 중 카드 1개 | 한 열 |
| 자동화 제안 | 제안 양식·복사 버튼·전달 안내 | 한 열 |

정적인 소개 페이지로 제작한다. 제안 양식 복사는 서버로 전송하지 않으며, 실제 접수 완료처럼 표시하지 않는다.

## 6. 확인 방법
브라우저에서 1280px·768px·375px 폭을 확인한다. 섹션 이동, 모바일 메뉴 열기·닫기, 키보드 이동, 복사 기능과 실패 시 안내를 점검한다.
로고 이미지 유무 두 경우를 확인한다. 기획서 완료 기준을 검토하고 실제로 확인하지 못한 항목은 명시한다.

## 7. 만든 뒤 고치기 예시
- 업무 카드의 설명을 더 짧게 바꿔 줘.
- 자동화 제안에 FAQ를 추가해 줘.
- 준비 중 카드를 실제 도구 소개로 바꿔 줘.
