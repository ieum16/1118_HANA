# 브로브로

## 한 줄 소개

바이브코딩으로 게임·로봇·챗봇을 만드는 데 필요한 자료를 모으고 공유하는 아케이드 테마의 홈페이지입니다.

## 누구를 위해 만들었나요

취미로 바이브코딩을 하며 게임이나 로봇을 만드는 사람을 위한 페이지입니다.

## 페이지 구성

- 소개
- 게임 예시와 플레이할 수 있는 벽돌깨기
- 게임 제작 인터뷰 분석
- 로봇 코딩 자료 (준비 중)
- 챗봇 자료 (준비 중)
