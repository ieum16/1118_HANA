# AI연수팀 로고 제작 프롬프트

## 그대로 복사해서 사용할 프롬프트

```text
AI연수팀의 로고를 만들어 줘.
흰 배경의 정사각형에 단순한 개구리 아이콘과 한글 팀 이름 ‘AI연수팀’을 배치해 줘.
개구리 페페에서 느껴지는 느긋하고 무심한 분위기를 참고해, 반쯤 감긴 눈과 살짝 비대칭인 입, 두꺼운 윤곽선을 가진 AI연수팀의 개구리 마스코트를 그려 줘.
개구리는 초록색 #82B74B, 윤곽선은 짙은 녹색 #17271D, 작은 포인트는 연못 파랑 #A5C6DA를 사용해 줘.
개구리가 작은 브라우저 창을 들여다보는 모습을 단순한 면과 선으로 표현해 줘. 화면을 작게 줄여도 표정과 브라우저 창의 형태가 보이게 해 줘.
팀 이름 철자를 정확히 쓰고, 아이콘과 글자 둘레에 여백을 넉넉하게 둬.
```

## 아이콘 변형

| 아이디어 | 표현하는 내용 |
|---|---|
| 브라우저 창을 들여다보는 개구리 | 미리보기 화면을 확인하는 제작 과정 |
| 브라우저 탭 사이로 얼굴을 내민 개구리 | 웹페이지를 만드는 팀 |
| 말풍선 옆 개구리 | AI에게 화면 구성과 문구의 초안을 요청하는 과정 |

## 수정 요청 예시

- “개구리의 눈과 입만 남기고 표정을 더 단순하게 그려 줘.”
- “같은 마스코트로 글자 없는 아이콘 버전도 만들어 줘.”
- “팀 이름이 ‘AI연수팀’으로 정확히 읽히도록 한글 글자 간격을 조정해 줘.”

완성한 로고는 이 채팅에 올리거나 `팀페이지/images/logo.png`로 저장한다. 참고할 화면 이미지가 있다면 `팀페이지/images/reference.png`에 둘 수 있다.
