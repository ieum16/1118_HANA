# AI연수팀 소개 페이지 제작 계획서

[기획서](prd.md)에 따라 팀 소개, 만든 웹페이지, 배운 내용과 적용 사례가 한 화면 흐름으로 이어지는 반응형 페이지를 만든다.

## 파일 구조

```text
팀페이지/
├─ prd.md
├─ logo-prompt.md
├─ build-plan.md
├─ index.html       제작 확인 후 생성
└─ images/
   ├─ logo.png      로고를 받은 경우 사용
   └─ reference.png 참고 화면이 있을 경우 사용
```

## 준비 상태

| 항목 | 현재 상태 | 제작 시 처리 |
|---|---|---|
| 팀 소개, 메뉴, 적용 사례 | 확정 | 기획서의 순서와 문구 적용 |
| 색상과 개구리 스타일 | 초안 작성 | 개구리 초록, 아이보리 배경, 두꺼운 윤곽선 적용 |
| 로고와 참고 이미지 | 공유 전 | 임시 글자 로고와 기획서 색상으로 시작할 수 있음 |
| 소개할 웹페이지 | 제작 중 | ‘준비 중’ 카드를 표시하고 완성 후 링크 추가 |

## 구현 순서

| 단계 | 작업 | 확인 |
|---|---|---|
| 1 | `index.html`에 헤더와 메뉴 세 개, 대응하는 섹션을 만든다. | 각 메뉴가 해당 섹션으로 이동하고 고정 헤더가 제목을 가리지 않는다. |
| 2 | 색상과 모서리를 CSS 변수로 정의한다. 소개 영역에는 팀 이름, 한 줄 소개, 마스코트나 임시 로고를 배치한다. | 개구리 콘셉트가 보이고 소개 문구와 버튼이 쉽게 읽힌다. |
| 3 | 만든 웹페이지 섹션에 점선 테두리의 ‘준비 중’ 카드를 배치한다. | 상태가 문구로 명확하게 보인다. 결과물이 공개되면 카드에 실제 링크를 넣을 수 있다. |
| 4 | 적용 사례 두 개를 흐름에 맞게 배치한다. | AI에 초안을 요청한 과정부터 미리보기 후 수정까지 순서대로 읽힌다. |
| 5 | 작은 화면에서 카드와 소개 영역을 한 열로 바꾸고 메뉴 열기·닫기를 구현한다. | 640px 미만에서 메뉴 버튼이 동작하고 항목 선택 후 메뉴가 닫힌다. |

## 제작 후 확인

- `index.html`을 브라우저에서 직접 열어 1280px와 375px 너비에서 확인한다.
- 메뉴와 소개 버튼을 눌러 이동을 확인한다. Tab으로 메뉴에 접근해 초점 표시를 확인하고 Enter로 동작시킨다.
- 375px에서 제목과 카드가 자연스럽게 줄바꿈되고 가로 스크롤이 생기지 않는지 확인한다.
- 로고 파일이 있는 경우 이미지로 표시되고, 빠졌을 때는 임시 표시가 보이는지 확인한다.
- ‘준비 중’ 상태와 두 적용 사례의 문구를 확인한다. 완성한 웹페이지 링크를 추가한 뒤 실제 페이지가 열리는지 확인한다.
