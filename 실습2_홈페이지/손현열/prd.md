# AI연수팀 소개 페이지 기획서

| 항목 | 내용 |
|---|---|
| 문서 상태 | 초안 v0.1 |
| 작성일 | 2026-11-19 |
| 작성 팀 | AI연수팀 |
| 관련 문서 | [로고 제작 프롬프트](logo-prompt.md), [제작 계획서](build-plan.md) |

## 1. 배경

AI연수팀은 AI 연수에서 배운 내용을 활용해 웹페이지를 만드는 팀이다. 팀 소개 페이지에서 연수 동료와 강사가 팀의 결과물을 열어보고, AI로 화면과 문구의 초안을 만든 뒤 미리보기로 확인하고 수정한 과정을 살펴볼 수 있게 한다.

## 2. 목표와 성공 기준

| 목표 | 확인 방법 |
|---|---|
| 방문자가 팀이 하는 일을 이해한다 | 첫 화면을 본 방문자가 AI 연수에서 배운 내용을 웹페이지 제작에 적용하는 팀이라고 설명할 수 있다. |
| 방문자가 결과물의 상태를 확인한다 | 지금은 카드에 ‘준비 중’이 표시된다. 결과물 완성 후에는 카드의 ‘웹페이지 열기’ 링크로 실제 페이지를 열 수 있다. |
| 방문자가 AI를 어디에 활용했는지 이해한다 | 적용 사례에서 화면 구성·문구 초안 요청과 미리보기·수정 과정을 순서대로 찾을 수 있다. |

## 3. 대상 사용자

| 대상 | 궁금한 점 | 기대 행동 |
|---|---|---|
| 같은 AI 연수 참가자 | 다른 팀은 AI로 어떤 페이지를 만들고 있나요? | 만든 웹페이지 섹션에서 진행 상태를 보고, 결과물이 공개되면 직접 열어본다. |
| 강사 | 연수에서 배운 방법을 어떻게 적용했나요? | 적용 사례에서 초안 요청과 미리보기 후 수정 과정을 확인한다. |

## 4. 범위

- 첫 버전은 메뉴 세 개가 있는 반응형 팀 소개 페이지다.
- 결과물 카드는 ‘준비 중’ 상태로 시작하며, 웹페이지가 완성되면 이름과 링크를 추가한다.
- 회원가입, 게시판, 문의 기능은 이번 기획 범위 밖이다.

## 5. 메뉴와 화면 순서

| 순서 | 메뉴 | 위치 | 화면 구성 |
|---|---|---|---|
| 1 | 팀 소개 | `#intro` | 팀 이름, 한 줄 소개, 개구리 마스코트 |
| 2 | 만든 웹페이지 | `#projects` | ‘준비 중’ 카드 한 장 |
| 3 | 배운 내용과 적용 사례 | `#practice` | 초안 요청과 미리보기·수정을 설명하는 카드 두 장 |

## 6. 화면 문구

### 팀 소개

- 제목 — **AI연수팀**
- 소개 — “AI 연수에서 배운 내용을 활용해 웹페이지를 만듭니다.”
- 버튼 — “만든 웹페이지 보기”. 결과물 섹션으로 이동한다.

### 만든 웹페이지

- 상태 — **준비 중**
- 설명 — “팀 웹페이지를 만들고 있어요. 완성되면 여기에 링크를 공개할 예정입니다.”
- 완성 후에는 결과물 제목과 한 줄 설명, ‘웹페이지 열기’ 링크를 넣는다.

### 배운 내용과 적용 사례

| 카드 제목 | 설명 |
|---|---|
| AI에게 화면과 문구 초안 요청하기 | AI에 웹페이지의 화면 구성과 각 영역에 들어갈 문구 초안을 요청했습니다. |
| 미리보기로 확인하고 수정하기 | 초안을 실제 화면으로 미리 본 뒤, 구성과 문구를 확인하며 수정했습니다. |

## 7. 디자인

개구리 페페에서 느껴지는 초록색과 두꺼운 윤곽선, 무심한 표정을 살린다. 마스코트는 반쯤 감긴 눈과 살짝 비대칭인 입을 가진 AI연수팀 개구리로 잡는다. (가정)

| 요소 | 값 |
|---|---|
| 메인 색 | 개구리 초록 `#82B74B` |
| 보조 색 | 연못 파랑 `#A5C6DA` |
| 포인트 색 | 차분한 주황빛 갈색 `#C57D5D` |
| 배경 / 글자와 윤곽선 | 따뜻한 아이보리 `#FFF8E8` / 짙은 녹색 `#17271D` |
| 분위기 | 느긋함, 장난기, 친근함 |
| 글꼴 | Pretendard 또는 시스템 기본 글꼴 |
| 카드 | 둥근 모서리와 짙은 테두리. ‘준비 중’ 카드는 점선 테두리 |
| 로고 | `images/logo.png`. 로고가 정해지기 전에는 팀 이름 첫 글자를 넣은 임시 로고 사용 |

## 8. 반응형과 접근성

- 데스크톱에서는 팀 소개 문구와 마스코트를 나란히, 휴대폰에서는 위아래로 배치한다.
- 적용 사례 카드는 데스크톱에서 두 열, 휴대폰에서 한 열로 배치한다.
- 640px 미만에서는 메뉴를 버튼으로 열고 닫는다. 키보드로 메뉴와 링크를 사용할 수 있고, 초점 표시가 눈에 보여야 한다.
- 375px 너비에서 가로 스크롤 없이 읽을 수 있게 한다. 상태는 색과 함께 ‘준비 중’ 문구로 표시한다.
- 팀 이름이 헤더에 텍스트로 표시될 때 옆의 로고는 장식 이미지로 처리한다. 마스코트가 별도로 표시되면 짧은 대체 텍스트를 제공한다.

## 9. 기술 조건

- 단일 `index.html`에 CSS와 JavaScript를 포함한다. 빌드 도구나 서버 없이 브라우저에서 바로 연다.
- 로고 이미지가 있으면 `images/logo.png`에서 불러오고, 이미지가 없으면 임시 표시로 전환한다.

## 11. 완료 기준

- [ ] 적용 사례에 초안 요청과 미리보기 후 수정 과정이 순서대로 보인다.

## 12. 열린 질문

- 로고는 아직 공유되지 않았다. 새 로고를 만들어 넣을지, 제작 시 임시 글자 로고로 시작할지 정한다.
- 소개할 웹페이지가 완성되면 제목, 소개 문구, 링크를 받는다.
- 실제로 수정한 화면이나 문구 사례가 정리되면 적용 사례에 전후 화면이나 예시를 추가할 수 있다.
