# 운영팀 소개 페이지 제작 계획서

## 1. 만들 것

현업 직원이 다섯 가지 상황의 해결 방법을 찾아보는 한 장짜리 운영팀 소개 페이지를 만든다. [기획서](prd.md)를 기준으로 작업한다.

## 2. 파일 구조


## 3. 준비물 체크

| 준비물 | 상태 |
|---|---|
| 참고 화면 | 별도 지정 없음. 색상표와 빠른 링크 참고 디자인을 기준으로 진행 |
| 시스템별 절차 | 공통 안내 초안 준비. 실제 경로와 승인 절차는 확인 가능할 때 보강 |

## 4. 만드는 순서

| 순서 | 할 일 | 확인 기준 |
|---|---|---|
| 1 | 헤더, 팀 소개, 운영 키워드 20개와 상황별 해결 방법 영역 배치 | 키워드를 선택하면 연결된 카드로 이동하고 안내가 펼쳐짐 |
| 2 | 기획서의 다섯 상황을 아코디언 목록으로 구성 | 각 카드에 먼저 할 일과 지원이 필요한 경우 표시 |
| 3 | 색상과 글꼴 적용 | 밝은 배경에서 안내 문구와 해시태그가 선명함 |
| 4 | 화면 너비에 따라 펼친 안내의 배치 조정 | 모든 화면에서 항목을 세로로 표시하고, 휴대폰에서는 두 안내 문단도 위아래로 배치 |
| 5 | 브라우저에서 화면 점검 | 메뉴 이동, 키보드 조작, 각 카드 열기, 375px 가로 스크롤 확인 |

## 5. 섹션별 구현 메모

- 헤더는 작은 로고, 팀 이름과 메뉴 하나로 구성한다. 브라우저 탭에도 같은 마크를 쓴다. 첫 소개 영역에는 제목과 소개 문구를 배치한다.
- 카드 제목에는 현업 직원이 쓰는 상황 문장을 그대로 쓴다.
- 오류나 승인 확인이 필요한 안내는 코랄색과 짧은 설명을 함께 사용한다.

## 6. 확인 방법

데스크톱과 375px 모바일 화면에서 첫 화면과 카드 내용을 살펴보고, 키보드만으로 메뉴 이동과 카드 펼치기를 실행한다. 기획서의 완료 기준을 따른다.
