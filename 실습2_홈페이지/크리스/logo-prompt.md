# DT팀 로고 제작 프롬프트

## 1. 기본 프롬프트
```text
DT팀의 업무 포털 로고를 만들어 줘.
초록·청록 계열(#008485 시안값), 단순한 아이콘 + DT 글자,
흰 배경, 정사각형.
인프라와 업무를 연결하는 두 개의 연결 고리를 단순한 도형으로 표현해 줘.
글자는 영문 대문자 DT를 정확하게 넣어 줘.
작은 크기에서도 선명하고 간결하며 안정적인 느낌으로 만들어 줘.
기존 은행 심볼을 복제하지 말고 독립적인 팀 로고로 구성해 줘.
```

## 2. 아이콘 아이디어
| 아이디어 | 의미 |
|---|---|
| 두 개의 연결 고리 | 인프라·계약·운영·현업 연결 |
| D와 T의 결합 | 작은 화면에서도 식별되는 팀 표시 |
| 간결한 흐름 화살표 | 반복 업무 자동화와 개선 |

## 3. 수정 문장
- 더 단순하게, 작은 화면에서도 읽히도록 만들어 줘.
- 아이콘만 글자 없이 만들어 줘.
- DT 철자를 정확하게 표현해 줘.

## 4. 이번 시안에 적용
별도 이미지 생성 없이 DT 글자 기반 인라인 SVG 로고로 먼저 제작한다. 나중에 images/logo.png가 있으면 우선 표시하고, 없거나 읽지 못하면 글자 로고를 표시한다. 참고 이미지가 없으므로 PRD의 색·여백·배치 기준을 따른다. 로고 이미지 준비는 제작의 선행 조건이 아니다.
