# DT Workspace 사용 안내

## 열기
index.html을 더블클릭하면 브라우저에서 열립니다. 별도 설치가 필요 없습니다.

## Vercel 배포
저장소: https://github.com/chriswpark00/DT_teampage

1. Vercel에서 새 프로젝트를 만들고 위 GitHub 저장소를 가져옵니다.
2. Production Branch는 main, Root Directory는 저장소 최상위(./)를 사용합니다.
3. Framework Preset은 Other, Build Command는 비워 두고 Output Directory는 .으로 설정합니다. 같은 설정을 vercel.json에 포함했습니다.
4. 환경 변수와 의존성 설치가 필요하지 않습니다. Deploy를 누르면 index.html이 첫 페이지로 표시됩니다.

참고: [Vercel 정적 사이트 빌드 설정](https://vercel.com/docs/builds/configure-a-build).
배포 후에도 데이터는 각 방문자의 브라우저에만 저장되며 직원 간에 공유되지 않습니다. 역할 선택은 시안용이며 실제 사내 인증은 별도 연결이 필요합니다.

## 역할별 확인
상단 역할 선택에서 화면을 바꿉니다.
- 직원: 장애 공지, 인프라 현황, 자동화 제안.
- 관리자: 직원 기능 + 계약 조회. 수정·삭제 불가.
- DT: 인프라·계약 등록/수정/삭제, 장애 공지 등록 및 복구 처리, 데이터 백업/초기화.

상단에는 직원 / 관리자 / DT 역할만 선택합니다. 계약과 자동화 제안은 업무 필터 없이 표시됩니다. 전광판은 한 카드에 계단측·벽면·천장 상태를 묶어 보여 줍니다. 프로그램 운영은 세부 내용이 정해질 때까지 준비 중으로 표시됩니다.

## 장애 공지
처음 보이는 장애는 화면 검토용 가상 예시입니다. DT팀 역할에서 상세 보기 → 공지 수정·복구 처리 → 복구 완료로 바꾸면 정상 안내로 전환됩니다. 복구 이력에서 완료한 내용을 확인할 수 있습니다.

## 데이터
- 모든 업체·계약·장애·담당자는 가상 데이터입니다.
- 변경 내용은 현재 브라우저에 저장됩니다. 다른 직원/브라우저와 공유되지 않습니다.
- 브라우저 데이터 삭제 또는 저장 제한 시 내용이 사라질 수 있습니다. DT팀의 데이터 백업으로 JSON 파일을 내려받을 수 있습니다. 백업 파일 가져오기는 이번 버전에 포함하지 않았습니다.
- 파일 직접 열기와 localhost 미리보기는 저장 공간이 다를 수 있습니다.
- 초기화는 현재 브라우저의 내용을 기본 가상 데이터로 되돌립니다.
- 현재 CRT 테마의 헤더는 이미지 대신 dt@workspace: ~/ops 경로를 표시합니다.

## 실제 운영 전 필요한 작업
역할 선택은 화면 검토용입니다. 실제 계정 인증과 서버의 권한 검사는 아직 연결하지 않았습니다. 실데이터를 사용하기 전 사내 로그인, 서버/API, 데이터베이스, 변경 이력과 장애 알림 연동이 필요합니다.

## 확인한 동작
2026-11-19 브라우저에서 다음을 확인했습니다.
- 직원의 계약 영역 숨김, 관리자 조회 전용, DT팀 관리 버튼 표시.
- 인프라 등록·수정·삭제, 계약 등록·수정·삭제.
- 잘못된 계약 기간 저장 차단, 계약 종류·검색 필터와 빈 결과 안내.
- 새로고침 후 인프라·계약 변경 복원.
- 장애 복구 완료 후 정상 안내로 전환.
- 자동화 제안 등록 및 모든 역할에 공통 장애 표시.
- 375px 모바일과 1280px 데스크톱에서 가로 넘침 없음, 모바일 메뉴 열기·닫기.

기획 문서는 prd.md, logo-prompt.md, build-plan.md를 참고하세요.

## CRT 터미널 디자인
사용자 제공 프롬프트에 맞춰 검정 배경, 형광 초록 글자, 스캔라인, 모노스페이스 글꼴, 터미널 창 프레임과 명령어 제목을 적용했습니다. 장애 알림은 앰버색으로 강조합니다. OS/브라우저의 동작 줄이기 설정에서는 커서와 상태 점이 깜박이지 않습니다. Google Fonts를 읽지 못해도 대체 글꼴로 사용할 수 있습니다.

이전 초록·흰색 디자인은 index-before-crt.html에 보관했습니다. 현재 화면은 index.html입니다.

## 전광판 컨트롤러
전광판 통합 카드의 버튼은 https://example.com/ 예시 주소를 새 탭으로 엽니다. 실제 장비를 연결하거나 조작하지 않습니다. 주소를 변경하려면 index.html의 DISPLAY_CONTROLLER_URL 값을 바꾸면 됩니다.
