# DT팀 업무 포털 제작 계획서

## 1. 만들 것
그룹 직원이 필요한 운영 정보를 빠르게 확인하는 한 장짜리 업무 포털 시안. PRD의 역할별 화면과 장애 우선 배치를 구현한다.

## 2. 파일 구조
```text
2. 팀 페이지 생성/
├─ prd.md
├─ logo-prompt.md
├─ build-plan.md
├─ index.html          ← 기획 검토 후 제작
└─ images/             ← 제작 시 생성
   ├─ logo.png         ← 선택
   └─ reference.png    ← 선택
```

## 3. 준비물 체크
| 준비물 | 상태 | 적용 |
|---|---|---|
| 로고 | 없음 | DT 글자 로고 사용 |
| 참고 자료 | 사용자 디자인 프롬프트·레이아웃 텍스트 | 검정·형광 초록 CRT 터미널. 업무 포털의 기능·권한 유지 |
| 데이터 | 실제 데이터 미사용 | 가상 전광판·업체·계약·장애 |
| 문의처 | 미정 | 예시 값 |
| 실제 인증·서버 | 시안 범위 밖 | 역할 전환으로 화면 검토 |

## 4. 만드는 순서
| 단계 | 할 일 | 검증 |
|---|---|---|
| 1 | 가상 데이터 모델과 역할별 표시 규칙 정의 | PRD 권한표와 일치 |
| 2 | 헤더·메뉴·최상단 장애 알림 구현 | 첫 화면에서 영향·상태 파악 |
| 3 | 핵심 요약 및 인프라 현황 구현 | 전광판 위치 세 가지 구분 |
| 4 | 계약 목록·종류/예산 필터·만료 표시 | 일반 직원에게 계약 정보 미표시 |
| 5 | DT팀의 등록·수정·삭제 및 장애 공지 변경 | 관리자 조회 전용, 입력 검증·삭제 확인 |
| 6 | 프로그램 운영 준비 중 및 자동화 제안 | 빈 목록과 접수 피드백 |
| 7 | 브라우저 저장·가상 데이터 초기화·백업 | 새로고침 후 복원과 저장 실패 처리 |
| 8 | 모바일·키보드 검토 | 375px, 가로 스크롤·초점·메뉴 확인 |

## 5. 섹션별 구현 메모
| 섹션 | 레이아웃 및 동작 |
|---|---|
| 헤더 | 고정 메뉴, 역할 선택(직원 / 관리자 / DT). 모바일 메뉴는 접기 |
| 장애 알림 | 모든 역할에 공통으로 우선 표시. 정상/조치 중/복구 완료 구분 |
| 요약 | 짧은 제목·숫자·상태. 권한 없는 계약 요약은 제거 |
| 인프라 | 전광판 한 카드에 계단측·벽면·천장 통합. 새 탭 컨트롤러 버튼. DT팀에만 개별 관리 버튼 |
| 계약 | 넓은 화면은 간결한 표, 좁은 화면은 카드. 종료일에서 만료일·남은 기간 계산 |
| 프로그램 운영 | 준비 중 배지와 점선 카드. 확정하지 않은 업무를 만들어 넣지 않음 |
| 자동화 제안 | 짧은 입력 폼과 목록. 전체 공개는 가정 |

화면에는 운영 정보와 행동 중심 문구를 사용한다. 시안 역할 선택에는 검토용임을 짧게 표시하며 서버 구현 설명을 사용자 화면에 길게 넣지 않는다.

## 6. 확인 방법
- 일반 직원: 계약 메뉴·목록·숫자 미표시, 인프라 조회 가능, 변경 불가.
- 지정 관리자: 계약 조회 가능, 인프라·계약 변경 불가.
- DT팀: 가상 인프라·계약 등록→수정→삭제, 장애 등록→상태 변경→복구 확인.
- 역할을 바꿀 때 열려 있던 상세·수정 화면도 닫고 새 권한에 맞게 재표시.
- 상단 업무 필터 없이 역할만 선택. 모든 역할에 공통 장애 알림 유지.
- 전광판 컨트롤러의 예시 URL과 새 탭 열기 확인.
- 빈 목록, 만료일 경계, 잘못된 기간, 취소, 저장 실패를 확인.
- 데스크톱·375px에서 메뉴 이동, 폼, 최상단 장애 노출, 가로 넘침 확인.
- 브라우저 검토가 불가능하면 그 한계를 알리고 index.html을 직접 여는 방법을 안내.

## 7. 실제 운영 확장
SSO 로그인 → 서버 권한 검사 → 데이터베이스/API → 변경 감사 이력 → 장애 감지/공지 연동 순으로 별도 구축한다. 부서·업무별 구독과 공통 공지의 우선순위를 정의한다. 브라우저 시안의 데이터 숨김은 운영 환경의 접근 통제를 대신하지 않는다.

## 8. 만든 뒤 고치기 예시
- 장애 알림에 예상 복구 시간을 추가해 줘.
- 계약 만료 예정 기준을 60일로 바꿔 줘.
- 프로그램 운영에 점검 일정과 담당자 메뉴를 추가해 줘.
- 영업 담당자에게 필요한 바로가기를 추가해 줘.
