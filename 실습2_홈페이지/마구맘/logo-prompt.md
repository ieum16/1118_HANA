# 브릿지팀 로고 프롬프트

## 기본 프롬프트

```text
브릿지팀의 로고를 만들어 줘.
브릿지팀은 고객 문의를 분석해 서비스 개선점을 찾는 팀이야.
흰 배경의 정사각형 안에 단순한 다리 아이콘과 한글 팀 이름 ‘브릿지팀’을 넣어 줘.
다리 양쪽에 점을 하나씩 배치해 고객의 목소리와 서비스 개선을 잇는 모습을 표현해 줘.
메인 색은 남색(#17345B), 포인트 색은 파랑(#2563EB)으로 써 줘.
작은 크기로 봐도 아이콘과 팀 이름이 선명하게 보이도록 해 줘.
```

## 아이콘 아이디어

| 아이디어 | 의미 |
|---|---|
| 다리와 양쪽의 점 | 고객의 목소리와 서비스 개선을 연결한다. |
| 말풍선 안의 세 점과 강조점 | 여러 문의에서 반복되는 주제를 찾는다. |
| 포개진 두 말풍선 | 여러 고객이 겪은 공통 문제를 찾는다. |

## 수정 문장 예시

- “다리의 선을 줄여서 작은 크기에서도 형태가 잘 보이게 해 줘.”
- “홈페이지 헤더에 쓸 수 있도록 글자 없이 아이콘만 한 장 더 만들어 줘.”
- “한글 팀 이름은 정확히 ‘브릿지팀’으로 넣어 줘.”
