# 브릿지팀 소개 페이지 제작 계획서

[기획서](prd.md)를 기준으로 새 팀원용 소개 페이지 `index.html`을 제작한다.

## 파일 구조

```text
team-page/
├── prd.md
├── logo-prompt.md
├── build-plan.md
├── index.html           제작 예정
└── images/              이미지 제공 시 사용
    ├── logo.png
    └── reference.png
```

## 준비물

| 항목 | 현재 상태 | 적용 방식 |
|---|---|---|
| 로고 | 제공 전 | 로고가 오면 적용하고, 그전에는 ‘브릿지팀’ 글자 로고를 사용한다. |
| 참고 화면 | 제공 전 | 기획서의 남색과 옅은 하늘색을 기준으로 배치한다. |
| 문의 채널 | 확인 전 | 예시 채널로 표시하고, 실제 주소를 받으면 링크를 연결한다. |

## 제작 순서

| 순서 | 작업 | 확인할 점 |
|---|---|---|
| 1 | 상단 메뉴와 섹션 세 개를 배치한다. | 메뉴가 팀 소개, 하는 일, 문의 공유로 이동한다. |
| 2 | 첫 화면에 팀 이름, 한 줄 소개, 문의 공유 버튼을 넣는다. | 페이지를 처음 열면 팀의 역할을 읽고 문의 공유로 이동할 수 있다. |
| 3 | 업무 카드 세 개에 설명과 예시를 넣는다. | 유형 분류에서 개선안 제안까지 업무 흐름이 이어진다. |
| 4 | 문의 공유 안내와 작성 예시를 넣는다. | 어떤 정보를 정리해야 하는지 예시로 확인할 수 있다. |
| 5 | 색, 타이포그래피, 반응형 메뉴와 카드 배치를 적용한다. | 모바일 메뉴를 사용할 수 있고 긴 문장이 화면 안에서 줄바꿈된다. |
| 6 | 브라우저에서 기획서의 완료 기준을 확인한다. | 375px과 1280px에서 화면과 메뉴를 확인한다. |

## 화면 배치

| 영역 | 데스크톱 | 모바일 |
|---|---|---|
| 상단 메뉴 | 로고 왼쪽, 메뉴 오른쪽 | 로고와 접이식 메뉴 버튼 |
| 팀 소개 | 팀 이름과 소개, 문의 공유 버튼 | 소개와 버튼을 위아래로 배치 |
| 하는 일 | 카드 3열 | 카드 1열 |
| 문의 공유 | 공유 항목과 작성 예시를 나란히 배치 | 공유 항목 아래에 작성 예시 배치 |

## 확인 방법

1. 브라우저에서 `index.html`을 열고 팀 소개와 업무 카드 세 개를 확인한다.
2. 메뉴와 문의 공유 버튼으로 각 섹션에 이동해 제목이 헤더 뒤로 가려지지 않는지 확인한다.
3. 375px에서 메뉴를 열고 항목을 선택한다. 가로 스크롤이 없고 메뉴가 닫히는지 확인한다.
4. 키보드로 모든 메뉴와 버튼에 접근할 수 있는지 확인한다.
