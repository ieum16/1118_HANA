# 연금팀

## 한 줄 소개

연금 업무에 필요한 프로그램을 개발하는 팀을 소개합니다.

## 누구를 위해 만들었나요

연금 프로그램 개발자와 연금 업무 담당자가 진행 상황과 개발툴 안내를 한곳에서 확인할 수 있도록 만들었습니다.

## 페이지 구성

- 연금팀 소개
- 프로그램 개발 현황
- 프로젝트 진행 현황
- 개발툴 매뉴얼

## 배포 주소

https://teampagetest-zeta.vercel.app/
