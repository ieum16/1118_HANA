# 연금팀 소개 페이지 제작 계획서

기획 초안을 확인받은 뒤 세 메뉴가 있는 반응형 페이지를 `index.html` 한 파일로 제작합니다. CSS와 JavaScript는 같은 파일에 담습니다.

| 순서 | 제작 작업 | 확인 방법 |
|---|---|---|
| 1 | 상단 로고, 팀 소개, 세 메뉴와 섹션을 배치 | 메뉴를 눌러 해당 섹션으로 이동하는지 확인 |
| 2 | 프로그램 카드, 프로젝트 카드, 개발툴 매뉴얼 목록 작성 | 개발 단계와 프로젝트 일정이 쉽게 읽히고 예시와 준비 중 항목에 표기가 있는지 확인 |
| 3 | 민트와 아이보리 색상, 둥근 카드, 헤더 로고 적용 | 배경과 글자의 대비, 로고 비율과 대체 텍스트 확인 |
| 4 | 모바일 메뉴와 카드 배치 구현 | 375px에서 한 열로 읽히는지, 메뉴 열기와 닫기가 키보드로도 가능한지 확인 |
| 5 | 브라우저에서 최종 점검 | 375px와 1280px에서 가로 스크롤과 링크 동작 확인 |

## 파일 구조

```text
team-page/
├─ prd.md
├─ logo-prompt.md
├─ build-plan.md
├─ index.html
└─ images/
   ├─ logo.png
   └─ reference.png (선택)
```

로고 파일을 받기 전에는 헤더에 `연금팀` 글자를 표시합니다. 팀 콘텐츠를 받기 전에는 가상의 프로그램 및 프로젝트를 `예시`로 표시하고, 자료가 없는 매뉴얼은 `준비 중`으로 표시합니다.
