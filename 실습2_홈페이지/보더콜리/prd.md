## 배경과 목표

연금팀은 연금 업무에 필요한 프로그램을 개발합니다. 이 페이지에서 연금 프로그램 개발자와 연금 업무 담당자가 프로그램과 프로젝트의 진행 상황을 확인하고, 개발툴 사용 안내를 찾을 수 있도록 합니다.

| 방문자 | 페이지에서 확인할 내용 |
|---|---|
| 연금 프로그램 개발자 | 프로그램별 개발 단계, 프로젝트의 다음 일정, 개발툴 사용법 |
| 연금 업무 담당자 | 필요한 프로그램의 개발 상태, 관련 프로젝트의 진행 상황 |

## 메뉴와 화면 순서

상단에는 로고와 메뉴를 표시합니다. 첫 화면에 팀 이름과 “연금 업무에 필요한 프로그램을 개발합니다.”를 배치하고, 아래 세 섹션을 메뉴 순서대로 배치합니다.

| 메뉴 | 표시 항목 (초안) |
|---|---|
| 프로그램 개발 현황 | 프로그램 이름, 용도, 개발 단계 |
| 프로젝트 진행 현황 | 프로젝트 이름, 현재 단계, 다음 일정 |
| 개발툴 매뉴얼 | 도구 이름, 쓰는 상황, 사용 절차 |

진행 상태는 `예정`, `진행 중`, `완료`로 표시합니다. 실제 내용이 제공되기 전에는 가상의 카드에 `예시`를 표시합니다. 제공되지 않은 매뉴얼은 `준비 중`으로 표시합니다.

## 디자인

- 밝은 민트 `#DDF4EB`, 따뜻한 아이보리 `#FFFAF2`, 진한 청록 `#205449`를 사용합니다. 색상 코드는 초안입니다.
- 연한 배경과 둥근 카드 모서리로 따뜻한 분위기를 냅니다. 진행 상태는 텍스트로도 표시합니다.
- 상단에 하나은행 퇴직연금 로고를 배치합니다. 이미지 파일을 받기 전에는 `연금팀` 글자를 표시합니다.

## 기술 조건과 완료 기준

빌드 도구 없이 브라우저에서 열 수 있는 `index.html`로 제작합니다.

- [ ] 세 메뉴를 누르면 해당 섹션으로 이동한다.
- [ ] 개발 단계와 프로젝트 단계가 각 섹션에서 한눈에 보인다.
- [ ] 개발툴 매뉴얼의 제공 여부를 확인할 수 있다.
- [ ] 375px와 1280px에서 가로 스크롤 없이 읽을 수 있고, 모바일 메뉴가 키보드로도 동작한다.
- [ ] 로고 파일이 제공되면 원본 비율과 대체 텍스트를 유지해 표시한다.

## 확정할 콘텐츠

- 프로그램과 프로젝트의 표시 이름, 진행 단계, 공개할 일정
- 개발툴 목록과 매뉴얼 내용
- 하나은행 퇴직연금 로고 이미지 파일
