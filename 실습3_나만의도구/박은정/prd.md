# 주간업무회의 대시보드 기획서

## 사용자와 목적

주간회의 자료 취합 담당자 한 명이 팀원별 업무 내용과 이미 집계된 캠페인 수치를 한 화면에 모읍니다. 기존에는 매주 약 30분이 걸렸으며, 사용 후 실제 작성 시간을 비교합니다.

## 입력과 출력

| 입력 | 처리 및 출력 |
|---|---|
| 보고 주 | 선택한 주의 월요일을 기준으로 전주 월~일 집계 기간 표시 |
| 전체 발송 건수, 실행 건수(손님 수 기준·중복 포함), 문자·푸시·인앱 발송 건수, 사용 부서 수 | 가로표, 주요 지표 카드, 채널 막대 차트와 최근 6주 발송·실행 추이 |
| 이슈 제목과 본문, 단위 업무명과 현황·개선 전·개선 후 | 입력한 줄바꿈을 살려 선택한 주의 Word 회의자료에 출력 |

## 꼭 필요한 기능

1. 캠페인 수치를 직접 입력하거나 가로표에서 붙여넣고 실적을 확인합니다.
2. 운영 이슈와 추진 업무를 주차별로 작성하고 저장합니다.
3. 선택한 보고 주의 회의자료를 편집 가능한 Word(.docx)로 내려받습니다.

## 예외와 조건

- 집계 수치에는 0 이상 정수를 사용합니다. 0과 미입력은 구분하고, 필수 수치가 비었거나 잘못되면 Word 저장 전에 표시합니다.
- 최근 6주 차트는 브라우저에 저장된 값을 사용하며, 미입력 주는 빈칸으로 표시합니다.
- HTML 한 파일을 브라우저에서 엽니다. 실습 예시는 가상 데이터이며 입력 내용은 브라우저에서 처리합니다. 주차별 저장 내용을 JSON으로 백업하고 복원할 수 있습니다.

## 있으면 좋은 기능
