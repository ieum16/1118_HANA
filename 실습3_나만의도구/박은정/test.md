# 주간업무회의 대시보드 테스트

## 꼭 필요한 기능

| 번호 | 해 볼 것 | 기대 결과 | 결과 |
|---|---|---|---|
| 1 | 캠페인 입력표에 1200, 950, 600, 400, 200, 5 입력 | 카드에 1,200·950·5, 채널 차트에 문자 600·푸시 400·인앱 200 표시 | ○ |
| 2 | 다른 주로 바꿨다가 돌아오고 새로고침 | 기존에 입력한 이슈와 추진 업무가 해당 주에 남음 | ○ |
| 3 | 여러 줄 이슈를 입력하고 Word 파일 저장 | .docx에 캠페인 가로표와 이슈 제목·본문이 별도 문단으로 들어가고 줄바꿈이 유지됨 | ○ |

## 예외 상황

| 번호 | 해 볼 것 | 기대 결과 | 결과 |
|---|---|---|---|
| 4 | 캠페인 입력란에 0을 입력한 뒤 문자로 바꿈 | 0은 카드에 0으로 표시되고 문자는 유효한 수치로 표시되지 않음 | ○ |
| 5 | 보고 주를 2027-01-04로 변경 | 전주 집계 기간이 2026-12-28~2027-01-03으로 표시 | ○ |
| 6 | 화면 너비를 375px로 줄임 | 화면 전체는 가로로 넘치지 않고 캠페인 입력표 안에서 좌우 이동 가능 | ○ |

## 보조 기능

| 번호 | 해 볼 것 | 기대 결과 | 결과 |
|---|---|---|---|
| 7 | JSON 백업 후 내용을 수정하고 백업 복원 | 백업 시점의 이슈와 수치가 다시 표시됨 | ○ |
| 8 | 여러 주에 발송·실행 건수 입력 후 최근 6주 차트 확인 | 해당 주에 입력한 수치가 막대와 설명에 반영됨 | ○ |

브라우저 동작과 내려받은 .docx의 문서 구조를 확인했습니다. Microsoft Word 데스크톱 앱에서 직접 여는 확인은 남아 있습니다.
