# 주간업무 워크스페이스 · teamteum PRD

작성일: 2026-11-19

## 배경과 목표

프로젝트 업무와 직접 입력한 업무를 금주 실적·차주 계획으로 정리해 주간보고를 반복 작성하는 수고를 줄입니다. 실제 배포 중인 독립 페이지 `workspace.html`을 실습3 제출용으로 준비합니다.

## 대상 사용자

이번 주 업무와 다음 주 계획을 보고서로 정리하는 팀원입니다. 체험용 담당자는 햄스터·냥이·토끼이며, 프로젝트와 업무는 소스에 포함된 가상 예시입니다.

## 꼭 필요한 기능

1. **업무 취합과 보고서 생성:** 기준일에 해당하는 가상 프로젝트를 불러와 선택한 업무를 금주 / 완료여부 / 차주 / 기한 표로 정리합니다. 생성 후 프로젝트 목록은 접힙니다.
2. **수기 입력과 편집:** 제목·담당자·업무 구분·완료여부·금주 업무·차주 계획·기한을 입력합니다. 전체·기획·개발·검토·기타로 분류해 확인하고 보고서 내용을 수정합니다. 진행 업무를 위, 완료 업무를 아래에 표시하며 완료 업무의 차주 내용과 기한은 비웁니다.
3. **저장과 활용:** 필터와 관계없이 전체 보고서 한 개를 브라우저에 저장합니다. 현재 업무 구분의 내용을 복사할 수 있으며 업무별 삭제와 전체 삭제를 제공합니다.

## 주간 계산과 입력 규칙

- 기준일은 수요일입니다. 금주는 전날인 화요일부터 다음 월요일, 차주는 그다음 화요일부터 월요일입니다.
- 예시 기준일 `2026-11-18`: 금주 `11/17~11/23`, 차주 `11/24~11/30`. 이 기간에는 가상 업무 7건이 조회됩니다.
- 수기 업무는 제목과 금주 또는 차주 내용이 필요합니다. 완료 업무는 금주 내용이 있어야 합니다.
- 기한은 실제 날짜를 `MM.DD` 형식으로 처리합니다. `02.30`처럼 존재하지 않는 날짜는 거부합니다.
- 내장 데이터는 2026년 11월의 예시입니다. 다른 기간에는 조회할 가상 업무가 없을 수 있습니다.

## 화면 구성

페이지를 열면 **주간업무 워크스페이스**가 바로 나타납니다. 기준일 선택 → 금주·차주 기간 → 프로젝트 목록 → 팀 주간보고 순서이며, 아래에는 이용 안내가 있습니다.

흰 배경과 검은 글씨를 사용합니다. 상단과 하단에는 팀 홈페이지로 돌아가는 링크가 있습니다. 복사가 성공하면 완료 알림을 표시하고, 브라우저에서 자동 복사를 허용하지 않으면 직접 복사할 텍스트를 표시하도록 구현되어 있습니다.

대표 화면은 실제 독립 워크스페이스에서 가상 주간보고를 생성하고 개발 업무 3건으로 분류한 화면을 사용합니다.

## 기술과 데이터

- CSS와 JavaScript를 포함한 HTML과 `favicon.svg`로 구성된 정적 웹 도구입니다. 별도 빌드·로그인·서버 API가 필요하지 않습니다.
- 업무 입력은 브라우저 안에서 처리하며, 소스에서 외부 서버로 전송하는 요청 코드는 발견하지 못했습니다.
- 저장은 localStorage를 사용하며 저장 버튼을 눌러야 합니다. 자동 저장과 다른 기기 간 동기화는 지원하지 않습니다.
- 제출 파일에는 사용자의 브라우저 저장 공간에 있는 개인 보고서가 포함되지 않습니다. 배포 페이지에서 저장한 내용이 내려받은 파일로 자동 복사되지는 않습니다.
