# 실습3 · 나만의 도구 만들기

내 업무에서 매일 · 매주 귀찮은 일 하나를 줄이는 작은 웹 도구를 만듭니다. (교안 2라운드 · 실습 ⑪~⑬)

- 조건: `index.html` 파일 하나 · 로그인 없음 · **가짜 데이터만** · 꼭 필요한 기능 3개 이하
- 예: 예적금 만기 계산기, 환전 계산기, 안내 문자 작성기, 금지어 점검기, 중도상환수수료 계산기, 개인정보 마스킹기, 가상 실적 현황판
