# 주간노트 테스트 체크리스트

2026-11-19 기준. ○는 명시한 방식으로 확인한 항목이며, 미확인은 실제 브라우저 조작이나 사용자 환경에서 추가로 확인할 항목이다.

JavaScript 구문과 데이터 처리에 대해 코드 기반 점검 20개를 통과했다. 이후 타이핑 효과, 모션 감소 설정 대응, 주아체 포함, 별 캐릭터 3개와 색상 적용을 별도로 점검했다. 배포 주소를 Chrome에서 열어 가상 예시와 세 영역이 표시되는 것을 확인하고 screenshot.png를 저장했다.

## 꼭 필요한 기능

| 번호 | 해 볼 것 | 기대 결과 | ○/× |
|---|---|---|---|
| 1 | 배포 주소 열기 | 주간노트와 가상 메모 3건, 주간 업무 예시 1건이 표시됨 | ○ · 배포 화면 확인 |
| 2 | 동일 메모를 주간 업무에 두 번 담기 | 업무가 한 건으로 유지되고 중복 연결을 방지함 | ○ · 코드 실행 |
| 3 | 다음 주로 이동해 전주 계획을 두 번 가져오기 | 새 주에는 한 건만 생성되고 전주 원본은 유지됨 | ○ · 코드 실행 |
| 4 | 전주 계획 가져오기 직후 확인 | 새 Due-date와 실제 실적이 빈 값으로 시작함 | ○ · 코드 실행 |
| 5 | 보고서 초안 만들기 | 업무명·전주 실적·이번 주 계획·특이사항·Due-date가 생성됨 | ○ · 코드 실행 |
| 6 | 보고서 셀 수정 후 예시 지우기 | 직접 수정한 보고 문장은 남음 | ○ · 코드 실행 |
| 7 | 메모 개별·일괄 입력 후 새로고침 | 입력한 건수와 원문이 브라우저에 보존됨 | 미확인 · 실제 조작 필요 |
| 8 | 백업 파일 저장 후 복원 | 메모·주간 업무·수정한 보고서가 복원됨 | 미확인 · 파일 왕복 필요 |
| 9 | 표 또는 텍스트 복사 | 5개 열의 보고서 내용을 원하는 문서에 붙여 넣을 수 있음 | 미확인 · 클립보드 조작 필요 |

## 예외 상황

| 번호 | 해 볼 것 | 기대 결과 | ○/× |
|---|---|---|---|
| 1 | 2027-01-01의 주 시작일 계산 | 2026-12-28로 계산됨 | ○ · 코드 실행 |
| 2 | 윤년 날짜와 잘못된 날짜 확인 | 2028-02-29는 유효하고 2026-02-30은 거부됨 | ○ · 코드 실행 |
| 3 | 보고 대상 주 밖 Due-date가 든 백업 검증 | 백업이 거부됨 | ○ · 코드 실행 |
| 4 | 다른 창에서 저장 데이터가 바뀐 상태에서 저장 | 기존 데이터를 덮어쓰지 않고 충돌 안내 | ○ · 코드 실행 |
| 5 | HTML 특수문자를 보고서로 내보내기 | 태그가 실행되지 않고 글자로 처리됨 | ○ · 코드 실행 |
| 6 | 메모·업무명에 공백만 입력 | 입력 안내 후 저장을 막음 | 미확인 · 실제 조작 필요 |
| 7 | 375px 화면에서 확인 | 한 열 배치, 페이지 가로 스크롤 없음 | 미확인 · 실제 화면 확인 필요 |

## 있으면 좋은 기능

| 번호 | 해 볼 것 | 기대 결과 | ○/× |
|---|---|---|---|
| 1 | 제목 타이핑 효과 진행 | 글자가 한 글자씩 나타나고 전체 표시 후 지워짐 | ○ · 코드 실행 및 배포 화면 확인 |
| 2 | 모션 감소 설정 적용 | 제목 전체가 정적으로 표시됨 | ○ · 코드 실행 |
| 3 | 폰트와 세 영역 제목 확인 | 포함된 주아체와 웃는 별 캐릭터 표시 | ○ · 배포 화면 확인 |
| 4 | 자유 문장 AI 다듬기 | 추후 기능으로 검토 | 미구현 |

입력 내용을 외부 서비스로 전송하는 fetch, XMLHttpRequest 또는 외부 form action 코드는 사용하지 않는다. 예시는 가상 업무이며 실제 작성 내용은 브라우저 저장소에 보관된다.
