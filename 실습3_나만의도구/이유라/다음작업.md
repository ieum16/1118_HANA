## 1. 주간노트의 실제 사용 흐름 확인

가장 먼저 배포된 주간노트에서 가상 업무를 입력하며 메모부터 보고서 복사까지 한 번 완주한다. 일상 업무에 쓰기 위한 저장과 백업 동작을 우선 확인한다.

- [ ] 배포 주소를 열어 세 영역과 최신 디자인을 확인한다.
- [ ] 가상 메모를 한 건씩, 여러 줄로 입력하고 새로고침해 모두 남는지 확인한다.
- [ ] 주간 업무에 담고 상태, 계획, Due-date를 입력한다. 주를 이동했다 돌아와 보존 여부를 확인한다.
- [ ] 다음 주에 전주 계획을 두 번 가져와 중복이 생기지 않고 전주 원본이 유지되는지 확인한다.
- [ ] 보고서 초안을 수정하고 주 이동·새로고침 후에도 문구가 보존되는지 확인한다.
- [ ] 백업을 내려받고 가상 기록을 변경한 뒤 복원해 메모·업무·수정한 초안이 돌아오는지 확인한다. 실제 기록이 있으면 먼저 별도 백업을 보관한다.
- [ ] 표와 텍스트를 문서 편집기에 붙여넣어 5열, 줄바꿈, 특수문자가 유지되는지 확인한다. 컨플루언스 결과는 사용자 환경에서 확인한다.
- [ ] 공백 입력 안내와 375px 화면의 가로 넘침을 확인한다.

확인한 날짜·환경·결과를 `test.md`에 기록한다. 문제가 있으면 재현 순서와 기대 결과를 남기고 수정 후 해당 흐름을 다시 확인한다. 실제 조작으로 통과한 항목만 완료로 바꾼다.
