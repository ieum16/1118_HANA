## 1. 풀 문제

매주 메모장에 초안을 작성하고 컨플루언스로 옮긴다. 지난주에 한 일이 산발적으로 기억나고, 미완료 업무의 진척을 설명하거나 보고용 문장으로 정리하는 데 시간이 든다.

| 항목 | 현재 | 목표 |
|---|---|---|
| 업무 회상 | 기억과 흩어진 메모를 찾아 정리 | 날짜별 메모를 업무별로 모아 확인 |
| 미완료 업무 | 지난주 계획을 찾아 수정 | 지난주 계획을 참고해 진행 내용과 이번 주 계획 작성 |
| 문장 작성 | 구어체 메모를 직접 다듬음 | 상태와 다음 조치가 드러나는 초안을 만들고 수정 |
| 소요 시간 | 미확인 | 실제 사용 후 비교 (가정) |

## 2. 사용자와 사용 장면

- 개인이 PC 브라우저에서 사용한다 (가정).
- 평소 업무 중 짧게 기록하고 금요일에 모아 정리한다.
- 작성 시점에 여러 메모를 한 번에 입력하는 방식도 지원한다.
- 월요일 시작, 일요일 종료의 주간 구분을 사용한다 (가정).
- 보고 대상 주를 선택하면 전주 실적과 해당 주 계획을 작성한다. 금요일에는 다음 주를 보고 대상 주로 선택해 방금 보낸 주의 실적과 다음 주 계획을 준비할 수 있다.

## 3. 페이지를 열었을 때

선택한 주, 최근 메모, 지난주 계획과 진행 상태가 보인다. 빠진 기록을 보충하고 상태와 완료 예정일을 정한 후 보고서를 확인한다.

## 4. 첫 버전의 세 영역

| 영역 | 기능 | 줄이는 불편 |
|---|---|---|
| 업무 메모 | 날짜·업무명·내용 기록, 여러 줄 일괄 등록, 수정·삭제 | 업무를 뒤늦게 떠올리는 부담 |
| 주간 업무 정리 | 메모 참조, 전주 계획 가져오기, 상태·실적·계획·특이사항·완료 예정일 편집 | 진행 중인 일의 재작성 |
| 보고서 초안 | 5개 열로 생성, 보고 문구 제안, 직접 수정, 표와 텍스트 복사 | 보고용 표현과 양식 정리 |

| 대상 | 필드 | 종류 | 필수 | 가상 예시 |

| 주간 업무 | 전주 실적 | 글 | - | 검토 요청 발송. 담당자 회신 대기 중. |

| 주간 업무 | 특이사항 | 글 | - | 회신 지연으로 일정 이월. |

| 보고 초안 | 보고 대상 주·편집한 셀 | 날짜·글 | ○ | 사용자가 확인한 최종 문장 |
| 공통 | 예시 여부·생성 시각·수정 시각 | 체크·시각 | ○ | 예시 여부 참 |

Due-date는 해당 주 계획을 끝낼 예정일이다. 보고 대상 주에 포함되는 날짜로 입력한다. 미정이면 비워 두고 보고서에 ‘미정’으로 표시한다. 날짜를 자동으로 미뤄 기록하지 않는다.

## 7. 기능 상세

### 업무 메모

- 날짜와 업무명을 지정하고 내용 입력 후 저장한다.
- 여러 줄 입력은 한 줄을 메모 한 건으로 등록한다. 날짜와 업무명은 입력 시 지정한 값을 공통 적용한다.
- 기간·업무명으로 기록을 찾아보고 주간 업무에 연결한다. 메모의 원문과 날짜를 확인할 수 있다.

### 주간 업무 정리

- 보고 대상 주별로 업무를 추가·수정·삭제한다.
- 선택한 주의 전주 메모를 참고해 전주 실적을 작성한다. 이번 주 메모도 선택해 참고할 수 있다.
- 전주 계획 가져오기는 원본 계획과 상태를 보여 주고 사용자가 가져올 업무를 선택한다.
- 전주 기록을 보존하고 새 주에 별도 행을 만든다. 동일 원본을 다시 가져와 중복 행을 만들지 않는다.
- 가져온 계획은 참고 내용으로 제공한다. 사용자가 실제 진행 내용과 이번 주 계획을 확인한다.
- 완료 상태와 미완료 상태 모두 사용자가 직접 결정한다. 이월 시 진행 내용, 지연 사유, 다음 조치를 적을 수 있다.

### 보고서 초안

- 열 순서는 업무명 / 전주 실적 / 이번 주 계획 / 특이사항 / Due-date로 고정한다.
- 입력한 상태·진행 내용·다음 조치를 이용하는 규칙 기반 문구 제안을 제공한다. 자유 문장의 의미를 해석하는 AI 연결은 추후 확장 항목이다.
- ‘담당자 회신 대기 중’, ‘검토 완료 예정’ 같은 표현을 제안한다. 입력하지 않은 실적, 원인, 진척률을 생성하지 않는다.
- 제안 문장을 미리 보고 적용하며, 보고서 셀은 직접 수정할 수 있다.
- 원본 업무 변경 후 초안 재생성 시 직접 수정한 내용의 교체를 확인한다.
- HTML 표와 일반 텍스트를 클립보드에 복사한다. 컨플루언스 편집기에서의 붙여넣기 형태는 실제 환경에 따라 확인한다. 표 복사 미지원 시 텍스트 복사를 제공한다.

### 공통

- 새로고침 후에도 기록과 초안을 유지한다.
- 앱 데이터 전체를 JSON으로 백업하고 유효한 백업을 복원한다. 복원 전 교체 확인을 받는다.
- 가짜 업무 예시 3~5건을 제공한다. 예시 지우기는 예시로 표시된 데이터만 제거한다.
- 입력 내용을 HTML로 실행하지 않고 글자로 표시한다.

## 8. 범위

첫 버전은 로컬 HTML 한 파일, 세 영역, 주별 기록 보존, 문구 제안, 복사와 백업 기능으로 구성한다.

추후 확장 후보는 AI 문장 다듬기와 컨플루언스 직접 등록이다. 실제 컨플루언스 등록은 사용자가 복사한 초안을 붙여 넣어 진행한다.

## 9. 디자인

은은한 세이지 그린과 밝은 배경을 사용한다. 주아체를 HTML 안에 포함하며 본문은 16px 이상으로 표시한다. 제목에는 타이핑 효과를, 세 영역 제목에는 웃는 별 캐릭터를 적용한다. 상태를 글자로 표시하고 날짜와 편집 버튼을 명확히 구분한다.

## 10. 기술 조건과 저장

- index.html 한 파일에 CSS와 JavaScript를 포함하며 더블클릭으로 연다.
- localStorage에 저장하며 읽기·쓰기 실패 시 안내하고 화면과 현재 입력을 유지한다.
- 브라우저 기록 삭제로 데이터가 사라질 수 있으므로 백업 기능과 안내를 제공한다.
- 외부로 데이터를 전송하지 않는다. 예시에는 가상 업무를 사용한다.

## 11. 완료 기준

- [ ] 메모를 개별·일괄 추가한 후 새로고침해도 보존된다.
- [ ] 전주 계획을 가져오고 상태·진척·기한을 바꿔도 전주 기록은 유지된다.
- [ ] 같은 계획을 다시 가져와도 중복되지 않는다.
- [ ] 선택한 주에 맞는 전주 실적과 이번 주 계획이 5개 열에 표시된다.
- [ ] 해당 주 밖의 Due-date에는 수정 안내가 표시된다.
- [ ] 보고 문구를 제안받고 직접 수정한 뒤 복사할 수 있다.
- [ ] 백업 복원 후 메모·주간 업무·수정된 보고 초안이 일치한다.
- [ ] 잘못된 백업은 기존 데이터를 변경하지 않는다.
- [ ] 375px 폭에서 페이지 가로 스크롤이 없다.
- [ ] 컨플루언스 실제 붙여넣기 결과는 사용자 환경에서 확인한다.

## 12. 확인할 가정

PC 개인 사용과 월요일 시작 주간 구분을 가정했다. 배포 주소는 https://weekly-action.vercel.app/ 이며, 실제 화면에서 가상 예시 표시를 확인했다. 코드 검증과 미확인 항목은 test.md에 기록했다.
