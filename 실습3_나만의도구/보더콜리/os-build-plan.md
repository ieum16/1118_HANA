## 3. Git 수집 방식 (v1.2 확정)
- **Git 변경 이력 기반**. 다만 브라우저는 임의의 로컬 Git 명령을 실행할 수 없으므로 직접 조회가 아닌 **Git diff 결과 붙여넣기**를 MVP 입력 방식으로 채택.
- 사용자 안내 명령 예: `git diff --name-status -M origin/main HEAD` (실제 base/target은 배포 범위에 맞게 사용자가 지정).
- 탭으로 구분된 `A\tpath`, `M\tpath`, `D\tpath`, `R100\told\tnew`를 파싱. 중복 제거, 파일 경로 검증, 상태별 분류, 알 수 없는 상태는 경고. 입력 원문과 비교 ref를 기록해 추적 가능하게 함.
- 배포에 포함될 커밋·파일은 사용자 검토가 필요. 미커밋 변경·빌드 산출물·외부 의존 파일은 자동으로 포함된다고 보장하지 않음.
- 추후 확장: 승인된 로컬 CLI/백엔드로 Git 조회 자동화. v1.2에서는 GitHub/Jira API, 저장소 토큰, 서버 연결 없음.

## 4. Excel 양식 생성 명세
| 시트 | 데이터 매핑 | 구현/검증 |
|---|---|---|
| 1 `운영환경적용내용` | 개발요청사항=요청서 개발요건, 개발사항=수동, 신규 및 추가 프로그램=Git A/M/D/R 목록, 테스트방법=수동 목록 | 변경 유형과 비교 ref를 명시하고 누락 확인 |
| 2 `결재및테스트목록` | 신청자=본인 설정, 책임자/관리자=후보 선택, 테스트 목록=시트1 동일 목록, 증적 링크 | 후보 1명 자동 선택, 내부 하이퍼링크 정확 |
| 3~N `증적_T001` 등 | 테스트 1건당 1시트, ID/방법/기대결과 자동, 실제결과/판정/이미지 영역 비움 | 중복/금지문자 없는 이름, 시트2 복귀 링크 |

- 테스트 0건: 기본 2시트만 생성, 미등록 경고.
- 테스트 5건: 정확히 7시트 생성. 테스트 삭제/순서 변경 시 **다시 생성한 문서**에 반영. 이미 내려받은 Excel 파일은 자동 업데이트되지 않음.
- 증적 이미지: 초기 Excel 파일에는 **붙여넣기용 빈 영역**만 생성. 이미지 업로드 후 삽입은 후속 기능.
- 서식: 제목/섹션 구분, 자동값·수동값 색상 구분, 인쇄 영역, 셀 줄바꿈, 링크 표시, 파일명 안전 문자 처리.
- 파일명 예: `운영환경적용요청서_DEMO-v1.4.0_20261123.xlsx`.

## 5. XLSX 기술 리스크와 해결 순서
- 단일 HTML에서 외부 라이브러리 없이 XLSX를 만들려면 ZIP/OOXML 생성 및 관계/링크/콘텐츠 타입 구성이 필요. 이를 구현·검증하기 전에는 'Excel 자동 생성 가능'을 완료 기능으로 간주하지 않음.
- **우선 최소 검증 파일**(2개 시트+1개 증적 시트, 내부 링크)을 생성하여 Excel 호환성을 테스트. 성공 후 동적 N시트·서식·검증 기능 확장.
- 구현이 어려우면 사용자에게 제약을 보고하고 **별도 로컬 Python/openpyxl 생성기**를 후속 선택지로 제안. 이 대안은 'HTML 파일 하나' 요건과 다르므로 사전 동의 없이 전환하지 않음.
