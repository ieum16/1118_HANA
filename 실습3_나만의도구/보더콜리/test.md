# 실습 3 테스트 결과

Chrome에서 가상 예시로 확인했습니다.

## 꼭 필요한 기능

| 확인 항목 | 기대 결과 | 결과 |
|---|---|---|
| 예시 데이터로 첫 실행 후 작업 추가 | 작업 3개가 보이고, 새 작업을 추가하면 4개가 되어 브라우저 저장소에 기록됨 | ○ |
| Git 예시 목록 가져오기 | 추가·수정·삭제·이름 변경을 모두 분류하고 이름 변경의 이전·새 경로를 유지 | ○ |
| 가상 결재자 선택 후 Excel 생성 | XLSX가 생성되고 기본 2개와 증적 3개를 더한 총 5개 시트 안내가 표시됨 | ○ |
| 생성한 문서 구조의 링크 대상 검사 | 테스트 목록에 증적 시트 링크가 있고 증적 시트에 테스트 목록 복귀 링크가 포함됨 | ○ |

## 예외 상황

| 확인 항목 | 기대 결과 | 결과 |
|---|---|---|
| 책임자 후보 1명, 관리자 후보 2명 | 책임자는 자동 선택하고 관리자를 고르기 전에는 문서 생성을 막음 | ○ |

| JSON 백업·복원 | 백업에 업무 데이터가 포함되고 복원하면 백업 시점의 작업 목록으로 돌아감 | ○ |
