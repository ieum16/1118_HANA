# Work Radar 테스트

Chrome에서 저장소에 올릴 `index.html`을 직접 열고 가상 업무로 확인했습니다.

- ○ 대시보드에 KPI 6개와 상태·완료 차트가 표시됩니다. KPI에서 필터가 적용된 전체 업무로 이동합니다.
- ○ 업무를 등록·수정·검색하고 여러 업무를 선택해 삭제할 수 있습니다. 정렬과 페이지 이동도 동작합니다.
- ○ 상세 화면에서 상태, 진행률, 다음 행동, 메모, 회신 정보, 첨부 파일을 바꿉니다. 새로고침 후 저장 내용과 활동을 확인했습니다.
- ○ 칸반에서 카드를 드래그하거나 상태 메뉴로 이동합니다.
- ○ 주간보고를 자동 생성해 편집·저장하고 TXT로 내려받을 수 있습니다.
- ○ 모바일 너비 390px에서 메뉴를 열 수 있고 화면 가로 넘침이 없습니다.
- ○ 삭제된 업무 주소와 손상된 로컬 데이터에 안내 화면을 표시합니다. 샘플 데이터로 초기화하면 복구됩니다.
- ○ 화면 이용 중 외부 HTTP 요청과 브라우저 오류가 발생하지 않았습니다.
