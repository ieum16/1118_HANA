## 한 줄 소개
관심 국내 종목의 한국어 뉴스를 모아 핵심 문장과 매체가 제공한 짧은 소개부터 읽는 개인 뉴스 정리함.

## 대상과 불편
여러 종목 뉴스를 따로 검색하고 긴 기사 전체를 읽을 시간이 부족한 사람. 보유 여부·계좌·거래 금액은 입력하지 않는다.

국내 종목코드 6자리를 사용한다. 미국 종목의 이전 브라우저 기록은 별도의 저장 키에 남겨 두고 이번 목록에는 불러오지 않는다.

## 꼭 필요한 기능 (3개)
1. 관심 목록 관리: 최대 10개, 추가·삭제·되돌리기, 국내 종목코드와 회사명 검색어 검사.
2. 한국어 뉴스 자동 수집: 최근 24시간 최대 20개. 짧은 소개가 있는 기사를 먼저 표시한다. 기본으로 ‘짧은 소개만’을 켜며 해제하면 제목·링크만 있는 기사도 볼 수 있다.
3. 읽음 표시·미읽음 필터·현재 브라우저에 기록 저장.

## 짧게 읽기
- 공개 본문을 확보한 기사: 회사명·수치·실적 등 단서가 있는 핵심 문장을 1~3개 발췌한다. 문장당 최대 145자.
- 매체나 공개 뉴스 RSS가 소개를 제공한 기사: 소개의 1~2개 문장을 표시한다.
- 원문을 읽지 못하고 소개도 없는 기사: ‘짧은 소개 미확보’로 구분한다. 제목을 요약이라고 표시하지 않는다.
- 화면에 기사 전체나 긴 본문 미리보기를 기본으로 펼치지 않는다.
- 현재 방식은 핵심 문장 발췌 및 매체 소개다. AI가 문맥을 이해하고 새로 쓴 요약과는 다르다. AI API 키와 자동 번역은 사용하지 않는다.

## 화면
기존 파랑·노랑 디자인, 왼쪽 관심 목록과 오른쪽 뉴스 카드 구조를 유지한다. 카드에는 한국어 제목, 출처, 짧은 핵심 문장, 발행 시각, 읽음 버튼을 둔다. 제목을 누르면 원문을 새 탭으로 연다. 휴대폰은 위아래 배치.

## 수집 경로
- 한국경제 증권·IT, 매일경제 증권·기업, 연합뉴스 경제의 공식 RSS.
- Google 뉴스: 한국어·한국 지역 검색.
- Bing 뉴스: 한국 지역의 최근 하루 RSS, 매체 소개가 있으면 함께 사용.
- 회사명과 별칭으로 관련성을 거르고 영어로만 된 제목은 제외한다.
- 고정된 피드 주소와 등록된 국내 매체의 기사만 크롤링한다. 임의 URL을 API 입력으로 받지 않는다.
- 사이트 robots.txt와 접근 제한을 확인한다. 제한을 우회하지 않고 소개·제목·링크로 표시한다.
- 본문은 등록 매체의 직접 주소 최대 8개, 동시 2개까지만 확인한다.
- 10분 캐시, 공유 매체 피드 90초 캐시, 요청 시간·크기·동시 실행 수 제한을 둔다.
- 실제 수집 실패와 기사 없음, 가상 예시를 구분한다.

## 실행 구성
- index.html: 화면과 브라우저 기록.
- api/news.js: Vercel API.
- lib/crawler.mjs: 한국어 RSS 수집과 핵심 문장 발췌.
- server.mjs: 로컬 실행 서버. http://127.0.0.1:4184/
- package.json·pnpm-lock.yaml·vercel.json: 의존성과 실행 설정.
- crawler.test.mjs·test.md: 자동 검사와 실제 검증.

사용자의 서버 크롤링 요청에 따라 HTML 한 장 조건을 넘겨 서버형으로 구현했다. HTML 더블클릭만으로는 실제 뉴스를 수집할 수 없다.

## 외부 전송과 저장
국내 종목코드·회사명 검색어로 공개 뉴스를 조회한다. 읽음 기록·보유 정보는 전송하지 않는다. API 키는 사용하지 않는다. 관심 목록과 읽음 기록은 현재 브라우저에 저장하며 브라우저 데이터를 지우면 사라질 수 있다.
