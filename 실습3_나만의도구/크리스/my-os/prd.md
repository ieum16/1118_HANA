# 딜링룸 간단 조치 안내 도구

## 목적
단순·반복 문의에 대해 사용자가 먼저 따라 할 조치 방법을 전달하고, 해결되지 않을 때 문의할 담당자 연락처를 함께 안내한다. 발생 시각·원인·처리 경과를 기록하는 보고서 작성은 제외한다.

## 사용자와 사용 흐름
딜링룸의 PC·단말기, 라이선스, 딜러폰, 딜 정보 수신·인터페이스·전문 관련 문의에 대응하는 담당자가 사용한다.
문의 유형 선택 → 안내 제목과 조치 방법 입력 → 미해결 시 문의할 연락처 선택 → 안내문 생성·수정·복사.

## 꼭 필요한 기능 — 3개
1. **간단 조치 안내 작성**: 문의 유형, 안내 제목, 줄마다 한 단계인 조치 방법, 추가 안내(선택)를 입력한다. 조치 방법에는 순서 번호를 자동으로 붙이고 빈 줄은 제외한다. 발생 시각·원인·진행 상태·전달 대상은 입력받지 않는다. 유형별 예시를 불러와 업무 절차에 맞게 고칠 수 있다.
2. **안내문 생성·복사**: 제목, 순서가 있는 조치 방법, ‘해결되지 않을 경우’ 안내와 선택한 담당자의 업체명·담당자명·역할·전화·이메일을 생성한다. 연락처 참고 메모는 본문에 포함하지 않는다. 결과를 직접 수정할 수 있으며 재생성 전 수정 내용 대체를 확인한다. 자동 복사가 실패하면 전체 선택과 수동 복사를 안내한다.
3. **연락처 관리**: 업체명·담당자명·담당 역할·전화·이메일·복수 장애 유형·메모를 등록·수정·삭제·검색한다. 전화·이메일 중 하나는 필수다. 업체명·담당자명·역할로 검색하고 유형으로 필터링한다. 같은 업체에 여러 담당자, 같은 장애에 여러 담당자, 한 담당자에 여러 장애 연결을 지원한다. 연락처에는 현업·업체 전달 대상 구분이 없다.

## 중복 연락처 처리
- 업체명 + 담당자명으로 동일인을 판단한다. 비교 시 공백, 영문 대소문자, 유니코드 전각/반각을 정규화한다.
- 같은 업체라도 담당자명이 다르면 같은 전화·이메일을 공유해도 별도로 등록한다.
- 동일 내용을 다시 등록하면 alert로 이미 등록되었음을 안내하고 추가하지 않는다.
- 같은 담당자의 전화·역할·상세내용이 바뀌면 기존 ID에 업데이트하고 alert로 결과를 알린다.
- 신규 등록 화면을 통한 업데이트에서는 기존 장애 유형에 새 유형을 합치고 미입력 전화·이메일·메모는 기존 값을 유지한다.
- 명시적인 수정 화면에서는 장애 유형 해제와 선택 항목 삭제를 허용한다.
- 수정 시 다른 연락처와 업체명 + 담당자명이 겹치거나 중복 후보가 여러 개면 자동 덮어쓰기를 막고 목록 확인을 안내한다.
- 예전 저장 연락처는 유지하고, 담당자명이 없으면 ‘담당자명 미등록’ 표시 후 수정으로 추가한다.

## 출력 예시 — 가짜 정보
[딜러폰] 딜러폰 소리가 들리지 않을 때

아래 방법을 순서대로 확인해 주세요.

1. 수화기 또는 헤드셋의 음량을 확인해 주세요.
2. 음소거가 켜져 있는지 확인해 주세요.

위 방법으로 해결되지 않을 경우
다음 담당자에게 문의해 주세요.
업체명: 가상 통신업체
담당자: 가상 담당자 A
담당 업무: 전화 장비 유지보수
이메일: phone-support@example.com

## 예외 상황과 조건
- 제목·조치 방법 공백 시 생성하지 않고 해당 입력을 안내한다.
- 연락처가 없거나 선택하지 않아도 생성할 수 있다. 결과에 연락처 미선택을 명시하고 담당자 선택을 안내한다.
- 담당자 선택·내용 변경·연락처 수정·삭제 후 생성 결과가 이전 내용일 수 있음을 안내한다.
- 연락처의 업체명·담당자명·역할, 연락수단, 담당 유형은 검증한다.
- 입력한 문구는 실행하지 않고 텍스트로 표시한다.
- HTML 파일 하나에 CSS·JS를 포함한다. 로그인·서버·설치·API·외부 통신이 없다.
- 연락처만 현재 브라우저 localStorage에 저장한다. 안내문과 작성 중 입력은 새로고침하면 초기화된다.
- 저장소 접근·용량·데이터 해석 실패를 처리하며 화면은 계속 사용할 수 있고 저장 실패를 안내한다.
- 브라우저 데이터 삭제 시 연락처가 사라질 수 있으며 다른 PC와 자동 공유되지 않는다.
- 예시에는 가짜 업체명·담당자명만 사용한다. 사용자의 업무용 업체명·담당자명 입력은 지원한다. 실제 거래·고객 정보, 비밀번호·API 키는 입력하지 않도록 안내한다.
- 디자인은 검정 뷰포트, 옵시디언 셸(#0c0c0c), 네온 라임(#ccff00) 주요 버튼, 에메랄드 상태 표시로 구성한다. 반투명 카드와 16px 배경 흐림, 60px 격자와 은은한 노이즈·글로우를 사용한다. 데스크톱은 입력·결과 2열, 모바일은 1열과 내부 좌우 16px 여백. 375px 폭에서 가로 스크롤이 없어야 한다.
- Space Grotesk·JetBrains Mono를 우선 지정하고 한글·시스템 대체 글꼴을 제공한다. 별도 글꼴 다운로드 없이 사용하며 해당 글꼴이 설치되지 않은 환경에서는 대체 글꼴로 표시한다.
- 키보드 포커스를 라임색으로 표시하고 동작 줄이기 설정을 지원한다.
