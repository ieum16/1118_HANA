# 간단 조치 안내 도구 — 확인표

## 검증 범위
2026-11-19: 스크립트 문법, 화면 ID 연결 및 중복 ID 검사를 통과했다. 아래 변경 기능 24개 시나리오를 Node VM·최소 DOM 모형에서 실행해 통과했다. 저장소·클립보드·alert·confirm은 모형으로 확인했다.

실제 브라우저와 375px 화면 배치는 검증하지 못했다. 기존에 앱 브라우저가 file: 미리보기를 보안 정책으로 차단하여 다른 경로로 우회하지 않았다. ○는 모형 점검, —는 직접 확인할 항목이다. index.html을 Chrome 또는 Edge에서 더블클릭해 확인한다.
