# 원천징수 FAQ 답변 도구 기획서

작성일: 2026-11-19 · 초안 v0.1

## 한 줄 소개
자주 문의하는 원천징수 질문과 답변을 모아두고, 키워드로 찾아 메일 회신용 답변을 복사하는 도구.

## 누가 쓰나
원천징수 관련 문의를 받고 답변을 작성하는 담당자.

## 줄이고 싶은 불편
반복되는 질문의 답변을 과거 메일에서 찾아 다시 작성하는 일을 줄인다. 새로운 문의는 질문과 답변을 직접 입력해 다음 검색에 활용한다.

## 입력
- 검색어: 질문·답변에 포함된 키워드
- 새 질문: 필수
- 새 답변: 필수, 여러 줄 입력 가능

## 출력
- 키워드와 일치하는 질문·답변 목록
- 선택한 항목의 메일 제목 및 회신 본문
- 복사 결과 또는 입력 오류 안내

메일 형식은 아래를 기본으로 한다. (가정)
제목: [원천징수 문의 회신] {질문}
본문: 안녕하세요. / {등록된 답변} / 감사합니다.
등록된 답변의 줄바꿈을 유지한다. 제목과 본문은 각각 복사할 수 있게 한다. 자동 발송은 하지 않는다.

## 꼭 필요한 기능 (3개)
1. **FAQ 검색**: 질문과 답변 전체를 키워드로 검색한다. 영문 대소문자를 구분하지 않고, 공백으로 구분된 검색어는 모두 포함하는 항목을 찾는다. 검색어가 없으면 전체 목록과 개수를 표시한다. (검색 규칙은 가정)
2. **메일 회신 작성·복사**: 결과를 선택하면 질문·답변과 메일 회신 미리보기를 표시한다. 제목·본문 각각 복사 버튼을 제공한다. 복사 실패 시 직접 선택해 복사할 수 있게 한다.
3. **FAQ 등록·수정·삭제·보관**: 질문과 답변을 입력해 등록한다. 보관함에서 항목을 선택한 뒤 질문·답변을 수정할 수 있다. 수정 취소 시 원본은 유지하며, 저장 시 같은 항목을 갱신하고 메일 미리보기에도 반영한다. 등록·수정한 항목은 즉시 검색 가능하며 localStorage에 저장해 같은 브라우저에서 다시 열어도 유지한다. 저장 실패 시 메모리에 남기고 새로고침하면 사라질 수 있음을 알린다.

## 화면 구성 (가정)
상단 제목과 FAQ 개수 → 키워드 검색 → 검색 결과 목록과 선택한 답변·메일 미리보기 → 새 질문·답변 등록 영역.
데스크톱에서는 목록과 미리보기를 2열, 휴대폰에서는 1열로 배치한다. 375px에서 가로 스크롤이 없어야 한다. 남색과 흰색을 사용한다.

## 샘플 데이터 (기능 시연용 4개)
샘플은 실제 세무 판단·발급 절차·처리 기한을 단정하지 않는 안내 문구로 구성한다. 샘플 배지를 표시한다. (내용은 가정)

| 질문 | 답변 |
|---|---|
| 원천징수 관련 문의 시 어떤 내용을 알려드리면 되나요? | 조회를 원하시는 귀속연도와 문의 목적을 알려주세요. 필요한 확인 항목은 담당자가 추가로 안내드리겠습니다. |
| 귀속연도와 자료 발급일이 다른데 어떤 기준으로 문의하나요? | 확인을 원하시는 소득의 귀속연도와 자료에 표시된 발급일을 함께 알려주시면 해당 항목을 확인해 안내드리겠습니다. |
| 원천징수 자료의 금액을 다시 확인하고 싶습니다. | 확인이 필요한 귀속연도와 금액 항목을 알려주세요. 담당자가 기준 자료와 대조한 뒤 확인 결과를 안내드리겠습니다. |
| 원천징수 관련 증빙 자료는 어떻게 요청하나요? | 필요하신 자료의 종류와 귀속연도, 사용 목적을 알려주세요. 확인 후 발급 가능 여부와 신청 방법을 안내드리겠습니다. |

샘플 답변은 실제 업무에 사용하기 전에 담당 기준에 맞게 검토하도록 표시한다. 세율·세액 계산·초과 여부 판단 기능은 포함하지 않는다.

## 있으면 좋은 기능 (후속)
- JSON 파일로 백업·복원
- 태그 분류 및 자주 쓰는 답변 즐겨찾기

## 예외 상황
- 검색 결과 없음: 일치하는 답변이 없다고 표시하고 새 FAQ 입력 영역으로 이동하는 버튼 제공. 검색어를 새 질문 칸에 제안한다. (가정)
- 빈 질문·답변 또는 공백만 입력: 해당 칸에 오류 안내, 등록 금지.
- 중복·관련 내용: 질문·답변이 일치하거나, 두 내용 전체에서 핵심 키워드가 겹치는 기존 항목을 카드로 표시한다. ‘환율이’와 ‘환율은’의 조사 차이를 처리하며 답변의 ‘해지’처럼 질문 외의 키워드도 비교한다. 일반적인 문의·안내 표현은 제외한다. 각 카드에 질문·답변·일치 이유를 표시한다. 같은 문의이면 해당 카드의 기존 답변을 사용하고 새로 등록하지 않는다. 다른 문의라고 선택한 경우에만 등록·수정한다. 취소 또는 Esc는 입력만 유지한다. 수정 중인 자기 자신은 비교에서 제외한다. 키워드 규칙으로 후보를 찾으며 의미의 최종 동일 여부는 사용자가 결정한다.
- 검색 결과 변경: 이전 선택이 결과에 없으면 첫 결과를 선택하고, 결과가 없으면 미리보기를 비운다.
- localStorage 차단·손상: 화면이 계속 열리도록 예외 처리하고 저장 상태를 안내한다. 기존 데이터는 자동 덮어쓰기하지 않는다.
- HTML처럼 보이는 질문·답변: 일반 텍스트로 표시하고 실행하지 않는다.
- 복사 실패: 미리보기 텍스트를 직접 복사할 수 있도록 안내한다.

## 조건
- index.html 하나에 CSS·JS 포함, 서버·설치·로그인·API 키 없이 더블클릭으로 실행.
- 검색은 브라우저 내부에서 수행한다. AI가 답변을 새로 추론하지 않고 등록된 답변만 제공한다.
- 새 FAQ 저장은 localStorage 사용, 키는 withholding-faq:v1. 읽고 쓰기는 try/catch로 감싼다.
- 최초 실행에는 샘플 4개를 넣고 첫 답변과 회신 예시가 바로 보이게 한다.
- 고객명·계좌번호·개인정보 없이 공통 질문과 답변만 등록하도록 입력 칸에 안내.
- 등록 데이터는 이 브라우저에만 보관되며 다른 PC·브라우저와 공유되지 않는다. 브라우저 데이터를 지우면 사라질 수 있음을 표시.
- 외부 서비스로 데이터를 보내지 않는다.

아직 제작·검증하지 않은 항목은 완료로 표시하지 않는다.


## 추가 요구사항: 질문·답변 삭제
- 선택한 항목의 ‘삭제’ 버튼에서 질문을 확인한 뒤 ‘삭제하기’를 누르면 질문과 답변을 함께 삭제한다. 샘플도 삭제 가능하다.
- 취소와 Esc는 저장 내용을 변경하지 않는다.
- 삭제를 브라우저에 저장하고, 마지막 항목까지 삭제한 경우 빈 보관함 상태도 유지한다.
- 삭제한 항목을 수정 중이었다면 수정 화면을 초기화한다. 나머지 수정 입력은 유지한다.
- 검색 결과에서 사라진 항목의 메일 미리보기를 비우거나 다음 결과를 표시한다.
- 저장 실패 시 새로고침하면 삭제 항목이 다시 표시될 수 있음을 안내한다.
