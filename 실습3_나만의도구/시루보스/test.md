# 원천징수 FAQ 답변 도구 테스트

검증일: 2026-11-19

Chrome에서 임시 검증 사본으로 실행했습니다. 최종 index.html과 같은 앱 코드로 검사했으며 검증 스크립트는 최종 파일에 포함하지 않았습니다.
○ = 통과, × = 실패, — = 미구현·미검증.

## 꼭 필요한 기능

|---|---|---|---|
| 1 | 처음 열기 | 샘플 4개와 첫 답변·메일 회신이 즉시 표시됨 | ○ |
| 2 | ‘귀속연도’ 검색 | 결과 4개 | ○ |

복사 성공·실패는 브라우저의 클립보드 API를 모의 처리해 확인했습니다. 운영체제 클립보드에서 실제 메일 앱에 붙여 넣기는 별도 확인하지 않았습니다.

| 2 | 기존 카드 내용 확인 | 기존 질문·답변·공통 키워드 모두 표시 | ○ |
