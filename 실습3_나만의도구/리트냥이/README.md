# 업무 인박스

## 한 줄 소개

여러 메신저에서 들어온 업무 요청의 기한과 우선순위를 한곳에서 확인하고 다음 행동을 고르는 도구다.

## 어떤 불편을 줄이나요

메신저마다 받은 요청을 다시 읽고, 담당자에게 무엇을 확인해야 하고 어떤 일부터 할지 따로 정리하는 일을 줄인다.

## 꼭 필요한 기능

- Slack·Discord·카카오톡 가상 메시지 수신 및 직접 입력, 발신자·소속·채널 정보 표시
- 메시지의 업무 유형·우선순위·기한 표현과 요청 문장 분석
- 업무 유형에 맞는 다음 행동 두 가지 제안과 선택 표시

## 아낄 수 있는 시간

아직 측정하지 않았다. 예를 들어 하루 5건에서 건당 1분을 줄인다면 주 5일 기준 약 25분이다.

## 써 보는 법

[index.html](index.html)을 브라우저에서 열고 **가상 메시지 수신**을 누른다. 수신함에서 발신자와 소속을 확인한 뒤 분석 결과와 행동 선택지를 살펴본다. [테스트 결과](test.md)

## 배포 주소

실습용 HTML을 로컬에서 실행한다.
