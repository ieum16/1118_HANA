# 서울 동네 길찾기

## 한 줄 소개

광진구·송파구·강동구의 지하철역에서 가까운 명소로 걸어가는 길을 확인한다.

## 어떤 불편을 줄이나요

방문할 시설의 가까운 역과 도보 안내를 각각 검색하는 수고를 줄인다.

## 꼭 필요한 기능

- 지역을 선택해 출발역과 목적지 보기
- 역에서 목적지까지의 도보 안내 읽기
- 길찾기 지도와 시설의 공식 교통 안내 열기

## 아낄 수 있는 시간

아직 측정하지 않았어요.

## 써 보는 법

[index.html](index.html)을 열고 지역 이름을 선택한다. 자세한 지도는 ‘지도에서 길찾기’로 연다.

## 배포 주소

로컬 HTML 파일로 실행한다.
