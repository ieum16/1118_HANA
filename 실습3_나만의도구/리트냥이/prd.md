# 업무 인박스 PRD

여러 메신저를 오가며 요청과 기한을 해석하고 우선순위를 정하는 일을 줄인다. 여러 채널에서 협업 요청을 받는 사람을 대상으로 가정한다.

## 핵심 기능

1. 가상 수신 이벤트 또는 직접 입력으로 Slack·Discord·카카오톡 메시지를 수신함에 모은다. 발신자 이름·회사·팀·역할·채널·수신 시각을 확인할 수 있다.
2. 메시지 표현을 규칙으로 분석해 업무 유형, 우선순위, 기한 표현과 요청 문장을 표시한다.
3. 유형에 맞는 다음 행동 두 가지를 보여 주고, 사용자가 선택한 항목을 해당 메시지에 표시한다.

## 예외와 조건

빈 메시지는 등록하지 않는다. 기한 표현이 없으면 ‘명시 없음’으로 두고, 판별이 어려운 업무는 ‘요청 확인’으로 보여 준다. 기한 표현을 발견해도 확정 기한인지는 원문을 확인한다.

실습은 HTML 한 파일 안에서 가상 데이터로 시연한다. 로그인, 서버, 외부 서비스 호출 없이 메시지를 분류한다.
