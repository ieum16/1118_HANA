# 일과 · 실습 3 기획서

작성일은 2026년 11월 19일이며, 작성자는 역지입니다.

## 한 줄 소개

업무를 등록하고 기간과 긴급도를 수정하며, 지난주·이번주 일정과 공문에 적힌 요청을 한 화면에서 확인하는 개인 업무 비서 시안입니다.

## 누가 쓰나

반복되는 업무와 마감이 있는 업무를 종이 스케줄러에 기록하던 사용자입니다.

## 줄이고 싶은 불편

매일 같은 업무를 다시 적고, 변동 사항이 생길 때마다 지우고 수정하는 번거로움을 줄입니다. 기간이 있는 업무의 진행 범위와 마감을 쉽게 확인합니다.

## 입력과 출력

| 구분 | 입력 | 출력 |
|---|---|---|
| 업무 | 제목, 메모, 유형, 시작일, 마감일, 긴급 여부 | 업무 목록, 완료 상태, 긴급 목록 |
| 캘린더 | 등록한 업무와 조회할 2주 | 지난주·이번주 일정, 연속 기간 막대 |
| 공문 | PNG·JPG·WebP 가상 공문 이미지 또는 붙여 넣은 원문 | 추출 원문, 관련 업무·준비물·마감·제출 방법 |

## 꼭 필요한 기능

1. 업무를 등록·수정·삭제·완료 처리하고 긴급 업무를 함께 확인합니다.
2. 2주 캘린더에서 기간 업무를 하나의 막대로 표시합니다. 주를 넘기면 다음 줄에 이어지고, 겹치는 업무는 줄을 나눕니다.
3. 공문 이미지의 글자를 추출하고 관련 문장을 업무 항목별로 정리해, 검토한 항목을 업무로 추가합니다.

## 디자인과 실행 조건

- 하나은행과 비슷한 청록색을 참고한 `#008485` 중심 디자인과 배민 주아체를 사용합니다.
- 제출 도구는 스타일·스크립트·폰트가 포함된 `index.html` 한 파일이며 브라우저에서 열 수 있습니다.
- 로그인과 API 키 없이 업무 관리 기능을 사용할 수 있습니다.
- 실제 고객·회사 자료를 포함하지 않고 가상 업무와 가상 공문으로 확인합니다.
- 업무는 해당 주소의 해당 브라우저 localStorage에 저장합니다.
- 공문 OCR은 첫 실행 시 외부 CDN에서 인식 자료를 내려받습니다. 이미지 글자 인식은 브라우저에서 수행합니다.

## 예외 상황

- 제목이 비어 있거나 마감일이 시작일보다 빠르면 등록을 막고 안내합니다.
- 과거에 저장한 날짜 없는 업무는 별도 목록에 남기고 사용자가 날짜를 지정할 수 있게 합니다.
- 공문에서 확인되지 않는 항목은 ‘원문에서 확인 필요’로 표시합니다.
- 흐리거나 글자가 없는 이미지, 인식 자료 다운로드 실패 시 원문을 직접 입력할 수 있습니다.

## 있으면 좋은 기능과 남은 작업

매일·주간 반복 업무의 회차별 완료 이력, 백업·복원, 사용자 문구 보관함, AI 문장 다듬기와 공문 분석, 오전 8시 40분 자동 알림을 차례로 보완합니다. 현재 문장 다듬기 버튼은 연결 준비 안내를 표시하고, 알림은 버튼으로 여는 예시 팝업입니다.
