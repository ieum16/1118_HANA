# 문의 처리 안내 업무 OS 기획서

## 사용자와 문제

영업점 문의에 답하고 처리 내역을 안내하는 담당자가 사용합니다. 엑셀에서 상태를 찾고 안내 문구를 다시 쓰는 일이 하루 약 10건, 건당 약 3분 반복됩니다.

## 꼭 필요한 기능

1. **문의 등록과 답변**. 점번호, 점명, 직원명, 직원번호, 문의 내용을 입력합니다. 네 필드를 `+`로 이어 표시한 접수번호를 검색합니다. 같은 직원의 문의는 건별로 관리하며, 답변 담당자와 답변을 저장하면 완료로 표시합니다.
2. **달력과 통계**. 접수일별 총 접수, 완료, 미완료와 월간 완료율을 표시합니다. 이전 접수 건을 포함해 선택한 날 실제로 답변한 문의 수도 표시합니다.
3. **직원별 PMS와 회의자료**. PMS 번호, 담당자, 중요도, 기한, 제목, 회의 공유 내용을 등록합니다. 중요도에 따라 미완료·논의 업무와 주간 완료 업무를 정리합니다. 페이지가 열려 있으면 한국 시간 오후 5시 이후에 미완료 문의와 PMS 건수를 알립니다.

## 저장과 사용 조건

- 로그인 없이 `index.html`을 PC 브라우저에서 엽니다. 실습에는 가짜 데이터만 사용합니다.
- 개인 기록은 브라우저에 저장합니다. 공유는 각 담당자가 같은 공용 폴더를 선택한 경우에 사용합니다.
- 별도의 PMS 연동 없이 사내 화면에서 확인한 항목을 직접 등록합니다. PC 알림은 브라우저의 알림 권한을 사용합니다.
- 이전 엑셀 목록 조회와 상태별 안내 문구 복사는 하단 메뉴에서 사용할 수 있습니다.
