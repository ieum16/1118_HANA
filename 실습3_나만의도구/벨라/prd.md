# 벨라의 팀 일정 업무 OS 기획서

초안 v0.1 · 2026-11-19 · [제작 계획서](os-build-plan.md)

## 1. 풀 문제

인증서 교체, 사업 품의, 정기 작업 일정을 메일로 주고받아 팀 전체의 최신 일정과 진척도를 확인하기 어렵다. 담당자와 마감일을 한 화면에서 비교하고, 내 업무 중 먼저 처리할 항목을 찾을 수 있게 한다.

## 2. 사용자와 사용 장면

실습에서는 한 브라우저에서 가상의 담당자를 골라 팀원별 화면을 확인한다. 첫 화면에서 내가 맡은 임박 업무를 보고, 월간 타임라인에서 다른 담당자의 일정과 상태까지 확인한다. PC와 휴대폰에서 열 수 있게 한다.

## 3. 화면 모듈

| 모듈 | 하는 일 |
|---|---|
| 내 마감 임박 업무 | 선택한 담당자의 미완료 업무 중 기한이 지났거나 14일 안에 기한이 오는 건을 가까운 순으로 표시한다. 14일은 실습 기준이다. |
| 팀 전체 월간 타임라인 | 월을 이동하며 일정, 담당자, 기준일, 진행 상태를 날짜순으로 확인한다. 내 담당 건은 색과 ‘내 담당’ 표시로 강조한다. |
| 일정 관리 | 일정 추가·수정, 상태 변경, 예시 삭제와 JSON 백업·복원을 제공한다. |

상단에 오늘 날짜와 ‘내 담당자’ 선택을 두고, 그 아래에 임박 업무와 월간 타임라인을 배치한다. 일정 편집 화면은 ‘일정 추가’나 기존 일정의 ‘수정’을 눌러 연다.

## 4. 데이터 항목

| 항목 | 종류 | 예시 |
|---|---|---|
| 업무명 | 필수 텍스트 | 테스트 인증서 교체 |
| 유형 | 필수 선택 | 인증서 교체, 사업 품의, 정기 작업 |
| 담당자 | 필수 선택 | 담당자 A, 담당자 B, 담당자 C |
| 기준일 | 인증서·품의에 필수 | 인증서 만료일 2026-12-18, 사업 착수일 2026-12-04 |
| 정기 작업 시작 월 | 정기 작업에 필수 | 2026-11 |
| 상태 | 필수 선택 | 예정, 진행 중, 검토 중, 완료 |
| 메모 | 선택 텍스트 | 검토 자료 준비 중 |

‘내 담당자’는 실습용 예시 인물 A·B·C 중에서 고른다. 업무명, 담당자, 메모는 실습용 필드이며, 초기 예시에는 실제 직원명이나 내부 자료를 사용하지 않는다.

## 5. 일정 계산과 진행 상태

| 업무 유형 | 타임라인에 표시할 날짜 |
|---|---|
| 인증서 교체 | 만료일 30일 전을 교체 시작일로 표시하고, 실제 기준인 만료일도 함께 보여 준다. 임박 목록은 교체 시작일을 기준으로 한다. |
| 사업 품의 | 착수일 14일 전을 승인 마감일로 표시한다. |
| 정기 작업 | 시작 월부터 매월 둘째 수요일을 작업 예정일로 표시한다. 월별 진행 상태를 기록한다. |

30일과 14일은 달력 날짜로 계산한다(가정). 완료 항목도 타임라인에는 남기고, 임박 목록에서는 제외한다.

## 6. 범위와 디자인

- 웹페이지는 `index.html` 한 파일로 열고, 일정과 담당자 설정을 브라우저에 저장한다. JSON 백업과 복원을 제공한다.
- 실습 단계에서는 각 브라우저에 별도로 저장된다. 실제 팀원이 여러 기기에서 같은 일정을 조회·수정하는 기능은 후속 단계에서 공유 저장소와 접근 권한을 정해 연결한다.
- 메인 색은 차분한 남색, 내 담당 강조색은 파랑, 기한이 지난 일은 글자와 배지로 구분한다(가정).

## 7. 완료 기준

- [ ] 첫 화면에서 내 임박 업무와 팀 전체 일정이 함께 보인다.
- [ ] 담당자를 바꾸면 강조 표시가 바뀌고 팀 전체 일정은 계속 보인다.
- [ ] 세 유형의 날짜가 기준대로 계산되며 월별 정기 작업 상태가 서로 구분된다.
- [ ] 일정을 추가·수정하고 새로고침해도 저장된다. 내보낸 JSON 파일로 복원할 수 있다.
- [ ] 휴대폰 폭 375px에서 가로 스크롤 없이 볼 수 있다.
