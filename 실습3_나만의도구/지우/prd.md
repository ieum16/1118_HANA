# 서무 카드 사용내역 정리 도구

## 한 줄 소개

미배정 카드 사용내역에서 사용자별 확인 요청을 만들고, 회신과 최종 예산 과목을 정리하면서 네 과목의 예상 잔액을 한 화면에서 보는 도구예요.

## 누가 쓰나요

- 서무 담당자가 미배정 내역을 가져오고, 사용자에게 확인한 뒤 예산 과목을 최종 배정해요.
- 카드 사용자는 메일에 안내된 결제 건마다 목적과, 비용 유형에 따라 필요한 정보를 회신해요.

## 줄이고 싶은 불편

사용자별로 카드 내역을 필터링해 메일에 옮겨 적고, 받은 답변을 원래 내역과 대조해 정리하는 일이 반복돼요. 최종 예산 과목을 정할 때는 네 과목의 잔여한도도 따로 조회해야 해요.

## 입력

| 시점 | 입력할 내용 |
|---|---|
| 사용내역 가져오기 | Finder에서 .xlsx, .csv, .tsv 파일을 고르거나 내려받은 엑셀 표를 붙여넣어요. 사용자, 사용일시, 가맹점, 금액을 먼저 확인한 뒤 목록에 추가해요. |
| 예산 기준 잡기 | 본점 회의비, 본점 업무추진비, 임원 회의비, 임원 업무추진비의 현재 잔여한도를 각각 입력해요. 숫자는 입력하는 동안 천 단위로 구분돼요. |
| 회신 정리 | 결제 건마다 사용 목적을 적어요. 회의비라면 함께 회의한 사람, 업무추진비라면 접대한 회사와 사람을 적어요. 사용자가 제안한 과목은 참고로 남길 수 있어요. |
| 최종 배정 | 지우 님이 결제 건별 최종 과목을 선택해요. 사용자가 제안한 과목과 최종 과목은 따로 표시해요. |

## 출력

- 선택한 사용자의 결제 건을 한 메일 표에 모아요. 각 줄의 사용 목적, 접대 회사, 접대한 사람 또는 회의 참여 직원 칸을 비워 두어 받는 사람이 바로 적을 수 있어요.
- 사용 월을 고르면 그 달의 결제와 메일 초안이 표시돼요. 해당 월의 법인카드 사용내역 확인 요청 제목과 본문을 각각 복사할 수 있어요.
- 정리 화면에서 **요청 전 → 회신 대기 → 회신 확인**, 그리고 최종 배정 여부를 볼 수 있어요. 초안 복사와 실제 요청 보냄은 서로 다른 동작으로 취급해요.
- 과목별로 **기준 잔여한도 / 배정 합계 / 배정 후 예상 잔액**을 보여 줘요. 모든 달의 최종 배정액을 기준으로 소진율을 퍼센트와 색이 변하는 막대로 표시하고, 한도를 넘으면 초과액을 표시해요.
- 요청 보냄 기록과 회신 확인을 취소하고, 최종 배정을 해제할 수 있어요. 회신 메모는 취소 후에도 유지돼요.
- 예산 사용내역은 실제 시스템에 반영하기 전의 점검용으로 볼 수 있어요.

## 꼭 필요한 기능

1. **파일 가져오기와 사용자별 메일 초안** — 미배정 내역을 한 번에 가져와 월·사용자별로 확인하고, 제목과 회신용 표를 복사해요.
2. **결제 건별 회신 정리와 최종 과목 선택** — 목적, 회의 참석자 또는 접대 회사·사람, 제안 과목을 해당 건에 기록하고 서무 담당자가 최종 과목을 선택해요.
3. **네 과목의 예상 잔액 미리보기** — 입력한 기준 잔여한도에서 도구 안에서 최종 과목을 선택한 금액만 차감해요. 선택을 변경하거나 해제하면 두 과목의 합계와 예상 잔액을 다시 계산해요.

## 화면에서 확인할 예시

- 예시 사용자 A가 28,000원과 42,000원을 결제했다면, 확인할 결제 두 건이 한 사람의 메일 초안에 각각 표시돼요.
- 본점 회의비 잔여한도가 100,000원이고 28,000원 건을 여기에 최종 배정하면 예상 잔액은 72,000원이에요.
- 같은 건의 제안 과목만 선택한 상태라면 잔액은 100,000원이에요. 최종 과목을 바꾸면 이전 과목의 차감액이 돌아가고 새 과목에서 차감돼요.

## 예외 상황

- 필요한 열이 없거나 금액을 읽을 수 없는 행은 무엇을 확인해야 하는지 알려 줘요.
- 같은 파일에서 복사한 표를 다시 붙여넣으면 기존 내역을 유지하고 중복 가져오기를 알려 줘요. 같은 날짜·가맹점·금액이라도 원본 표의 별개 행은 각각 표시해요.
- 회의비의 참석자 또는 업무추진비의 접대 회사·사람이 비어 있으면 회신 확인이 필요한 상태로 남겨요.
- 예산 잔여한도가 입력되지 않은 과목에는 확인 가능한 금액과 예상 잔액 입력 안내를 표시해요.
- 카드번호가 포함된 표를 붙여넣을 수 있지만 첫 버전은 카드번호를 표시하거나 메일에 넣을 필요가 없는 흐름으로 설계해요.

## 제작 조건

브라우저에서 직접 여는 index.html 한 장으로 만들어요. 실습에는 가상 미배정 결제 5건을 담은 예시 엑셀을 사용해요. 가져오기 창에서 같은 예시 표를 바로 채울 수도 있어요. 붙여넣은 데이터와 작성 내용은 브라우저에서 처리해요.
