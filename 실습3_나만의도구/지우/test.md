# 서무 카드 사용내역 정리 도구 테스트

index.html을 크롬에서 열고 예시 데이터로 확인해요. 아래 ○는 이번에 브라우저에서 확인한 결과예요.

## 꼭 필요한 기능

| 번호 | 해 볼 것 | 기대 결과 | ○/× |
|---|---|---|---|
| 1 | 첫 화면을 열고 예시 사용자 A를 선택해 메일 초안 보기 | 예시식당 28,000원과 예시카페 42,000원 두 행이 한 표로 나오며, 사용 목적·접대한 회사·접대한 사람 또는 회의 참여 직원 칸이 비어 있어요. | ○ |
| 2 | 메일 초안을 복사한 뒤 요청 보냄 기록 누르기 | 복사할 때는 두 건이 요청 전이고 기록 버튼을 누르면 회신 대기로 바뀌어요. | ○ |
| 3 | 예시식당의 사용자 제안 과목만 본점 회의비로 선택하기 | 본점 회의비의 예상 잔액은 100,000원이에요. | ○ |
| 4 | 같은 건의 최종 과목을 본점 회의비로 선택한 뒤 임원 회의비로 변경하기 | 본점 회의비가 72,000원에서 다시 100,000원으로 돌아오고 임원 회의비는 52,000원이 돼요. | ○ |
| 5 | 회신 확인에 필요한 사용 목적과 참석자를 적고 회신 확인 처리 누르기 | 회신 확인으로 바뀌고 해당 건이 메일 초안에서 빠져요. | ○ |
| 6 | 가짜 카드번호 열을 포함한 엑셀 표를 붙여넣기 | 사용자, 사용일시, 가맹점, 금액으로 결제 건이 만들어지고 카드번호는 표시되지 않아요. | ○ |

## 예외 상황

| 번호 | 해 볼 것 | 기대 결과 | ○/× |
|---|---|---|---|
| 7 | 금액에 글자가 있는 행을 포함해 붙여넣기 | 금액을 확인할 행을 알려주고 목록을 그대로 유지해요. | ○ |
| 8 | 필수 열 이름이 빠진 표를 붙여넣기 | 찾을 수 없는 열을 알려줘요. | ○ |
| 9 | 같은 표에 동일한 행 두 개를 넣어 가져오고 표 전체를 다시 붙여넣기 | 첫 가져오기에 두 행이 각각 추가되고 두 번째에는 중복을 알려줘요. | ○ |
| 10 | 10,000원 한도가 있는 과목에 65,000원 결제 건을 배정하기 | 예상 잔액에 55,000원 초과가 표시돼요. | ○ |
| 11 | 업무추진비에서 접대한 사람을 비운 채 회신 확인 누르기 | 접대한 사람 입력 안내가 나오고 회신 확인 상태로 바뀌지 않아요. | ○ |

## 있으면 좋은 기능

| 번호 | 해 볼 것 | 기대 결과 | ○/× |
|---|---|---|---|
| 12 | 예산 배정과 회신을 입력한 뒤 새로고침하기 | 같은 브라우저에서 예산과 회신 내용이 유지돼요. | ○ |
| 13 | 휴대폰 폭 375px로 열어 보기 | 카드와 작업 영역이 세로로 배치되고 페이지 좌우 스크롤이 없어요. | ○ |
| 14 | 한 건 또는 사용자별로 보냄 기록을 취소하기 | 회신 대기 건이 요청 전으로 돌아가요. | ○ |
| 15 | 회신 확인을 취소하고 최종 배정을 해제하기 | 회신 입력값은 유지되고, 배정했던 금액만큼 예상 잔액이 돌아와요. | ○ |
| 16 | 가져오기 창에서 예시 표 넣기 선택 | 가상 사용자 3명의 결제 5건을 가져올 수 있어요. | ○ |
| 17 | 기준 잔여한도 100,000원인 과목에 28,000원 배정하기 | 28%와 해당 길이의 진행 막대가 표시돼요. | ○ |
| 18 | 기준 잔여한도 30,000원인 과목에 36,000원 배정하기 | 120%, 꽉 찬 빨간 막대, 6,000원 초과가 표시돼요. | ○ |
| 19 | Finder 파일 선택으로 예시 엑셀을 불러오기 | 파일 이름과 결제 5건을 확인할 수 있어요. 목록에 추가를 누르면 5건이 반영돼요. | ○ |
| 20 | 손상된 .xlsx 파일을 선택한 뒤 정상 CSV 선택 | 손상된 파일에는 안내가 나오고 정상 CSV는 미리볼 수 있어요. | ○ |
| 21 | 10월과 11월 결제를 불러오고 10월 선택 | 10월 내역만 목록과 메일 표에 나오며 제목은 ‘10월 법인카드 사용내역 확인 요청’이에요. | ○ |
| 22 | 기준 잔여한도에 1000000을 순서대로 입력하고 중간 숫자 편집 | 입력 도중 1,000,000처럼 쉼표가 표시되고 예산이 곧바로 다시 계산돼요. | ○ |
