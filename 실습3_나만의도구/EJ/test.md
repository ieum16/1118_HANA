# 일일 채널 성과 증감 계산기 테스트

`index.html`을 브라우저에서 열어 가상 예시로 확인한다.

## 꼭 필요한 기능

| 번호 | 해 볼 것 | 기대 결과 | ○/× |
|---|---|---|---|
| 1 | 파일을 처음 연다. | 입력 칸에 가상 표가 있고 지표 5개와 비교 결과 20개가 바로 표시된다. | ○ |
| 2 | 가상 예시를 엑셀에 옮긴 뒤 머리글을 포함해 복사한다. 입력 칸에 붙여넣고 증감 계산을 누른다. | MAU 오늘 수치는 350,000명이다. 전일, 전주 동기간, 전월 말, 전년 말 순서로 +2,000명, +5,000명, -2,000명, +40,000명이 표시된다. | |
| 3 | 가상 예시에서 YAU의 전일 대비와 NEW 하나원큐 손님 수의 전년 말 대비를 본다. | 각각 0명과 +41,000명이다. | ○ |
| 4 | 결과 표 복사를 누르고 빈 엑셀 시트에 붙여넣는다. | 머리글과 지표 5개를 포함한 6행 6열의 표가 붙여넣어진다. 브라우저에서 클립보드 사용을 제한하면 선택된 텍스트가 표시되어 직접 복사할 수 있다. | |
| 5 | 화면 너비를 375px로 줄인다. | 각 지표의 오늘 수치와 네 가지 증감이 세로로 나열된다. 페이지에 가로 스크롤이 생기지 않는다. | |

## 예외 상황

| 번호 | 해 볼 것 | 기대 결과 | ○/× |
|---|---|---|---|
| 6 | 가상 예시에서 DAU의 전일 값 `82,500`을 비우고 다시 계산한다. | DAU 전일 대비만 `확인 필요`로 표시된다. 전주 동기간 대비는 +2,000명이고 유효 비교 건수는 19개다. | ○ |
| 7 | 가상 예시에서 MAU 오늘 값 `350,000`을 `미집계`로 바꾸고 다시 계산한다. | MAU의 오늘 수치와 증감 네 개가 `확인 필요`로 표시된다. 나머지 지표는 계산되고 유효 비교 건수는 16개다. | |
| 8 | 가상 예시에서 `전년 말` 머리글을 `작년`으로 바꾸고 다시 계산한다. | `빠진 머리글 · 전년 말`이 표시된다. 두 복사 버튼 모두 비활성화되고 그래프가 사라진다. | |
| 9 | 가상 예시에서 YAU 행을 지우고 다시 계산한다. | `YAU · 지표 행이 빠졌어요.`가 표시되고 YAU의 증감 네 개는 `확인 필요`로 표시된다. | |
| 10 | 가상 예시에서 NEW 하나원큐 손님 수의 전년 말 값을 `0`으로 바꾸고 다시 계산한다. | 전년 말 대비가 +145,000명으로 표시된다. | |

## 보고 문장과 그래프

| 번호 | 해 볼 것 | 기대 결과 | ○/× |
|---|---|---|---|
| 11 | 보고 문장 복사를 누른 뒤 메모장에 붙여넣는다. | 첫 줄에 한국 시간 기준 오늘 날짜가 `보고 기준일 YYYY-MM-DD`로 표시된다. 다음 줄은 `MAU 350,000명 (전일 대비 +2,000명, 전주 동기간 대비 +5,000명, 전월 말 대비 -2,000명, 전년 말 대비 +40,000명).`이고, 나머지 지표 네 줄이 이어진다. | |
| 12 | 그래프 비교 기준을 전일 대비에서 전월 말 대비로 바꾼다. | 전일 대비에서 MAU는 오른쪽 +2,000명, DAU는 왼쪽 -500명, YAU는 중앙 0명 점이다. 전월 말 대비로 바꾸면 MAU는 왼쪽 -2,000명으로 바뀐다. | ○ |
| 13 | 비교 기준을 전일 대비로 놓고 DAU 전일 값을 비운 뒤 다시 계산한다. | DAU는 그래프에서 막대 없이 `확인 필요`로 표시된다. 복사한 보고 문장에도 `전일 대비 확인 필요`가 들어간다. | |
| 14 | 가상 예시에서 하나원큐 전체 손님 수를 가입손님 수로, NEW 하나원큐 손님 수를 뉴앱 이용자 수 또는 NEW 하나원큐 이용 손님 수로 바꾼 뒤 다시 계산한다. | 증감 20개가 계산되고 결과 표, 그래프, 복사 문장에는 새 이름이 표시된다. MAU, YAU, DAU 영문 설명은 결과 표에서만 약어 아랫줄에 표시된다. | |
| 15 | 보고 기준일을 `2026-11-18`로 바꾼 뒤 보고 문장을 다시 복사한다. | 첫 줄에 `보고 기준일 2026-11-18`이 표시된다. 결과 표 복사의 첫 줄은 지표 머리글 그대로다. | |
