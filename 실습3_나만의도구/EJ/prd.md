# 일일 채널 성과 증감 계산기

## 목적

디지털 마케팅과 데이터 분석 담당자가 엑셀에 모아 둔 일일 채널 지표를 한 번 붙여넣어 20개 증감을 계산하고, 결과를 보고 자료에 옮긴다.

## 입력과 출력

- **입력** — 머리글을 포함해 엑셀에서 복사한 표. 지표는 MAU, YAU, DAU, 하나원큐 전체 손님 수, NEW 하나원큐 손님 수다. 수치는 오늘, 전일, 전주 동기간, 전월 말, 전년 말 기준으로 준비한다. 엑셀에 모인 전주 동기간 값을 그대로 사용한다. 엑셀에서 기존 이름인 가입손님 수, 뉴앱 이용자 수, NEW 하나원큐 이용 손님 수도 인식한다.
- **표 배치(가정)** — 지표가 행에 있고, 오늘과 비교 기준이 열에 있다. 첫 열의 머리글은 `지표`다.
- **출력** — 지표별 오늘 수치와 네 가지 기준 대비 증감을 담은 표. 증감은 `오늘 수치 − 비교 기준 수치`로 계산하며, `+2,000명`, `-500명`, `0명`처럼 인원수 차이로 표시한다.

## 필수 기능

1. 엑셀 표를 머리글과 함께 붙여넣으면 지표와 기준별 수치를 읽는다.
2. 다섯 지표의 오늘 수치와 20개 증감을 결과 표에 표시한다.
3. 결과를 한 번에 복사해 엑셀이나 보고 자료에 붙여넣을 수 있게 한다.

## 예외 상황

- 수치의 천 단위 쉼표를 인식한다. `0`은 유효한 수치로 계산한다.
- 비어 있거나 숫자로 읽을 수 없는 칸을 알려 주고, 그 칸이 필요한 비교 결과에 `확인 필요`를 표시한다. 오늘 값이 없으면 해당 지표의 비교 네 건에 모두 표시한다.
- 필요한 지표나 기준 머리글을 찾을 수 없으면 어느 항목이 빠졌는지 알려 준다.

## 보고 문장과 그래프

- **보고 문장 복사** — 선택한 보고 기준일을 맨 위에 넣고, 지표마다 오늘 수치와 네 가지 증감을 한 줄로 만들어 한꺼번에 복사한다. 기준일의 기본값은 한국 시간 기준 오늘이며 화면에서 바꿀 수 있다. 누락값은 `확인 필요`로 표시한다.
- **지표별 증감 그래프** — 선택한 비교 기준의 다섯 지표를 가로 막대로 표시한다. 감소는 0명 왼쪽, 증가는 오른쪽에 그린다. 0은 점으로 표시하고, 누락값에는 막대 없이 `확인 필요`를 표시한다.

## 실행 조건

`index.html` 한 파일을 브라우저에서 열어 사용한다. 서버, 로그인, 설치, API 키가 필요 없고 붙여넣은 표는 브라우저 안에서 처리한다. 예시와 테스트에는 가상의 수치만 사용한다.
