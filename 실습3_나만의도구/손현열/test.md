# 메일 분류 대시보드 확인표

처음 확인할 때는 브라우저의 새 프로필로 `index.html`을 엽니다. 반복 확인 중에는 삭제를 되돌리고, 직접 옮긴 메일을 원래 목록으로 돌려놓으면 초기 건수와 비교할 수 있습니다.

## 꼭 필요한 기능

| 번호 | 해 볼 것 | 기대 결과 | ○/× |
|---|---|---|---|
| 1 | 처음 화면을 열고 세 목록을 본다 | 전체 9건, 처리할 메일 3건, 회신이 필요한 메일 2건, 불필요한 메일 4건이다. `[마감 안내]`는 처리할 목록에, `[회신 요청]`은 회신 목록에 있다. | |
| 2 | `[뉴스레터] 이번 주 읽을거리`를 회신 목록으로 옮기고 새로고침한다 | 회신이 필요한 메일 3건, 불필요한 메일 3건으로 표시되고, 옮긴 메일에 `수동 분류`와 `회신하기`가 나타난다. | |
| 3 | 초기 목록에서 불필요한 메일 2건을 선택해 삭제한다. 새로고침한 뒤 `삭제 되돌리기`를 누른다 | 삭제 직후 전체 7건, 불필요한 메일 2건이다. 복구하면 전체 9건, 불필요한 메일 4건으로 돌아온다. | |
| 4 | 처리할 메일 1건을 불필요한 메일로 옮기고, 그 메일만 삭제했다가 되돌린다 | 해당 메일이 불필요한 목록에 `수동 분류` 상태로 복구된다. | |
| 5 | 처리 대기에서 메일의 `완료`를 체크하고 새로고침한 뒤, 처리 완료에서 해당 체크를 해제한다 | 메일이 즉시 처리 완료로 옮겨지고 처리 대기 2건·처리 완료 1건으로 갱신된다. 새로고침 후에도 완료 목록에 남으며, 체크를 해제하면 곧바로 처리 대기로 돌아가고 건수도 원래대로 돌아온다. | |
| 6 | 회신 대기에서 `회신하기`로 `확인했습니다.`를 저장하고, 새로고침한 뒤 회신 완료에서 메일을 연다 | 메일이 즉시 회신 대기에서 회신 완료로 옮겨지고 두 건수가 갱신된다. 새로고침 후에도 완료 목록에 있으며 제목과 `저장한 답장 보기`로 원문과 답장을 읽을 수 있다. | |
| 12 | 세 목록에서 메일 제목을 각각 누르고, 주간 회의 메일을 `회신하기`로 다시 연다 | 제목을 누르면 보낸 사람, 받은 시간, 미리보기에 없는 세부 내용까지 표시된다. 회신 창에는 같은 원문과 답장 입력란이 함께 보인다. | |

## 예외 상황

| 번호 | 해 볼 것 | 기대 결과 | ○/× |
|---|---|---|---|
| 7 | `공용 회의실 이용 안내`와 `교육 뉴스레터에 실을 소개 문구 회신 요청`을 찾는다 | 첫 메일은 처리할 목록에 있고, 둘째는 회신 목록에서 `회신 요청 · 규칙 겹침`으로 표시된다. | |
| 8 | `전체 선택`으로 불필요한 메일을 모두 삭제한다 | `불필요한 메일이 없습니다.`가 나타나고, 전체 선택과 선택 삭제가 비활성화된다. | |
| 9 | 회신 창에서 공백만 넣어 저장하거나, 회신 완료에서 `답장 수정`으로 내용을 바꾸고 취소한다 | 공백만은 저장되지 않고, 취소하면 이전에 저장한 회신 내용과 완료 상태가 유지된다. | |
| 10 | 375px 너비에서 세 목록과 회신 창을 연다 | 목록이 위아래로 배치되고, 회신 창에서 원문을 끝까지 스크롤하며 가로 스크롤 없이 답장을 입력할 수 있다. | |
