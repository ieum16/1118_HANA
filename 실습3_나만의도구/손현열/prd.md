# 가상 메일 분류 대시보드

메일이 많이 들어올 때 어떤 메일부터 확인할지 빠르게 정하는 개인용 도구다. 브라우저에서 `index.html`을 열면 가상의 보낸 사람, 제목, 미리보기가 있는 예시 메일이 표시된다. 어느 목록에서든 제목을 누르면 보낸 사람과 받은 시간, 본문 전체를 볼 수 있다.

## 꼭 필요한 기능

1. **자동 분류와 직접 이동** · 회신, 답변, 답장 요청을 회신 목록에 우선 분류한다. 승인, 검토, 마감 등 업무 요청이나 분류가 애매한 메일은 처리할 목록에 남긴다. 광고, 뉴스레터, 할인 등 불필요한 메일 단서만 있으면 불필요한 목록에 둔다. 메일을 다른 두 목록 중 하나로 직접 옮길 수 있다.
2. **처리 완료와 가상 회신** · 처리 대기에서 `완료`를 체크하면 처리 완료로 옮기고, 해제하면 처리 대기로 돌린다. 회신 대기에서는 `회신하기`로 원문을 보면서 답장을 작성한다. 저장하면 메일이 회신 완료로 이동한다. 회신 완료에서 제목이나 `저장한 답장 보기`를 누르면 원문과 답장을 함께 볼 수 있고, `답장 수정`으로 기존 답장을 고칠 수 있다. 처리와 회신의 대기·완료 건수를 각각 표시한다.
3. **삭제와 복구** · 불필요한 메일만 개별로 또는 여러 건 선택해 삭제한다. 최근 삭제한 묶음을 되돌리면 분류와 진행 상태를 함께 복구한다.

## 실행 조건과 예외 상황

- HTML 파일 하나로 동작하며 서버, 로그인, 메일함 연결을 사용하지 않는다. 메일은 모두 가상이다.
- 선택한 메일이 없으면 삭제 버튼이 비활성화된다. 목록이 비면 안내 문구를 보여준다.
- 분류 변경, 완료 여부, 가상 회신, 삭제 상태와 최근 복구 기록은 사용할 수 있는 경우 현재 브라우저에 저장한다. 브라우저 저장이 차단되면 현재 화면에서 계속 이용할 수 있고 저장 상태를 안내한다.
- 향후 기능 후보는 제목과 보낸 사람 검색이다.
