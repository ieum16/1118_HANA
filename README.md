# 1118_HANA · AI 바이브코딩 실습 저장소

하나은행 심화반 「말로 만드는 나만의 업무 도구」(8시간 · ChatGPT · Codex) 실습 저장소입니다.
강의 **예제**와 **스킬**이 이 안에 다 들어 있고, 여러분이 만든 결과물도 여기에 모여서 강사 대시보드에서 함께 봅니다.

## 시작하기 (처음 한 번)

1. 바탕화면 `바이브코딩` 폴더를 Codex에서 엽니다.
2. Codex에 아래처럼 말합니다.
   ```
   https://github.com/ieum16/1118_HANA 저장소를 바이브코딩 폴더에 clone 해 줘.
   ```
3. Codex에서 **`1118_HANA` 폴더를 다시 열고** 이렇게 말합니다.
   ```
   자기소개 할게
   ```
4. Codex가 네 가지를 물어봐요: **닉네임(또는 실명) · 하는 업무 · 깃허브 경험 · 바이브코딩 경험**. 답하면 내 폴더가 생기고, 확인을 받은 뒤 깃허브에 올라가요.

> 처음 올릴 때 깃허브 로그인 창이 뜨면 정상이에요. 「Permission denied」가 나오면 메일함에서 깃허브 **초대 수락(Accept invitation)** 을 먼저 눌러 주세요.

## 폴더 구성

```
1118_HANA/
├── 00_자기소개/            ← <닉네임>.md  (처음 시작할 때 자동으로 생겨요)
├── 실습1_확장프로그램/      ← <닉네임>/  크롬 확장 「오늘 할 일 작성기」
├── 실습2_홈페이지/          ← <닉네임>/  팀 소개 페이지 + 버셀 링크
├── 실습3_나만의도구/        ← <닉네임>/  내 업무용 작은 도구
├── [강사예시]/             ← 강사 예제 (고치지 않고, 쓰고 싶으면 내 폴더로 복사)
├── .agents/skills/         ← Codex용 스킬 2종 (받으면 바로 쓸 수 있어요)
└── .claude/skills/         ← Claude Code용 같은 스킬
```

| 실습 | 무엇을 | Codex에 이렇게 |
|---|---|---|
| [실습1](실습1_확장프로그램) | 할 일 크롬 확장 (기본 · 메일 · 캐릭터 · 환율 예시) | "실습1 올려 줘" |
| [실습2](실습2_홈페이지) | 가상 팀 소개 페이지 · 버셀 링크 | "팀 페이지 만들고 싶어" → "실습2 올려 줘" |
| [실습3](실습3_나만의도구) | 내 업무의 불편을 줄이는 도구 | "내 업무 도구 만들고 싶어" → "실습3 올려 줘" |

## 스킬 2종 (설치 필요 없음)

이 저장소 폴더를 Codex로 열면 바로 쓸 수 있어요. 안 보이면 Codex를 껐다 켜 주세요.

| 스킬 | 이렇게 말하면 시작 | 결과물 |
|---|---|---|
| **team-page-prd** · 팀 홈페이지 PRD 제작기 | "팀 페이지 만들고 싶어" | PRD · 로고 프롬프트 · 제작 계획서 → (만들까요?) → `index.html` |
| **work-os-builder** · 나만의 업무 도구 | "내 업무 도구 만들고 싶어" | 작은 도구: `prd.md` → (만들까요?) → `index.html` + `test.md` · 업무 OS: 기획서 · 계획서 → `index.html` |

두 스킬 모두 계획서까지 만든 뒤 **"만들까요?" 하고 멈춰요.** 읽어 보고 괜찮으면 "만들어 줘".

> `.agents`, `.claude`처럼 점(.)으로 시작하는 폴더는 탐색기에서 숨겨져 보일 수 있어요. 탐색기 → 보기 → 숨긴 항목.

## 꼭 지켜 주세요: 개인정보 · 회사 정보

- 내 폴더 이름은 **닉네임이나 실명** 중 편한 것으로 정해요.
- **고객 정보 · 사내 자료는 넣지 않아요.** 고객 이름, 계좌번호, 실제 거래 금액, 사내 시스템 주소, 내부 문서 모두 해당돼요. 실습은 **가짜 데이터**로.
- **연락처 · 비밀번호 · API 키**는 넣지 않아요.
- 스크린샷에 메일 · 메신저 · 다른 탭이 찍히지 않았는지 한 번 더 봐요.
- 내 폴더만 고치고 올려요. 다른 사람 폴더와 `[강사예시]`는 건드리지 않아요.

애매하면 가짜 이름, 가짜 번호로 바꿔서 올립니다. 회사의 AI 이용 정책이 항상 우선입니다.
